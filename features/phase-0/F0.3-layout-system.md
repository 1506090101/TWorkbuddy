# F0.3 — 统一布局系统

> **Phase**: Phase 0 — 基础设施层 (Foundation)
> **Priority**: P0
> **Status**: 进行中 (已部分实现)
> **Dependencies**: F0.2 (统一设计系统)

## 概述

F0.3 定义 Agent Buddy 应用的全局布局骨架，是所有功能模块的视觉容器。布局采用经典的 IDE 风格三栏结构：左侧会话/导航栏（Sidebar）、中间主对话区（Main Content）、右侧详情面板（Right Panel），顶部为自定义标题栏（TitleBar），底部为输入区域（InputBar）。

布局系统与 Zustand 状态管理深度集成，所有面板的折叠/展开状态、尺寸参数通过 `uiStore` 统一管理，支持动画过渡。窗口配置遵循 macOS 风格的无边框窗口设计（`titleBarStyle: hiddenInset`），同时兼容 Windows/Linux 的基本体验。

面板间预留 resize handle 机制的设计接口，允许用户拖拽调整面板宽度（后续增强）。布局响应窗口尺寸变化，当窗口宽度低于阈值时自动折叠侧边面板，确保主内容区始终可用。

## 验收标准

### 功能验收
- [ ] 三栏布局完整可用：左侧栏 (Sidebar, 默认 260px) + 中间主区 (flex-1) + 右侧面板 (RightPanel, 默认 360px)
- [ ] 顶部 TitleBar (40px) 支持窗口拖拽和窗口控制按钮（最小化/最大化/关闭）
- [ ] Sidebar 可折叠至 48px（仅显示图标），展开至 260px（显示完整内容）
- [ ] 右侧面板可折叠（完全隐藏），默认状态为关闭
- [ ] 面板折叠/展开有平滑过渡动画（300ms `ease-spring`）
- [ ] 最小窗口尺寸为 800x600
- [ ] 默认窗口尺寸为 1280x800
- [ ] 窗口最大化时保持布局比例
- [ ] macOS 使用 `hiddenInset` 标题栏样式，Windows 使用 `default` 或自定义

### 非功能验收
- [ ] 面板折叠动画帧率 >= 60fps
- [ ] 布局 resize 不触发不必要的 React 重渲染（使用 Zustand selector 优化）
- [ ] 自定义 TitleBar 中的窗口控制按钮与原生窗口行为一致

```typescript
/** 布局状态 */
export interface LayoutState {
  /** Sidebar 展开状态 */
```

### IPC 通道

| 通道 | 方向 | 参数 | 返回值 | 说明 |
|------|------|------|--------|------|
| `window:minimize` | invoke→handle | 无 | `void` | 窗口最小化 |
| `window:maximize` | invoke→handle | 无 | `void` | 窗口最大化/还原 |
| `window:close` | invoke→handle | 无 | `void` | 关闭窗口 |
| `window:on-state-change` | listen←main | `{isMaximized: boolean, isFocused: boolean}` | — | 主进程推送窗口状态变化 |

### 关键实现逻辑

#### 1. AppLayout 组件核心逻辑

```tsx
// renderer/src/components/layout/AppLayout.tsx
import { useEffect } from 'react'
import { useUILayoutStore } from '../../stores/uiStore'
import { TitleBar } from './TitleBar'
import { Sidebar } from './Sidebar'
import { RightPanel } from './RightPanel'

interface AppLayoutProps {
  children: React.ReactNode
}

export function AppLayout({ children }: AppLayoutProps) {
  const {
    sidebarExpanded,
    sidebarWidth,
    sidebarTransitioning,
    rightPanelExpanded,
    rightPanelWidth,
    rightPanelMode
  } = useUILayoutStore()

  const effectiveSidebarWidth = sidebarExpanded ? sidebarWidth : LAYOUT_CONSTANTS.SIDEBAR_COLLAPSED_WIDTH

  return (
    <div className="h-screen flex flex-col overflow-hidden bg-secondary font-ui">
      {/* 顶部标题栏 */}
      <TitleBar />

      {/* 主体区域 */}
      <div className="flex flex-1 overflow-hidden" style={{ height: `calc(100vh - ${LAYOUT_CONSTANTS.TITLEBAR_HEIGHT}px)` }}>
        {/* 左侧栏 */}
        <Sidebar />

        {/* 中间主区域 */}
        <main
          className="flex-1 flex flex-col overflow-hidden transition-all"
          style={{
            // 主区域宽度自动适配左右面板的宽度
            marginLeft: 0,  // Sidebar 用 absolute/fixed 定位，不占流
            transitionDuration: `${LAYOUT_CONSTANTS.TRANSITION_DURATION}ms`,
            transitionTimingFunction: 'var(--ease-spring)'
          }}
        >
          {children}
        </main>

        {/* 右侧面板 */}
        {rightPanelExpanded && rightPanelMode && (
          <RightPanel />
        )}
      </div>
    </div>
  )
}
```

#### 2. Sidebar 折叠/展开实现

```tsx
// renderer/src/components/layout/Sidebar.tsx
import { PanelLeftClose, PanelLeftOpen } from 'lucide-react'
import { useUILayoutStore } from '../../stores/uiStore'
import { LAYOUT_CONSTANTS } from '../../types/layout'

export function Sidebar() {
  const {
    sidebarExpanded,
    toggleSidebar,
    setSidebarTransitioning
  } = useUILayoutStore()

  const handleToggle = () => {
    setSidebarTransitioning(true)
    toggleSidebar()
    // 动画结束后清除 transition 状态
    setTimeout(() => {
      setSidebarTransitioning(false)
    }, LAYOUT_CONSTANTS.TRANSITION_DURATION)
  }

  return (
    <aside
      className="h-full flex flex-col bg-tertiary border-r border-default shrink-0 overflow-hidden transition-all"
      style={{
        width: sidebarExpanded
          ? LAYOUT_CONSTANTS.SIDEBAR_EXPANDED_WIDTH
          : LAYOUT_CONSTANTS.SIDEBAR_COLLAPSED_WIDTH,
        transitionDuration: `${LAYOUT_CONSTANTS.TRANSITION_DURATION}ms`,
        transitionTimingFunction: 'var(--ease-spring)'
      }}
    >
      {/* SidebarHeader */}
      <div className="flex items-center justify-between h-10 px-3 border-b border-default shrink-0">
        {sidebarExpanded && (
          <span className="font-semibold text-sm text-primary truncate">
            Agent Buddy
          </span>
        )}
        <button
          onClick={handleToggle}
          className="w-7 h-7 rounded-md flex items-center justify-center
                     hover:bg-hover transition-colors text-secondary ml-auto shrink-0"
          title={sidebarExpanded ? '折叠侧边栏' : '展开侧边栏'}
        >
          {sidebarExpanded ? <PanelLeftClose size={16} /> : <PanelLeftOpen size={16} />}
        </button>
      </div>

      {/* SidebarContent: 仅展开状态渲染内容，折叠状态只显示图标 */}
      <div className="flex-1 overflow-y-auto overflow-x-hidden">
        {sidebarExpanded ? (
          <div className="p-2">
            {/* 内容由父组件或路由注入 */}
          </div>
        ) : (
          <div className="flex flex-col items-center pt-2 gap-1">
            {/* 图标仅模式 */}
          </div>
        )}
      </div>
    </aside>
  )
}
```

#### 3. TitleBar 实现

```tsx
// renderer/src/components/layout/TitleBar.tsx
import { Minus, Square, X } from 'lucide-react'
import { LAYOUT_CONSTANTS } from '../../types/layout'

export function TitleBar() {
  const handleMinimize = () => window.electronAPI?.minimizeWindow()
  const handleMaximize = () => window.electronAPI?.maximizeWindow()
  const handleClose = () => window.electronAPI?.closeWindow()

  return (
    <div
      className="flex items-center justify-between bg-secondary border-b border-default shrink-0 select-none"
      style={{
        height: LAYOUT_CONSTANTS.TITLEBAR_HEIGHT,
        // 整个 TitleBar 是可拖拽区域 (Windows/Linux)
        WebkitAppRegion: 'drag',
        appRegion: 'drag'
      } as React.CSSProperties}
    >
      {/* 左侧: 可放置 logo 或面包屑 */}
      <div className="flex items-center pl-3" style={{ WebkitAppRegion: 'no-drag', appRegion: 'no-drag' } as React.CSSProperties}>
        {/* 可放置快捷操作区 */}
      </div>

      {/* 中间: 可放置标题或当前会话名 */}
      <div className="flex-1 text-center text-sm text-secondary truncate px-4">
        Agent Buddy
      </div>

      {/* 右侧: 窗口控制按钮 */}
      <div
        className="flex items-center h-full"
        style={{ WebkitAppRegion: 'no-drag', appRegion: 'no-drag' } as React.CSSProperties}
      >
        <WindowControlButton onClick={handleMinimize} icon={<Minus size={14} />} label="最小化" />
        <WindowControlButton onClick={handleMaximize} icon={<Square size={12} />} label="最大化" />
        <WindowControlButton onClick={handleClose} icon={<X size={14} />} label="关闭" isClose />
      </div>
    </div>
  )
}

function WindowControlButton({
  onClick,
  icon,
  label,
  isClose = false
}: {
  onClick: () => void
  icon: React.ReactNode
  label: string
  isClose?: boolean
}) {
  return (
    <button
      onClick={onClick}
      className={`w-11 h-full flex items-center justify-center transition-colors
        ${isClose
          ? 'hover:bg-danger-500 hover:text-white'
          : 'hover:bg-hover text-secondary'
        }`}
      title={label}
      aria-label={label}
    >
      {icon}
    </button>
  )
}
```

```tsx
// renderer/src/components/layout/RightPanel.tsx
import { X } from 'lucide-react'
import { useUILayoutStore } from '../../stores/uiStore'
import { LAYOUT_CONSTANTS, type RightPanelMode } from '../../types/layout'

export function RightPanel() {
  const {
    rightPanelWidth,
    rightPanelMode,
    closeRightPanel
  } = useUILayoutStore()

  const panelTitle = getPanelTitle(rightPanelMode)

  return (
    <aside
      className="h-full bg-secondary border-l border-default flex flex-col shrink-0 transition-all"
      style={{
        width: rightPanelWidth,
        transitionDuration: `${LAYOUT_CONSTANTS.TRANSITION_DURATION}ms`,
        transitionTimingFunction: 'var(--ease-spring)'
      }}
    >
      {/* Header */}
      <div className="flex items-center justify-between h-10 px-3 border-b border-default shrink-0">
        <span className="text-sm font-medium text-primary">{panelTitle}</span>
        <button
          onClick={closeRightPanel}
          className="w-7 h-7 rounded-md flex items-center justify-center
                     hover:bg-hover transition-colors text-secondary"
        >
          <X size={14} />
        </button>
      </div>

      {/* Content: 根据 mode 渲染对应内容 */}
      <div className="flex-1 overflow-y-auto">
        {/* 具体内容由各 Feature 面板组件填充 */}
      </div>
    </aside>
  )
}

function getPanelTitle(mode: RightPanelMode | null): string {
  const titles: Record<NonNullable<RightPanelMode>, string> = {
    'agent-result':   'Agent 结果',
    'diff-review':    '变更审查',
    'knowledge-base': '知识库',
    'task-list':      '任务列表',
    'session-tree':   '会话分支',
    'settings':       '设置'
  }
  return mode ? titles[mode] : ''
}
```

## UI/UX 规范

- **Sidebar 折叠动画**: 宽度从 260px → 48px，内容淡出 → 图标淡入，使用 `ease-spring` 曲线（300ms）
- **RightPanel 动画**: 从右侧滑入/滑出，transform + opacity
- **TitleBar 窗口控制按钮**: 圆形的 macOS 风格按钮（红/黄/绿）。Windows 上使用方块图标
- **布局自适应**: 窗口宽度 < 900px 时自动折叠 Sidebar；窗口宽度 < 700px 时自动折叠 RightPanel
- **焦点环**: Focus visible 时 TitleBar 按钮显示 outline
- **拖拽区域**: TitleBar 的非按钮区域支持窗口拖拽移动（`-webkit-app-region: drag`）

## 开放问题

1. **自定义 TitleBar vs 原生**: macOS `hiddenInset` 已经很好看，是否需要完全自定义 TitleBar？Windows 上原生 TitleBar 和自定义哪个更好？
2. **Resize handle**: 是否 Phase 0 就实现拖拽调整面板宽度，还是留给后续增强？
3. **多显示器**: 布局系统是否需要支持跨显示器/独立窗口模式？
4. **底部面板**: 是否需要预留底部面板区域（终端、输出）？当前布局只有三栏，终端可能作为底部附加面板。

## 备注

- Theme colors 使用 F0.2 定义的 CSS 变量（`bg-secondary`, `border-default`, `text-primary` 等）
- 布局状态通过 `useUILayoutStore` 全局共享，确保所有子组件能响应布局变化
- `AppLayout` 应该作为 `App.tsx` 的唯一根级容器组件
- Sidebar/RighPanel 内部的具体内容渲染由后续 Feature 实现，本 Feature 只定义容器结构
- 窗口控制按钮的 IPC 通道由 F0.5（IPC 通信层）统一实现
