# F0.4 — 通用 UI 基础组件库

> **Phase**: Phase 0 — 基础设施层 (Foundation)
> **Priority**: P0
> **Status**: 进行中 (已部分实现)
> **Dependencies**: F0.2 (统一设计系统)

## 概述

F0.4 构建 Agent Buddy 的通用 UI 基础组件库，提供所有功能模块共享的原子级 UI 组件。这些组件确保全应用视觉一致、交互统一、无障碍合规，并完整支持 F0.2 定义的明暗双主题。组件库包含 14 类核心组件，覆盖按钮、输入框、提示、加载态、徽章、卡片、弹窗、标签页、下拉选择、开关、图标按钮、空状态和消息通知。

每个组件都遵循统一的设计规范：使用 Tailwind CSS 语义类名（引用 CSS 变量）、支持 `className` 透传、提供完整的 TypeScript props 类型定义、支持 disabled/loading/error 等通用状态、遵循 WAI-ARIA 无障碍标准。组件采用 Compound Component 模式（需要子组件组合的场景，如 Card/Header/Footer），提供简洁直观的 API。

组件库的文件结构按功能分组：表单类（Button, Input, Select, Switch）、反馈类（Toast, Spinner, EmptyState, Tooltip）、容器类（Card, Dialog, Tabs, Badge）。所有组件统一从 `@/components/ui` 路径导出，使用 Barrel Export 模式简化导入。

## 验收标准

### 功能验收
- [ ] **Button**: variants (primary/secondary/ghost/danger/success), sizes (sm/md/lg), loading state (spinner + disabled), icon slot
- [ ] **Input / Textarea**: label, placeholder, error message, hint text, disabled, required indicator
- [ ] **Tooltip**: hover 延迟 500ms, placement (top/bottom/left/right), 支持 JSX content
- [ ] **Spinner**: sizes (sm/md/lg), 使用 CSS animation, 角色为 `status: "loading"`
- [ ] **Badge**: variants (default/success/warning/danger/info), dot 变体
- [ ] **Card**: header/body/footer 插槽, 可选 hover effect
- [ ] **Dialog/Modal**: overlay 背景, Escape 关闭, 焦点捕获 (focus-trap), 点击 overlay 关闭, 阻止背景滚动
- [ ] **Tabs**: underline 和 pill 两种 variant, 受控/非受控模式
- [ ] **Dropdown/Select**: 搜索过滤选项, 键盘导航 (ArrowUp/Down/Enter/Escape)
- [ ] **Switch**: toggle 开关, checked/unchecked 状态, disabled
- [ ] **IconButton**: 纯图标按钮, 自动附带 Tooltip
- [ ] **EmptyState**: icon + title + description + 可选 action 按钮
- [ ] **Toast/Notification**: position (top-right 为主), auto-dismiss (默认 5s), success/error/warning/info 类型
- [ ] 所有组件支持明暗主题自动切换（通过 Tailwind dark: 前缀）
- [ ] 所有组件有完整的 TypeScript props 类型导出

### 非功能验收
- [ ] 组件体积：单个组件 < 5KB (gzipped)
- [ ] 无障碍：关键交互元素有正确的 ARIA label/role/state
- [ ] 键盘操作：Dialog/Select/Tabs 支持完整键盘导航
- [ ] 无外部 UI 库依赖（除 lucide-react 图标）

#### 1. Button 组件

```tsx
// renderer/src/components/ui/Button.tsx
import { forwardRef } from 'react'
import { Loader2 } from 'lucide-react'
import type { ButtonProps } from './types'

const variantStyles: Record<NonNullable<ButtonProps['variant']>, string> = {
  primary:   'bg-primary-500 text-white hover:bg-primary-600 active:bg-primary-700 shadow-sm',
  secondary: 'bg-secondary text-primary border border-default hover:bg-hover active:bg-active',
  ghost:     'text-secondary hover:bg-hover active:bg-active',
  danger:    'bg-danger-500 text-white hover:bg-danger-600 active:bg-danger-700 shadow-sm',
  success:   'bg-success-500 text-white hover:bg-success-600 active:bg-success-700 shadow-sm',
}

const sizeStyles: Record<NonNullable<ButtonProps['size']>, string> = {
  sm: 'h-7 px-2.5 text-xs gap-1.5 rounded-md',
  md: 'h-8 px-3.5 text-sm gap-2 rounded-lg',
  lg: 'h-10 px-5 text-base gap-2.5 rounded-lg',
}

export const Button = forwardRef<HTMLButtonElement, ButtonProps>(
  ({ variant = 'primary', size = 'md', loading = false, icon, iconOnly, children, disabled, className = '', ...props }, ref) => {
    const isDisabled = disabled || loading

    return (
      <button
        ref={ref}
        disabled={isDisabled}
        className={`
          inline-flex items-center justify-center font-medium
          transition-colors duration-fast ease-out
          focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-primary-200 focus-visible:ring-offset-1
          ${variantStyles[variant]}
          ${sizeStyles[size]}
          ${iconOnly ? 'aspect-square p-0' : ''}
          ${isDisabled ? 'opacity-50 cursor-not-allowed' : 'cursor-pointer'}
          ${className}
        `.trim()}
        {...props}
      >
        {loading ? (
          <Loader2 size={size === 'sm' ? 14 : size === 'md' ? 16 : 18} className="animate-spin shrink-0" />
        ) : icon ? (
          <span className="shrink-0">{icon}</span>
        ) : null}
        {!iconOnly && children && <span>{children}</span>}
      </button>
    )
  }
)

Button.displayName = 'Button'
```

#### 2. Dialog 组件 (focus-trap + portal)

```tsx
// renderer/src/components/ui/Dialog.tsx
import { useEffect, useRef, useCallback } from 'react'
import { createPortal } from 'react-dom'
import { X } from 'lucide-react'
import type { DialogProps } from './types'

const sizeStyles: Record<NonNullable<DialogProps['size']>, string> = {
  sm:   'max-w-sm',
  md:   'max-w-lg',
  lg:   'max-w-2xl',
  full: 'max-w-[90vw] max-h-[90vh]',
}

export function Dialog({
  open, onOpenChange, title, description, children, footer,
  size = 'md', closeOnOverlay = true, closeOnEscape = true
}: DialogProps) {
  const dialogRef = useRef<HTMLDivElement>(null)
  const previousActiveElement = useRef<HTMLElement | null>(null)

  // 焦点捕获
  useEffect(() => {
    if (!open) return

    previousActiveElement.current = document.activeElement as HTMLElement

    // 将焦点移到弹窗内第一个可聚焦元素
    const focusable = dialogRef.current?.querySelector<HTMLElement>(
      'button, [href], input, select, textarea, [tabindex]:not([tabindex="-1"])'
    )
    focusable?.focus()

    // 阻止背景滚动
    document.body.style.overflow = 'hidden'

    return () => {
      document.body.style.overflow = ''
      previousActiveElement.current?.focus()
    }
  }, [open])

  // Escape 关闭
  const handleKeyDown = useCallback((e: React.KeyboardEvent) => {
    if (e.key === 'Escape' && closeOnEscape) {
      onOpenChange(false)
    }
  }, [closeOnEscape, onOpenChange])

  if (!open) return null

  return createPortal(
    <div className="fixed inset-0 z-50 flex items-center justify-center" onKeyDown={handleKeyDown}>
      {/* Overlay */}
      <div
        className="absolute inset-0 bg-overlay animate-fade-in"
        onClick={closeOnOverlay ? () => onOpenChange(false) : undefined}
      />

      {/* Dialog Body */}
      <div
        ref={dialogRef}
        role="dialog"
        aria-modal="true"
        aria-label={title}
        aria-describedby={description ? 'dialog-description' : undefined}
        className={`
          relative z-10 bg-secondary rounded-xl shadow-xl
          w-full ${sizeStyles[size]}
          animate-scale-in
          border border-default
        `.trim()}
      >
        {/* Header */}
        {title && (
          <div className="flex items-center justify-between px-5 pt-5 pb-3">
            <h2 className="text-lg font-semibold text-primary">{title}</h2>
            <button
              onClick={() => onOpenChange(false)}
              className="w-7 h-7 rounded-md flex items-center justify-center
                         hover:bg-hover transition-colors text-secondary"
              aria-label="关闭"
            >
              <X size={16} />
            </button>
          </div>
        )}

        {description && (
          <p id="dialog-description" className="px-5 pb-3 text-sm text-secondary">{description}</p>
        )}

        {/* Body */}
        <div className="px-5 py-2 overflow-y-auto">
          {children}
        </div>

        {/* Footer */}
        {footer && (
          <div className="flex items-center justify-end gap-2 px-5 py-4 border-t border-default">
            {footer}
          </div>
        )}
      </div>
    </div>,
    document.body
  )
}
```

#### 3. Toast 系统

```tsx
// renderer/src/components/ui/Toast.tsx
import { useEffect, useState } from 'react'
import { createPortal } from 'react-dom'
import { X, CheckCircle, AlertCircle, AlertTriangle, Info } from 'lucide-react'
import { useToastStore } from '../../stores/toastStore'
import type { ToastItem } from './types'

const typeIcons = {
  info: <Info size={18} />,
  success: <CheckCircle size={18} />,
  warning: <AlertTriangle size={18} />,
  error: <AlertCircle size={18} />,
}

const typeStyles = {
  info:    'border-info-400 bg-info-50 dark:bg-info-950',
  success: 'border-success-400 bg-success-50 dark:bg-success-950',
  warning: 'border-warning-400 bg-warning-50 dark:bg-warning-950',
  error:   'border-danger-400 bg-danger-50 dark:bg-danger-950',
}

function ToastItemComponent({ toast: t }: { toast: ToastItem }) {
  const removeToast = useToastStore(s => s.removeToast)
  const [visible, setVisible] = useState(false)

  useEffect(() => {
    // 入场动画
    requestAnimationFrame(() => setVisible(true))

    // 自动关闭
    if (t.duration !== undefined && t.duration > 0) {
      const timer = setTimeout(() => {
        setVisible(false)
        setTimeout(() => removeToast(t.id), 300) // 等退场动画
      }, t.duration ?? 5000)
      return () => clearTimeout(timer)
    }

    // 默认 5 秒
    const timer = setTimeout(() => {
      setVisible(false)
      setTimeout(() => removeToast(t.id), 300)
    }, 5000)
    return () => clearTimeout(timer)
  }, [])

  return (
    <div
      className={`
        flex items-start gap-3 p-3 rounded-lg border shadow-md
        transition-all duration-normal ease-out
        max-w-sm w-full
        ${typeStyles[t.type ?? 'info']}
        ${visible ? 'translate-x-0 opacity-100' : 'translate-x-full opacity-0'}
      `.trim()}
    >
      <span className="shrink-0 mt-0.5 text-primary">{typeIcons[t.type ?? 'info']}</span>
      <div className="flex-1 min-w-0">
        <p className="text-sm font-medium text-primary">{t.title}</p>
        {t.description && <p className="text-xs text-secondary mt-0.5">{t.description}</p>}
      </div>
      <button
        onClick={() => {
          setVisible(false)
          setTimeout(() => removeToast(t.id), 300)
        }}
        className="shrink-0 w-5 h-5 rounded flex items-center justify-center hover:bg-hover text-secondary"
      >
        <X size={12} />
      </button>
    </div>
  )
}

export function ToastContainer() {
  const toasts = useToastStore(s => s.toasts)

  if (toasts.length === 0) return null

  return createPortal(
    <div
      className="fixed top-4 right-4 z-[100] flex flex-col gap-2 pointer-events-none"
      aria-live="polite"
      aria-label="通知"
    >
      {toasts.map(t => (
        <div key={t.id} className="pointer-events-auto">
          <ToastItemComponent toast={t} />
        </div>
      ))}
    </div>,
    document.body
  )
}
```

## UI/UX 规范

- **统一圆角**: 所有组件使用 `rounded-lg`（8px），小型元素使用 `rounded-md`（6px）
- **统一焦点环**: 所有可交互元素使用 `focus-visible:ring-2 focus-visible:ring-primary-200 focus-visible:ring-offset-1`
- **统一过渡**: 所有状态变化使用 `transition-colors duration-fast ease-out`（150ms）
- **禁用态**: `opacity-50 cursor-not-allowed` + 交互事件阻止
- **加载态**: 使用 spinner 替换内容 + 按钮禁用
- **颜色语义**:
  - primary（蓝）= 主要操作、选中态、激活
  - success（绿）= 成功、完成、通过
  - danger（红）= 危险操作、删除、停止
  - warning（黄）= 警告、注意
  - info（青）= 信息、提示
- **间距一致性**: 组件内部使用 Tailwind 的 spacing scale（与 F0.2 4px 基准对齐）
- **暗色主题**: 所有组件通过 `dark:` 前缀适配暗色模式

## 开放问题

1. **组件库是否走 monorepo**: 当前组件在 `renderer/src/components/ui/`，如果未来主进程也需要 UI（如 Tray 菜单），是否需要提取为独立包？
2. **日期选择器**: 是否需要 DatePicker？当前未纳入 Phase 0，但设置中可能需要日期选择。
3. **虚拟列表容器**: Select 的选项很多时是否需要虚拟列表？（可先简单限制选项数量的 UI 提示）
4. **过渡动画**: Toast 入场/退场动画是否需要依赖 framer-motion 或保持纯 CSS？
