# F0.2 — 统一设计系统 (Design System)

> **Phase**: Phase 0 — 基础设施层 (Foundation)
> **Priority**: P0
> **Status**: 进行中 (已部分实现)
> **Dependencies**: F0.1 (项目初始化与工程骨架)

## 概述

F0.2 定义 Agent Buddy 应用全平台的统一设计语言，以 Design Token 体系为核心，通过 CSS 变量 + Tailwind CSS 配置实现颜色、字体、间距、圆角、阴影、动画曲线等视觉属性的集中管理和跨组件复用。设计系统支持明暗双主题，主题切换通过 CSS 变量级别的即时替换实现，无闪烁、无重渲染。

设计 Token 采用三层架构：**Raw Value**（原始值如 `#3b82f6`）→ **CSS Variable**（如 `--color-primary-500`）→ **Semantic Token**（如 `bg-primary`），确保视觉一致性同时保持灵活性。Tailwind 配置通过 `theme.extend` 引用所有 CSS 变量，使组件开发时使用语义化类名而非硬编码颜色值。

色彩系统基于 Tailwind CSS 的 50-950 色阶体系，覆盖 primary (蓝)、accent (紫)、neutral (灰) 三个主色系，以及 success (绿)、warning (黄)、danger (红)、info (青) 四个语义色系。每个色系包含 11 级色阶，覆盖从极浅到极深的所有使用场景。

## PRD 对应

- **3.7.2 UI 风格**: 配色方案、圆角卡片风格
- **3.7.3 设置中心 Tab 8**: 外观主题设置（light/dark/system）
- **3.16.3 键盘优先工作流**: 快捷键颜色标识

## 验收标准

### 功能验收
- [ ] CSS 变量定义所有设计 token（`--color-*`, `--font-*`, `--space-*`, `--radius-*`, `--shadow-*`, `--animate-*`）
- [ ] Tailwind config 通过 `theme.extend` 引用 CSS 变量，组件中可使用 `bg-primary` / `text-muted` 等语义类名
- [ ] 明色主题（light mode）CSS 变量完整定义且视觉可用
- [ ] 暗色主题（dark mode）CSS 变量完整定义且视觉可用
- [ ] 主题切换通过 CSS class (`dark`) 切换 CSS 变量实现，无 JavaScript 干预
- [ ] `prefers-color-scheme` 媒体查询自动跟随系统主题
- [ ] Tailwind 的 `dark:` 前缀在所有组件中可用
- [ ] GitHub 风格代码块色彩方案（亮/暗各一套）

### 非功能验收
- [ ] 主题切换响应时间 < 50ms（CSS 变量切换无 JavaScript 开销）
- [ ] 设计 token 数量合理：颜色 < 100 个变量，总计 < 200 个变量
- [ ] 所有 token 有明确的命名规范和文档注释

## 技术设计

### 数据模型

```typescript
// ─── 色彩系统 (每色系 11 级: 50, 100, 200, 300, 400, 500, 600, 700, 800, 900, 950) ───

type ColorScale = {
  50: string;    // 最浅 — 极浅背景
  100: string;   // 浅背景、禁用态
  200: string;   // 选中态背景
  300: string;   // 边框
  400: string;   // 占位符文字
  500: string;   // 主色、链接
  600: string;   // hover 态
  700: string;   // active 态
  800: string;   // 深色文字
  900: string;   // 最深色
  950: string;   // 暗色主题专用最浅色
};

// 用于背景、边框、文字等非语义场景

// 语义色系
type SemanticColors = {
  success: ColorScale;   // 绿
  warning: ColorScale;   // 黄
  danger: ColorScale;    // 红
  info: ColorScale;      // 青
};

// ─── 字体系统 ───
interface FontTokens {
  family: {
    ui: string;          // UI 字体栈: -apple-system, BlinkMacSystemFont, 'Segoe UI', ...
    code: string;        // 代码字体栈: 'JetBrains Mono', 'Fira Code', 'Cascadia Code', ...
  };
  size: {
    xs: '11px';          // 辅助文字、badge
    sm: '13px';          // 次要文字、工具调用标题
    base: '14px';        // 正文
    lg: '16px';          // 标题
    xl: '20px';          // 大标题
    '2xl': '24px';       // 页面标题
    '3xl': '30px';       // Hero 标题
  };
  weight: {
    normal: '400';
    medium: '500';
    semibold: '600';
    bold: '700';
  };
  lineHeight: {
    tight: '1.25';
    normal: '1.5';
    relaxed: '1.75';
  };
}

// ─── 间距系统 (4px 基准) ───
interface SpacingTokens {
  '1':  '4px';
  '2':  '8px';
  '3':  '12px';
  '4':  '16px';
  '5':  '20px';
  '6':  '24px';
  '8':  '32px';
  '10': '40px';
  '12': '48px';
  '16': '64px';
  '20': '80px';
}

// ─── 圆角系统 ───
interface RadiusTokens {
  sm:   '6px';     // 小型元素
  md:   '8px';     // 卡片、输入框
  lg:   '12px';    // 弹窗、面板
  xl:   '16px';    // 大型容器
  '2xl':'20px';    // 特大圆角
  full: '9999px';  // 圆形元素
}

// ─── 阴影系统 ───
interface ShadowTokens {
  sm:   string;    // 轻微浮起
  md:   string;    // 常规浮起
  lg:   string;    // 明显浮起
  xl:   string;    // 重度浮起
  inner: string;   // 内阴影（输入框）
  glow:  string;   // 发光效果（primary 色系）
}

// ─── 动画曲线 ───
interface AnimationTokens {
  duration: {
    instant: '100ms';
    fast:    '150ms';
    normal:  '200ms';
    slow:    '300ms';
    slower:  '500ms';
  };
  timing: {
    'ease-out':    string;   // 常规: cubic-bezier(0, 0, 0.2, 1)
    'ease-spring': string;   // 弹性: cubic-bezier(0.34, 1.56, 0.64, 1)
    'ease-in-out': string;   // 过渡: cubic-bezier(0.4, 0, 0.2, 1)
  };
}
```

### IPC 通道

本 Feature 无 IPC 通道。主题切换通过 CSS 变量完成，不涉及主进程通信。

#### 3. 主题切换逻辑

主题切换在 `renderer/src/index.css` 中通过 `prefers-color-scheme` 和 `.dark` class 协作实现：

```css
/* System preference: 当用户设置跟随系统时 */
@media (prefers-color-scheme: dark) {
  :root:not(.light):not(.dark) {
    /* 应用暗色变量覆盖 */
    --bg-primary: var(--color-neutral-950);
    /* ... (与 .dark 规则完全一致) ... */
  }
}

/* 显式主题: JavaScript 在 <html> 上切换 class */
/*
   html.classList.add('dark')    → 暗色主题
   html.classList.remove('dark')  → 亮色主题
   html.classList.add('light')    → 锁定亮色（覆盖系统偏好）
   不添加任何 class                → 跟随系统
*/
```
