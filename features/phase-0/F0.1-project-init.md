# F0.1 — 项目初始化与工程骨架

> **Phase**: Phase 0 — 基础设施层 (Foundation)
> **Priority**: P0
> **Status**: 进行中 (已部分实现)
> **Dependencies**: None

## 概述

F0.1 是整个 Agent Buddy 项目的工程起点，负责搭建 Electron + electron-vite + React 18 + TypeScript 的项目骨架。本 Feature 建立标准的 main / preload / renderer 三层 Electron 架构，配置 TypeScript 严格模式、ESLint + Prettier 代码规范、Tailwind CSS 构建管线，确保团队从第一天起就拥有统一、可维护的工程基础。

项目初始化不仅包括脚手架搭建，还涵盖完整的目录结构规范制定、开发/构建/调试工作流定义、以及核心依赖的版本锁定。这是所有后续 Feature 的物理载体，其设计直接影响整个项目的可维护性和开发体验。

工程骨架遵循 electron-vite 的最佳实践：主进程代码在 `main/` 目录独立编译为 Node.js 环境、preload 脚本在 `preload/` 目录以安全受限模式编译、渲染进程在 `renderer/` 目录以浏览器环境编译，三者通过类型安全的 IPC bridge 通信（具体通信层由 F0.5 定义）。

- [ ] Hot Module Replacement (HMR) 在开发模式下正常工作（renderer 热更新）

- [ ] 开发工具（DevTools）在开发模式下可用
- [ ] `package.json` 中 scripts 包含 `dev` / `build` / `lint` / `typecheck`

- [ ] 首次 `npm install` 时间 < 120 秒（网络正常环境）

- [ ] 构建产物体积合理（主进程 < 2MB, renderer < 5MB before gzip）

### 关键实现逻辑

#### 1. electron-vite 构建配置

```typescript
// electron.vite.config.ts
import { resolve } from 'path'
import { defineConfig, externalizeDepsPlugin } from 'electron-vite'
import react from '@vitejs/plugin-react'
import tailwindcss from 'tailwindcss'

export default defineConfig({
  main: {
    plugins: [externalizeDepsPlugin()],
    build: {
      outDir: 'out/main',
      rollupOptions: {
        input: {
          index: resolve(__dirname, 'main/index.ts')
        }
      }
    }
  },
  preload: {
    plugins: [externalizeDepsPlugin()],
    build: {
      outDir: 'out/preload',
      rollupOptions: {
        input: {
          index: resolve(__dirname, 'preload/index.ts')
        }
      }
    }
  },
  renderer: {
    root: resolve(__dirname, 'renderer'),
    build: {
      outDir: 'out/renderer',
      rollupOptions: {
        input: {
          index: resolve(__dirname, 'renderer/index.html')
        }
      }
    },
    plugins: [react()],
    css: {
      postcss: {
        plugins: [tailwindcss(), autoprefixer()]
      }
    },
    resolve: {
      alias: {
        '@': resolve(__dirname, 'renderer/src')
      }
    }
  }
})
```

#### 3. 主进程入口

```typescript
// main/index.ts
import { app, BrowserWindow, shell } from 'electron'
import { join } from 'path'
import { is } from '@electron-toolkit/utils'

let mainWindow: BrowserWindow | null = null

function createWindow(): void {
  mainWindow = new BrowserWindow({
    width: 1280,
    height: 800,
    minWidth: 800,
    minHeight: 600,
    show: false,
    autoHideMenuBar: true,
    titleBarStyle: 'hiddenInset',
    webPreferences: {
      preload: join(__dirname, '../preload/index.js'),
      sandbox: false,
      contextIsolation: true,
      nodeIntegration: false
    }
  })

  mainWindow.on('ready-to-show', () => {
    mainWindow?.show()
  })

  mainWindow.webContents.setWindowOpenHandler((details) => {
    shell.openExternal(details.url)
    return { action: 'deny' }
  })

  if (is.dev && process.env['ELECTRON_RENDERER_URL']) {
    mainWindow.loadURL(process.env['ELECTRON_RENDERER_URL'])
  } else {
    mainWindow.loadFile(join(__dirname, '../renderer/index.html'))
  }
}

app.whenReady().then(() => {
  createWindow()

  app.on('activate', () => {
    if (BrowserWindow.getAllWindows().length === 0) createWindow()
  })
})

app.on('window-all-closed', () => {
  if (process.platform !== 'darwin') {
    app.quit()
  }
})
```
