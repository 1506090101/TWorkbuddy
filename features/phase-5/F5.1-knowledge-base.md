# F5.1 — 个人知识库

> **Phase**: Phase 5 — 知识库 (Knowledge Base)
> **Priority**: P0
> **Status**: Not Started
> **Dependencies**: F4.1 (多层级记忆系统)

## 概述

个人知识库是 Agent Buddy 从"助手"进化为"知识管理者"的核心功能。它提供 RAG（Retrieval-Augmented Generation）检索能力，让 Agent 在回答问题前先检索知识库中的相关知识，避免重复犯错，复用已有经验。知识库具备自动积累层（Agent 工作中提取的有价值信息、代码模式、解决方案、踩坑记录）、用户管理层（手动添加文档、笔记、代码片段、链接）、索引层（Embedding 向量化 + FTS 全文索引 + 标签分类系统）和检索层（语义搜索 + 关键词搜索 + 关联推荐）。

知识库的主要用途包括：增强回答质量（回答前检索注入）、主动提醒建议（检测相关性时提示）、用户直接查阅（浏览/搜索界面）、可分享复用（导出/导入知识包）。这让 Agent Buddy 成为一个能持续积累知识、主动应用知识的智能工作伙伴。

```typescript
interface KnowledgeCard {
  id: string;
  title: string;                   // 简短标题
  content: string;                 // Markdown 正文
  category: string;                // 分类（如 "前端"、"数据库"、"DevOps"）
  tags: string[];                  // 标签
  source: "auto" | "manual";      // 来源：自动积累 / 手动添加
  sourceSessionId?: string;       // 来源会话 ID
  sourceProjectId?: string;       // 来源项目
  embedding?: number[];            // 向量嵌入
  url?: string;                    // 网页链接（如有）
  urlSummary?: string;             // 抓取的网页摘要
  createdAt: number;
  updatedAt: number;
}

// 知识库检索选项
interface SearchOptions {
  limit?: number;
  category?: string;
  tags?: string[];
  dateRange?: [number, number];
  threshold?: number;              // 相似度阈值
}

// 检索结果
interface SearchResult {
  card: KnowledgeCard;
  score: number;                   // 相似度分数
  matchType: "semantic" | "fulltext" | "hybrid";
  highlights: string[];            // 高亮的匹配片段
}

// 知识包（导出/导入）
interface KnowledgePack {
  version: string;
  exportedAt: number;
  cards: KnowledgeCard[];
  categories: string[];
  tags: string[];
}

// Embedding 配置
interface EmbeddingConfig {
  providerId: string;
  model: string;                   // 如 "text-embedding-3-small"
  dimensions: number;              // 向量维度
  batchSize: number;               // 批量大小
}
```

### 关键实现逻辑

**向量化与检索流程**：

```typescript
// main/services/knowledge/KnowledgeBase.ts

class KnowledgeBase {
  private db: Database;              // SQLite (better-sqlite3)
  private embeddingConfig: EmbeddingConfig;

  // 初始化 SQLite + 向量存储
  async initialize(): Promise<void> {
    this.db = new Database(path.join(os.homedir(), ".agentbuddy/data/knowledge.db"));

    // 创建表
    this.db.exec(`
      CREATE TABLE IF NOT EXISTS knowledge_cards (
        id TEXT PRIMARY KEY,
        title TEXT NOT NULL,
        content TEXT NOT NULL,
        category TEXT,
        tags TEXT,                   -- JSON array
        source TEXT,                 -- "auto" | "manual"
        source_session_id TEXT,
        source_project_id TEXT,
        url TEXT,
        url_summary TEXT,
        embedding BLOB,             -- Float32Array 序列化
        created_at INTEGER,
        updated_at INTEGER
      );

      CREATE VIRTUAL TABLE IF NOT EXISTS knowledge_fts USING fts5(
        title, content, category, tags,
        content='knowledge_cards',
        content_rowid='rowid'
      );

      CREATE INDEX IF NOT EXISTS idx_cards_category ON knowledge_cards(category);
      CREATE INDEX IF NOT EXISTS idx_cards_created ON knowledge_cards(created_at);
    `);
  }

  // 生成 Embedding
  async generateEmbedding(text: string): Promise<number[]> {
    // 分批处理长文本
    const maxChunkLength = 8000;
    const chunks = chunkText(text, maxChunkLength);

    const embeddings: number[][] = [];
    for (const chunk of chunks) {
      const response = await callEmbeddingAPI(
        this.embeddingConfig.providerId,
        this.embeddingConfig.model,
        chunk
      );
      embeddings.push(response.embedding);
    }

    // 多 chunk 取平均
    if (embeddings.length === 1) return embeddings[0];
    return averageEmbeddings(embeddings);
  }

  // 语义搜索（余弦相似度）
  async semanticSearch(query: string, topK: number = 10): Promise<SearchResult[]> {
    // 1. 生成查询向量
    const queryEmbedding = await this.generateEmbedding(query);

    // 2. 从 SQLite 读取所有向量
    const rows = this.db.prepare(
      "SELECT id, title, content, category, tags, embedding FROM knowledge_cards WHERE embedding IS NOT NULL"
    ).all();

    // 3. 计算余弦相似度
    const results: SearchResult[] = [];
    for (const row of rows) {
      const cardEmbedding = new Float32Array(row.embedding.buffer);
      const score = cosineSimilarity(queryEmbedding, Array.from(cardEmbedding));
      results.push({
        card: this.rowToCard(row),
        score,
        matchType: "semantic",
        highlights: [],
      });
    }

    // 4. 排序并返回 Top-K
    return results.sort((a, b) => b.score - a.score).slice(0, topK);
  }

  // 全文搜索（FTS5）
  async fulltextSearch(query: string, topK: number = 10): Promise<SearchResult[]> {
    const rows = this.db.prepare(`
      SELECT k.*, bm25(knowledge_fts) as score
      FROM knowledge_fts
      JOIN knowledge_cards k ON k.rowid = knowledge_fts.rowid
      WHERE knowledge_fts MATCH ?
      ORDER BY score
      LIMIT ?
    `).all(query, topK);

    return rows.map(row => ({
      card: this.rowToCard(row),
      score: row.score,
      matchType: "fulltext",
      highlights: extractHighlights(row.content, query),
    }));
  }

  // 混合搜索（语义 + 全文合并排序）
  async hybridSearch(query: string, opts?: SearchOptions): Promise<SearchResult[]> {
    const [semanticResults, fulltextResults] = await Promise.all([
      this.semanticSearch(query, opts?.limit ?? 20),
      this.fulltextSearch(query, opts?.limit ?? 20),
    ]);

    // 合并去重并重新排序
    const merged = mergeSearchResults(semanticResults, fulltextResults);
    return merged.slice(0, opts?.limit ?? 10);
  }

  // RAG 检索注入
  async ragRetrieve(query: string, topK: number = 5): Promise<KnowledgeCard[]> {
    const results = await this.hybridSearch(query, { limit: topK, threshold: 0.7 });
    return results.map(r => r.card);
  }
}

// 余弦相似度计算
function cosineSimilarity(a: number[], b: number[]): number {
  let dotProduct = 0;
  let normA = 0;
  let normB = 0;
  for (let i = 0; i < a.length; i++) {
    dotProduct += a[i] * b[i];
    normA += a[i] * a[i];
    normB += b[i] * b[i];
  }
  return dotProduct / (Math.sqrt(normA) * Math.sqrt(normB));
}
```

```typescript
// main/services/knowledge/AutoAccumulator.ts

class AutoAccumulator {
  // Agent 完成工作后调用
  async evaluateForKnowledge(
    sessionId: string,
    projectId: string,
    workSummary: string
  ): Promise<void> {
    // 1. 调用 LLM 评估是否有值得记住的内容
    const prompt = `Evaluate if this work session produced knowledge worth saving.

Work summary: ${workSummary}

Check if any of these apply:
- Solved a complex problem with a reusable solution
- Discovered a useful code pattern
- Made an important architectural decision
- Encountered and resolved a tricky bug/gotcha

If worth saving, respond in JSON:
{ "worthSaving": true, "title": "...", "content": "...", "category": "...", "tags": [...] }
Otherwise: { "worthSaving": false }`;

    const result = await pi.prompt(prompt, { model: getCheapestModel() });
    const parsed = JSON.parse(result.text);

    if (parsed.worthSaving) {
      // 2. 提示用户确认
      const accepted = await suggestSaveKnowledge(
        parsed.title,
        parsed.content,
        parsed.category
      );

      if (accepted) {
        // 3. 用户确认后保存
        await this.knowledgeBase.addCard({
          title: parsed.title,
          content: parsed.content,
          category: parsed.category,
          tags: parsed.tags || [],
          source: "auto",
          sourceSessionId: sessionId,
          sourceProjectId: projectId,
        });
      }
    }
  }
}
```

```typescript
async function fetchUrlAndSummarize(url: string): Promise<{
  title: string;
  summary: string;
  content: string;
}> {
  // 1. 抓取网页内容
  const response = await fetch(url);
  const html = await response.text();

  // 2. 提取正文（去除导航/广告等）
  const { title, content } = extractReadableContent(html);

  // 3. 调用 LLM 生成摘要
  const prompt = `Summarize this web page content in 3-5 sentences.

Title: ${title}
Content: ${content.slice(0, 10000)}

Provide a concise summary that captures the key points.`;

  const result = await pi.prompt(prompt, { model: getCheapestModel() });

  return {
    title,
    summary: result.text,
    content,
  };
}
```

## 备注

- 知识库使用 SQLite（`~/.agentbuddy/data/knowledge.db`）存储卡片和向量
- RAG 检索注入集成到 ContextBudgetManager 的 knowledgeRAG 预算分配（8%, ~10000 tokens）
- 知识库使用 on-demand 加载策略——每次查询时按需注入，非全量加载
- Embedding 模型默认使用 `text-embedding-3-small`，可通过设置配置其他模型
- 本功能依赖 F4.1 记忆系统（记忆系统提供项目/用户上下文，知识库提供 RAG 检索增强）
