# F1.8 — 模型分配与会话即时覆盖

> **Phase**: Phase 1 — 基础底座 + 代码安全
> **Priority**: P1
> **Status**: In Progress
> **Dependencies**: F1.7 (Provider 管理面板)

## 概述

模型分配面板允许用户为每个 Agent 独立配置 Chat Model、Vision Model 和 Thinking Level。与 Provider 管理面板（F1.7）不同，模型分配面板关注的是"使用哪个模型"而非"有哪些 Provider 可用"。该面板将 F1.2 中定义的模型路由和 Per-Agent 分配能力以可视化 UI 呈现。

## V2 需求调整：会话即时覆盖

设置面板继续管理 Agent 的**默认** Chat/Vision/Thinking 分配。Agent Composer 另提供当前 `WorkSession` 的即时覆盖：用户可在不修改 Agent 定义或全局设置的前提下选择本会话模型和 Thinking；清除覆盖后立即回到 Agent 默认分配。顶部上下文栏与 Composer 必须展示实际生效值和覆盖来源。

模型选择不是独立聊天设置，而是当前开发任务的执行上下文。顶部显示“Agent 默认”或“会话覆盖”来源；当 Provider/模型不可用时必须阻止发送并说明修复路径。Vision 模型仍由 F1.2 根据图片附件路由，不能因 Composer 的文字模型覆盖而绕过图片能力校验。

### V2 验收（首轮实现进度）

- [x] Composer 可打开当前会话模型选择器，列出当前 Agent 可用的 Provider/Model 和 Thinking 选项。
- [x] 保存会话覆盖不改写 `ModelAssignment` 默认值，也不影响其他会话。
- [x] 清除会话覆盖后，下一次 prompt 使用当前 Agent 默认 Chat/Vision/Thinking 分配。
- [x] 会话模型覆盖由主进程持久化，重启和重新打开会话后保持一致。
- [ ] 顶部上下文栏与 Composer 显示当前模型、Thinking、是否覆盖和 Vision 路由结果。
- [ ] Provider/模型被移除或不可用时，覆盖自动失效并提示用户选择有效模型；不得静默发送到空模型。

面板按 Agent 分组展示——顶部 Agent 选择器切换当前编辑的 Agent，下方配置区包含 Chat Model 选择（Provider + Model 两级下拉）、Vision Model 选择（可选，含"不配置"选项）、以及三个行为开关（Auto-switch on image / Fallback to chat for images / Retry on provider error）。Thinking Level 使用一个四档滑块选择器（off/low/medium/high）。

保存配置后，系统自动重新初始化对应 Agent 的 AgentSession（通过 F1.3 的 `setModel` 方法），确保模型更改立即生效。用户在下拉框中只能选择已在 F1.7 中添加并验证的 Provider 及其下的模型。

## 当前实现范围

- 模型设置面板复用 F1.1 Provider 列表，支持默认 Agent 与已保存 Agent 的独立配置。
- 保存、重置和删除 Provider 后的引用清理由主进程的模型配置存储处理；删除后的前端即时提示仍待补充。
- 成功状态使用面板内反馈，尚未接入全局 Toast 或自动关闭行为。

## 技术设计

### 数据模型

```typescript
// 模型分配（与 F1.2 共享类型）
interface ModelAssignment {
  chat: {
    providerId: string;
    modelId: string;
  };
  vision?: {
    providerId: string;
    modelId: string;
  };
  thinkingLevel: "off" | "low" | "medium" | "high";
  autoSwitchOnImage: boolean;
  fallbackToChatForImages: boolean;
  retryOnProviderError: boolean;
}

// 下拉选项数据结构
interface ProviderOption {
  id: string;
  name: string;
  type: ProviderType;
  status: ProviderStatus;
}

interface ModelOption {
  id: string;
  name: string;
  contextWindow?: number;
  supportsVision?: boolean;
}

// 配置保存请求
interface SaveModelAssignmentRequest {
  agentId: string;
  assignment: ModelAssignment;
}
```

### IPC 通道

| 通道 | 方向 | 参数 | 返回值 | 说明 |
|------|------|------|--------|------|
| `model:get-assignments` | invoke | 无 | `Record<string, ModelAssignment>` | 获取所有 Agent 的模型分配 |
| `model:save-assignment` | invoke | `SaveModelAssignmentRequest` | `void` | 保存并应用 Agent 的模型分配 |
| `model:reset-assignment` | invoke | `{ agentId: string }` | `void` | 重置为默认值 |
| `provider:list` | invoke | 无 | `ProviderConfig[]` | 获取 Provider 列表（复用 F1.1） |

### 关键实现逻辑

#### 面板主组件

```tsx
// renderer/src/components/settings/ModelAssignmentPanel.tsx

import React, { useState, useEffect, useCallback } from "react";
import { Save, RotateCcw } from "lucide-react";

const THINKING_LEVELS = [
  { value: "off", label: "关闭", description: "直接执行，不显示思考过程" },
  { value: "low", label: "低", description: "简要推理" },
  { value: "medium", label: "中", description: "适度推理（推荐）" },
  { value: "high", label: "高", description: "深度推理，消耗更多 tokens" },
] as const;

export const ModelAssignmentPanel: React.FC = () => {
  const [selectedAgentId, setSelectedAgentId] = useState("default");
  const [assignments, setAssignments] = useState<Record<string, ModelAssignment>>({});
  const [isDirty, setIsDirty] = useState(false);
  const [saving, setSaving] = useState(false);

  const providers = useProviderStore(s => s.providers);
  const agents = useAgentStore(s => s.agents);

  // 当前编辑的配置
  const current = assignments[selectedAgentId] || DEFAULT_ASSIGNMENT;

  // 加载配置
  useEffect(() => {
    loadAssignments();
  }, []);

  const loadAssignments = async () => {
    const result = await window.electronAPI.getModelAssignments();
    setAssignments(result);
  };

  // 更新单个字段
  const update = <K extends keyof ModelAssignment>(
    key: K,
    value: ModelAssignment[K]
  ) => {
    setAssignments(prev => ({
      ...prev,
      [selectedAgentId]: {
        ...prev[selectedAgentId],
        [key]: value,
      },
    }));
    setIsDirty(true);
  };

  // 更新 chat.vision 子字段
  const updateModelField = (
    target: "chat" | "vision",
    field: "providerId" | "modelId",
    value: string
  ) => {
    setAssignments(prev => ({
      ...prev,
      [selectedAgentId]: {
        ...prev[selectedAgentId],
        [target]: {
          ...prev[selectedAgentId][target],
          [field]: value,
        },
      },
    }));
    setIsDirty(true);
  };

  // 获取选中 Provider 的模型列表
  const getModelsForProvider = useCallback((providerId: string): ModelOption[] => {
    const provider = providers.find(p => p.id === providerId);
    return provider?.models.map(m => ({
      id: m.id,
      name: m.id,
      contextWindow: m.contextWindow,
      supportsVision: m.supportsVision,
    })) || [];
  }, [providers]);

  // 获取 Provider 选项列表
  const providerOptions: ProviderOption[] = providers
    .filter(p => p.status !== "error")
    .map(p => ({ id: p.id, name: p.name, type: p.type, status: p.status }));

  // 选中的 Chat Provider 的模型
  const chatModels = getModelsForProvider(current.chat.providerId);
  const visionModels = current.vision
    ? getModelsForProvider(current.vision.providerId)
    : [];

  // 保存
  const handleSave = async () => {
    setSaving(true);
    try {
      await window.electronAPI.saveModelAssignment({
        agentId: selectedAgentId,
        assignment: current,
      });
      setIsDirty(false);
      toast.success(`${agents.find(a => a.id === selectedAgentId)?.name} 的模型配置已保存`);
    } catch (error: any) {
      toast.error(`保存失败: ${error.message}`);
    } finally {
      setSaving(false);
    }
  };

  // 重置
  const handleReset = () => {
    setAssignments(prev => ({
      ...prev,
      [selectedAgentId]: { ...DEFAULT_ASSIGNMENT },
    }));
    setIsDirty(true);
  };

  return (
    <div className="p-6">
      {/* Agent 选择器 */}
      <div className="mb-6">
        <label className="text-xs font-medium text-gray-500 mb-2 block">
          选择 Agent
        </label>
        <div className="flex gap-1 flex-wrap">
          {agents.map(agent => (
            <button
              key={agent.id}
              onClick={() => setSelectedAgentId(agent.id)}
              className={cn(
                "px-3 py-1.5 rounded-lg text-sm transition-colors",
                selectedAgentId === agent.id
                  ? "bg-blue-600 text-white"
                  : "bg-gray-100 dark:bg-gray-800 text-gray-700 dark:text-gray-300 hover:bg-gray-200"
              )}
            >
              {agent.name}
            </button>
          ))}
        </div>
      </div>

      {providers.length === 0 ? (
        <div className="text-center py-8 text-gray-400 text-sm">
          暂无可用的 Provider，
          <button
            onClick={() => navigateToSettings("providers")}
            className="text-blue-600 hover:underline"
          >
            前往配置
          </button>
        </div>
      ) : (
        <div className="space-y-6">
          {/* Chat Model 选择 */}
          <section>
            <h3 className="text-sm font-medium mb-3">Chat Model</h3>
            <div className="grid grid-cols-2 gap-3">
              <FormField label="Provider">
                <Select
                  value={current.chat.providerId}
                  onChange={v => {
                    updateModelField("chat", "providerId", v);
                    // 切换 Provider 时清空 modelId
                    updateModelField("chat", "modelId", "");
                  }}
                  options={providerOptions.map(p => ({
                    value: p.id,
                    label: `${p.name} (${p.type})`,
                  }))}
                  placeholder="选择 Provider"
                />
              </FormField>
              <FormField label="Model">
                <Select
                  value={current.chat.modelId}
                  onChange={v => updateModelField("chat", "modelId", v)}
                  options={chatModels.map(m => ({
                    value: m.id,
                    label: m.id,
                    hint: m.contextWindow ? `${(m.contextWindow / 1000).toFixed(0)}K 上下文` : undefined,
                  }))}
                  placeholder={current.chat.providerId ? "选择模型" : "请先选择 Provider"}
                  disabled={!current.chat.providerId}
                />
              </FormField>
            </div>
          </section>

          {/* Vision Model 选择 */}
          <section>
            <div className="flex items-center justify-between mb-3">
              <h3 className="text-sm font-medium">Vision Model</h3>
              <Switch
                checked={!!current.vision}
                onChange={enabled => {
                  if (enabled) {
                    update("vision", { providerId: "", modelId: "" });
                  } else {
                    update("vision", undefined);
                  }
                }}
              />
            </div>

            {current.vision ? (
              <div className="grid grid-cols-2 gap-3">
                <FormField label="Provider">
                  <Select
                    value={current.vision.providerId}
                    onChange={v => {
                      updateModelField("vision", "providerId", v);
                      updateModelField("vision", "modelId", "");
                    }}
                    options={providerOptions.map(p => ({ value: p.id, label: p.name }))}
                    placeholder="选择 Provider"
                  />
                </FormField>
                <FormField label="Model">
                  <Select
                    value={current.vision.modelId}
                    onChange={v => updateModelField("vision", "modelId", v)}
                    options={visionModels.map(m => ({ value: m.id, label: m.id }))}
                    placeholder={current.vision.providerId ? "选择模型" : "请先选择 Provider"}
                    disabled={!current.vision.providerId}
                  />
                </FormField>
              </div>
            ) : (
              <p className="text-sm text-gray-400">
                不配置 Vision Model 时，图片将由 Chat Model 处理
                {current.fallbackToChatForImages ? "" : "（将被拒绝）"}
              </p>
            )}
          </section>

          {/* 行为开关 */}
          <section>
            <h3 className="text-sm font-medium mb-3">行为设置</h3>
            <div className="space-y-3">
              <SwitchRow
                label="图片自动切换"
                description="检测到图片时自动切换到 Vision Model"
                checked={current.autoSwitchOnImage}
                onChange={v => update("autoSwitchOnImage", v)}
              />
              <SwitchRow
                label="回退到 Chat Model"
                description="未配置 Vision Model 时使用 Chat Model 处理图片"
                checked={current.fallbackToChatForImages}
                onChange={v => update("fallbackToChatForImages", v)}
              />
              <SwitchRow
                label="错误重试"
                description="Provider 返回错误时自动重试一次"
                checked={current.retryOnProviderError}
                onChange={v => update("retryOnProviderError", v)}
              />
            </div>
          </section>

          {/* Thinking Level */}
          <section>
            <h3 className="text-sm font-medium mb-3">推理深度</h3>
            <div className="grid grid-cols-4 gap-2">
              {THINKING_LEVELS.map(level => (
                <button
                  key={level.value}
                  onClick={() => update("thinkingLevel", level.value)}
                  className={cn(
                    "p-3 rounded-lg border-2 text-center transition-all",
                    current.thinkingLevel === level.value
                      ? "border-blue-500 bg-blue-50 dark:bg-blue-900/20"
                      : "border-gray-200 dark:border-gray-700 hover:border-gray-300"
                  )}
                >
                  <div className="text-sm font-medium">{level.label}</div>
                  <div className="text-xs text-gray-400 mt-1">{level.description}</div>
                </button>
              ))}
            </div>
          </section>

          {/* 操作栏 */}
          <div className="flex items-center gap-3 pt-4 border-t border-gray-200 dark:border-gray-700">
            <Button
              onClick={handleReset}
              variant="ghost"
              size="sm"
              icon={<RotateCcw size={14} />}
            >
              重置为默认
            </Button>
            <div className="flex-1" />
            <Button
              onClick={handleSave}
              loading={saving}
              disabled={!isDirty}
              variant="primary"
              size="sm"
              icon={<Save size={14} />}
            >
              保存
            </Button>
          </div>
        </div>
      )}
    </div>
  );
};

// 开关行组件
const SwitchRow: React.FC<{
  label: string;
  description: string;
  checked: boolean;
  onChange: (v: boolean) => void;
}> = ({ label, description, checked, onChange }) => (
  <div className="flex items-center justify-between py-2">
    <div>
      <div className="text-sm">{label}</div>
      <div className="text-xs text-gray-400">{description}</div>
    </div>
    <Switch checked={checked} onChange={onChange} />
  </div>
);

const DEFAULT_ASSIGNMENT: ModelAssignment = {
  chat: { providerId: "", modelId: "" },
  thinkingLevel: "off",
  autoSwitchOnImage: true,
  fallbackToChatForImages: false,
  retryOnProviderError: true,
};
```

## UI/UX 规范

- **Agent 选择器**：横向标签按钮，选中蓝色背景白色文字，未选中灰色
- **Provider 选择**：标准下拉，显示 Provider 名称 + 类型后缀，按连接状态排序（connected 优先）
- **Model 选择**：下拉选项附加上下文大小提示（如 "GPT-4o · 128K 上下文"）
- **开关行**：全宽可点击，左侧标签+描述，右侧 Switch 组件
- **Thinking Level**：四格卡片选择器，选中蓝色边框 + 蓝色浅背景
- **无 Provider 时**：EmptyState 引导 + 链接跳转到 Provider 管理面板

## 测试要点
