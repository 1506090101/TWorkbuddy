# F1.17 设置中心：外观与快捷键

> **Phase**: Phase 1 - 基础底座与代码安全  
> **Priority**: P2  
> **Status**: V2 实现中  
> **Dependencies**: F0.2、F0.4、F1.16

## V2 需求调整

设置中心服务于紧凑开发工作台的个人偏好，而非独立配置产品。主题、字体和工作台快捷键必须即时预览、重启后恢复，并与 F1.16 的命令注册表使用同一事实来源。它们是 renderer 的非敏感 UI 偏好，沿用已有 `uiStore` 持久化；Provider、密钥、权限、项目和 Agent 配置仍由主进程处理。

V1 草案中“electron-store 保存所有外观偏好”、注册任意全局系统快捷键、修改 Git/工具/变更审批快捷键的方案不适用 V2。首轮只允许改写已有工作台全局动作，避免抢占 Composer 文本输入、复制粘贴、撤销与变更审查焦点域。

## 首轮实现

- 外观页提供浅色、深色、跟随系统三种主题；`useTheme` 继续响应系统色彩变化。
- UI 字体为 12-18px、代码字体为 12-20px；设置写入 `--font-size-base`、`--font-size-code` 与 `--font-code` CSS token，实时影响工作台和代码展示。
- 支持 JetBrains Mono、Fira Code、Cascadia Code、Source Code Pro 与自定义代码字体名称；语言偏好保留在同一外观页。
- 快捷键页只列出命令面板、新建任务、聚焦 Composer、上/下一任务、打开设置六项全局动作。
- 点击当前按键进入录制；绑定必须含 Ctrl/Cmd 或 Alt，拒绝单修饰键以及复制、粘贴、剪切、全选、撤销、重做。
- 覆盖、冲突、恢复默认都持久化到 `uiStore`；App 全局监听器按覆盖后的注册表立即处理事件，命令面板同步显示当前组合键。

## 验收

- [x] 三种主题和系统主题监听可即时应用并持久化。
- [x] UI/代码字体大小、代码字体族由 CSS token 即时预览并持久化。
- [x] 设置页列出受支持的全局工作台快捷键，可搜索、录制、显示覆盖值并恢复默认。
- [x] 重复绑定显示冲突状态；系统编辑快捷键和无修饰键录制被拒绝。
- [x] F1.16 全局监听器和命令面板使用同一默认/覆盖绑定。
- [ ] 自定义快捷键导入导出、快捷键方案、Vim 模式、系统级全局快捷键及修改审查快捷键需在后续 Feature 单独设计。

## 验证

桌面端在设置页切换深色主题，UI/代码字体分别调整到 16px/17px 并选择 Fira Code；`<html>` 的 `dark` class 和三个 CSS token 均即时更新，`uiStore` 保存对应偏好。快捷键页展示六项全局动作、录制状态、冲突和恢复默认；验收后恢复系统主题、14px 字号与默认绑定。
