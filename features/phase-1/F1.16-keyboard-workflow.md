# F1.16 键盘优先工作流

> **Phase**: Phase 1 - 基础底座与代码安全  
> **Priority**: P1  
> **Status**: V2 实现中  
> **Dependencies**: F0.3、F1.3、F1.5、F2.1、F2.4

## V2 需求调整

键盘能力服务于 Agent 工作台的连续任务流，而不是为传统聊天页堆叠快捷键。用户应能不离开键盘地新建或切换任务、聚焦 Composer、打开当前任务的操作面板，并以斜杠命令组织 Agent、模型、目标、项目和附件上下文。

V1 草案中的 Git commit、直接调用任意工具、Skill 加载、Vim 模式、快捷键自定义和所有 diff 快捷键不属于首轮。文件写入、命令和变更审批仍必须遵循 F1.6/F1.11-F1.13 的权限与焦点边界；不得为了快捷键绕过确认，也不得劫持复制、粘贴、撤销等系统编辑行为。

## 首轮实现

- `Ctrl/Cmd+Shift+P` 打开命令面板；`Esc` 关闭。面板支持模糊筛选、上下键、Enter、鼠标选择和最近使用的操作排序。
- 首批命令覆盖：新建任务、上一/下一任务、聚焦 Composer、添加附件、设置目标、选择项目、切换右侧上下文、归档当前任务和打开设置。
- `Ctrl/Cmd+N` 新建任务，`Ctrl/Cmd+K` 聚焦 Composer，`Ctrl/Cmd+Tab`/`Ctrl/Cmd+Shift+Tab` 切换任务，`Ctrl/Cmd+,` 打开设置。快捷键只在工作台全局命令中处理，避免截获 Composer 的 Enter、Shift+Enter、复制、撤销和变更审查快捷键。
- Composer 在输入首字符为 `/` 时显示命令建议；支持 `/agent <名称或 id>`、`/model <Provider/模型>`、`/goal`、`/project` 和 `/files`。选项可用上下键和 Enter 补全，带参数的命令在 Enter 时执行。
- 快捷键与斜杠操作调用已有 WorkSession、Agent、Provider、目标和项目 IPC，执行失败显示在 Composer 或不关闭的命令面板中。

## 数据与边界

`CommandItem` 是 renderer 内的命令描述：标识、名称、分类、关键字、快捷键、启用条件和回调。最近命令只存入本地 UI 偏好，不包含项目内容、提示词或密钥。斜杠命令不直接调用受权限约束的工具；它们只改变 Composer 上下文或打开现有的用户选择流程。

## 验收

- [x] 命令面板在 `Ctrl/Cmd+Shift+P` 后可立即聚焦，支持相关性排序、最近命令、键盘导航和关闭。
- [x] 新建、切换任务、聚焦 Composer、右侧面板、项目、目标、附件、设置和归档均可从面板执行，并对无活动任务的命令禁用。
- [x] 全局新建、聚焦、切换任务和设置快捷键可用，且不破坏 Composer 编辑和变更审查快捷键。
- [x] `/` 菜单支持过滤、方向键、Enter 和 Escape；五项 V2 命令均能复用已有状态/IPC 完成操作或给出明确错误。
- [x] Palette 与 Composer 在无 Provider、无项目、无 Agent 匹配、加载/执行失败时保持可用且状态明确。
- [ ] 复杂 Git、工具直接调用、Vim 模式、快捷键自定义及新的审批快捷键由后续 Feature 单独设计。

## 验证

桌面端验证了 `Ctrl+Shift+P` 打开、搜索并键盘执行“新建任务”，最近命令随即置顶；验证了 `Ctrl+K` 聚焦 Composer、`Ctrl+Tab` 切换任务。Composer 成功执行 `/goal`、`/agent default`、`/model ttt/deepseek-v4-flash` 与 `/files`（选择后移除 `package.json`）；`/project` 复用现有目录选择 IPC，仅在用户确认系统目录选择后更新项目。
