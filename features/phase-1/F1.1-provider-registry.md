# F1.1 — 多 Provider 注册表与配置

> **Phase**: Phase 1 — 基础底座 + 代码安全
> **Priority**: P0
> **Status**: Completed
> **Dependencies**: F0.5 (IPC 通信层), F0.6 (状态管理)

## 概述

本功能实现 Agent Buddy 的 LLM Provider 注册表系统，允许用户添加、配置和管理任意数量的 LLM 服务提供商实例。作为整个模型配置层的基石，该功能直接决定了应用的"模型自由度"——用户不会被困在某一厂商中，可以自由组合 OpenAI、Anthropic、DeepSeek 等多个厂商的模型，甚至可以添加多个同类中转站实例。

Provider 管理完全在主进程侧运行，通过 `ProviderManager` 类管理注册表，保证 API Key 等敏感信息不会泄露到渲染进程。每个 Provider 实例的配置（包括加密后的 API Key）通过 `electron-store` 持久化，配置在应用启动时自动加载，并实时注入到 Pi SDK 的运行环境中。

用户可以通过 "Auto-detect" 按钮探测可用模型列表，通过 "Test" 按钮验证连接。黄色（untested）和红色（error）状态指示器让用户一目了然地了解每个 Provider 的健康状况。该功能与 F1.7（Provider 管理面板 UI）和 F1.8（模型分配面板）深度配合，共同构成完整的模型配置工作流。

## 验收标准

### 功能验收
- [x] 支持 7 种 Provider 类型：`openai` / `anthropic` / `deepseek` / `gemini` / `mistral` / `openrouter` / `custom`
- [x] 每个 Provider 实例包含完整的配置字段：id, name, type, apiKey, baseURL, models[], status
- [x] 用户可添加多个同类 Provider（如多个 OpenAI 中转站），互不冲突
- [x] `detectModels()` 调用 `/models` 接口，正确解析并返回模型列表
- [x] `testConnection()` 发送简单 chat completion 请求，返回成功/失败及耗时

- [x] 配置持久化到 `~/.agentbuddy/config/providers.json`

## 技术设计

### 数据模型

```typescript
// Provider 类型枚举
type ProviderType = "openai" | "anthropic" | "deepseek" | "gemini" | "mistral" | "openrouter" | "custom";

// Provider 连接状态
type ProviderStatus = "connected" | "untested" | "error";

// 单个 Provider 配置
interface ProviderConfig {
  id: string;                    // 唯一标识
  name: string;                  // 显示名称
  type: ProviderType;            // Provider 类型
  apiKey: string;                // API 密钥（加密存储）
  baseURL?: string;              // 自定义地址（留空=官方地址）
  models: ModelInfo[];           // 可用模型列表
  status: ProviderStatus;        // 连接状态
  statusMessage?: string;        // 状态详细信息（错误时）
  createdAt: number;
  updatedAt: number;
}

// 模型信息
interface ModelInfo {
  id: string;                    // 模型 ID，如 "gpt-4o"
  name: string;                  // 显示名称，如 "GPT-4o"
  contextWindow?: number;        // 上下文窗口大小
  supportsVision?: boolean;      // 是否支持视觉
  supportsStreaming?: boolean;   // 是否支持流式
  description?: string;          // 模型描述
}

// electron-store 持久化格式
interface ProviderStore {
  providers: ProviderConfig[];
  version: number;
}
```

### IPC 通道

| 通道 | 方向 | 参数 | 返回值 | 说明 |
|------|------|------|--------|------|
| `provider:list` | invoke | 无 | `ProviderConfig[]` | 获取所有 Provider 列表（apiKey 脱敏） |
| `provider:create` | invoke | `Omit<ProviderConfig, 'id' \| 'createdAt' \| 'updatedAt' \| 'status'>` | `ProviderConfig` | 创建新 Provider 实例 |
| `provider:update` | invoke | `{ id: string; changes: Partial<ProviderConfig> }` | `ProviderConfig` | 更新 Provider 配置 |
| `provider:delete` | invoke | `{ id: string }` | `void` | 删除 Provider |
| `provider:detect-models` | invoke | `{ providerId: string }` | `ModelInfo[]` | 探测可用模型列表 |
| `provider:test-connection` | invoke | `{ providerId: string }` | `{ success: boolean; duration: number; message: string }` | 测试连接 |
| `provider:import` | invoke | `{ data: ProviderConfig[] }` | `ProviderConfig[]` | 批量导入 Provider 配置 |

### 组件结构

本功能无渲染进程直接组件，由 `ProviderManager` 类在主进程管理，UI 在 F1.7 中实现。

### 关键实现逻辑

#### ProviderManager 核心实现

```typescript
// main/providers/provider-manager.ts

import { safeStorage } from "electron";
import Store from "electron-store";

interface ProviderStore {
  providers: ProviderConfig[];
  version: number;
}

class ProviderManager {
  private store: Store<ProviderStore>;
  private providers: Map<string, ProviderConfig> = new Map();

  constructor() {
    this.store = new Store<ProviderStore>({
      name: "providers",
      defaults: { providers: [], version: 1 },
      encryptionKey: "agent-buddy-providers", // electron-store 内置加密
    });
    this.loadProviders();
  }

  // 加载并解密所有 Provider 配置
  private loadProviders(): void {
    const stored = this.store.get("providers");
    for (const p of stored) {
      // 解密 apiKey（如果启用了 safeStorage）
      if (safeStorage.isEncryptionAvailable()) {
        try {
          p.apiKey = safeStorage.decryptString(Buffer.from(p.apiKey, "base64"));
        } catch {
          // 兼容明文存储（迁移阶段）
        }
      }
      this.providers.set(p.id, p);
    }
  }

  // 保存并加密 Provider
  private saveProvider(config: ProviderConfig): void {
    const saved = { ...config };
    // 加密 apiKey
    if (safeStorage.isEncryptionAvailable()) {
      saved.apiKey = safeStorage.encryptString(config.apiKey).toString("base64");
    }
    this.providers.set(config.id, saved);
    this.persistToStore();
  }

  // 持久化到 electron-store
  private persistToStore(): void {
    this.store.set("providers", Array.from(this.providers.values()));
  }

  // 获取模型配置（注入环境变量）
  getModel(providerId: string, modelId: string): {
    modelId: string;
    envVars: Record<string, string>;
  } {
    const provider = this.providers.get(providerId);
    if (!provider) throw new Error(`Provider "${providerId}" not found`);

    const envVars: Record<string, string> = {};

    // 根据 Provider 类型注入对应的环境变量
    switch (provider.type) {
      case "openai":
        envVars.OPENAI_API_KEY = provider.apiKey;
        break;
      case "anthropic":
        envVars.ANTHROPIC_API_KEY = provider.apiKey;
        break;
      case "deepseek":
        envVars.DEEPSEEK_API_KEY = provider.apiKey;
        break;
      case "gemini":
        envVars.GEMINI_API_KEY = provider.apiKey;
        break;
      case "mistral":
        envVars.MISTRAL_API_KEY = provider.apiKey;
        break;
      case "openrouter":
        envVars.OPENROUTER_API_KEY = provider.apiKey;
        break;
      case "custom":
        envVars.OPENAI_API_KEY = provider.apiKey;
        break;
    }

    if (provider.baseURL) {
      envVars.OPENAI_BASE_URL = provider.baseURL; // 或根据 type 设置对应 BASE_URL
    }

    return {
      modelId: this.resolveModelId(provider.type, modelId, provider.baseURL),
      envVars,
    };
  }

  // 解析模型 ID（处理 Provider 特定的命名前缀）
  private resolveModelId(type: ProviderType, modelId: string, baseURL?: string): string {
    // 对于 custom/provider 中转，直接使用原始 modelId
    if (type === "custom" || baseURL) {
      return modelId;
    }
    return modelId;
  }

  // 探测模型列表
  async detectModels(providerId: string): Promise<ModelInfo[]> {
    const provider = this.providers.get(providerId);
    if (!provider) throw new Error("Provider not found");

    const baseURL = this.getBaseURL(provider);
    const url = `${baseURL}/models`;

    const response = await fetch(url, {
      headers: {
        Authorization: `Bearer ${provider.apiKey}`,
        "Content-Type": "application/json",
      },
    });

    if (!response.ok) {
      throw new Error(`Failed to fetch models: ${response.statusText}`);
    }

    const data = await response.json();
    return this.parseModelList(data, provider.type);
  }

  // 测试连接
  async testConnection(providerId: string): Promise<{
    success: boolean;
    duration: number;
    message: string;
  }> {
    const start = Date.now();
    const provider = this.providers.get(providerId);
    if (!provider) throw new Error("Provider not found");

    try {
      const baseURL = this.getBaseURL(provider);
      const model = provider.models[0]?.id || "gpt-3.5-turbo";

      const response = await fetch(`${baseURL}/chat/completions`, {
        method: "POST",
        headers: {
          Authorization: `Bearer ${provider.apiKey}`,
          "Content-Type": "application/json",
        },
        body: JSON.stringify({
          model,
          messages: [{ role: "user", content: "ping" }],
          max_tokens: 1,
        }),
        signal: AbortSignal.timeout(10000),
      });

      const duration = Date.now() - start;

      if (response.ok) {
        return { success: true, duration, message: `连接成功 (${duration}ms)` };
      } else {
        return {
          success: false,
          duration,
          message: `连接失败: ${response.status} ${response.statusText}`,
        };
      }
    } catch (error: any) {
      const duration = Date.now() - start;
      return {
        success: false,
        duration,
        message: `连接失败: ${error.message}`,
      };
    }
  }

  // 获取 Base URL
  private getBaseURL(provider: ProviderConfig): string {
    if (provider.baseURL) return provider.baseURL;

    const urls: Record<ProviderType, string> = {
      openai: "https://api.openai.com/v1",
      anthropic: "https://api.anthropic.com/v1",
      deepseek: "https://api.deepseek.com/v1",
      gemini: "https://generativelanguage.googleapis.com/v1beta",
      mistral: "https://api.mistral.ai/v1",
      openrouter: "https://openrouter.ai/api/v1",
      custom: "",
    };
    return urls[provider.type] || "";
  }

  // 解析模型列表（不同 Provider 格式不同）
  private parseModelList(data: any, type: ProviderType): ModelInfo[] {
    // 不同 Provider 的 /models 响应格式各异
    const rawModels = data.data || data.models || data || [];

    return rawModels.map((m: any) => ({
      id: m.id || m.name,
      name: m.id || m.name,
      contextWindow: m.context_window || m.contextWindow,
      supportsVision: m.supports_vision || m.supportsVision || false,
      supportsStreaming: m.supports_streaming ?? true,
      description: m.description || "",
    }));
  }

  // IPC 事件处理器注册
  registerIpcHandlers(): void {
    ipcMain.handle("provider:list", () => {
      // 返回脱敏后的列表
      return Array.from(this.providers.values()).map(p => ({
        ...p,
        apiKey: p.apiKey ? "••••••••" : "",
      }));
    });

    ipcMain.handle("provider:create", (_event, data) => {
      const config: ProviderConfig = {
        ...data,
        id: `provider_${Date.now()}`,
        status: "untested",
        createdAt: Date.now(),
        updatedAt: Date.now(),
      };
      this.saveProvider(config);
      return config;
    });

    ipcMain.handle("provider:update", (_event, { id, changes }) => {
      const existing = this.providers.get(id);
      if (!existing) throw new Error(`Provider "${id}" not found`);
      const updated = { ...existing, ...changes, updatedAt: Date.now() };
      this.saveProvider(updated);
      return updated;
    });

    ipcMain.handle("provider:delete", (_event, { id }) => {
      this.providers.delete(id);
      this.persistToStore();
    });

    ipcMain.handle("provider:detect-models", async (_event, { providerId }) => {
      return this.detectModels(providerId);
    });

    ipcMain.handle("provider:test-connection", async (_event, { providerId }) => {
      const result = await this.testConnection(providerId);
      // 更新状态
      const provider = this.providers.get(providerId);
      if (provider) {
        provider.status = result.success ? "connected" : "error";
        provider.statusMessage = result.message;
        this.persistToStore();
      }
      return result;
    });
  }
}

// 单例
export const providerManager = new ProviderManager();
```

## UI/UX 规范

本功能的 UI 在 F1.7（设置中心 — Provider 管理面板）中实现。本功能提供的 IPC 接口返回的数据格式需与 UI 组件配合：

- `provider:list` 返回的列表需标记每个 Provider 的状态颜色（green/yellow/red）
- API Key 字段通过 IPC 返回时统一脱敏为 `••••••••`

## 备注

- `ProviderManager` 采用单例模式，在主进程生命周期内全局唯一
- `electron-store` 内置的加密（`encryptionKey`）和 `safeStorage` 是两层加密，双重保护 API Key
- Provider 类型图标和颜色映射在 UI 侧（F1.7）定义，此处只需返回类型枚举
- 该模块是整个模型配置层的基石，F1.2（视觉模型路由）和 F1.3（Pi SDK 集成）都依赖此模块提供的 `getModel()` 方法
