# F1.7 — 设置中心 — Provider 管理面板

> **Phase**: Phase 1 — 基础底座 + 代码安全
> **Priority**: P0
> **Status**: Completed
> **Dependencies**: F1.1 (多 Provider 注册表), F0.4 (UI 组件库)

## 概述

Provider 管理面板是设置中心的核心 Tab 页之一，为用户提供可视化界面来管理所有 LLM Provider 实例。该面板直接操作 F1.1 中 `ProviderManager` 的数据，通过 IPC 通道将用户的增删改操作同步到主进程，并实时展示每个 Provider 的连接状态。

面板包含三个主要区域：左侧的 Provider 列表（带状态指示器），右侧的编辑表单（类型选择、名称、API Key、Base URL、模型列表），以及底部的操作按钮（Auto-detect 模型、Test 连接、保存、删除）。API Key 输入框默认隐藏输入内容，点击切换按钮可显示。模型列表由"Auto-detect"按钮自动填充，也可手动编辑。

该面板与 F1.8（模型分配面板）平级，共同构成 Phase 1 的模型配置工作流：先在 Provider 面板中添加并验证 LLM 服务，再到模型分配面板为 Agent 选择具体模型。

## 验收标准

### 功能验收
- [x] Provider 列表展示：左侧列出所有已添加的 Provider，每行显示名称、类型图标、状态指示器
- [x] 状态指示器颜色：绿色(connected) / 黄色(untested) / 红色(error)
- [x] 点击列表项切换到该 Provider 的编辑视图，右侧表单加载对应数据
- [x] "添加 Provider" 按钮：新建空白表单，类型默认为 OpenAI
- [x] 类型下拉选择：7 种 Provider 类型（OpenAI/Anthropic/DeepSeek/Gemini/Mistral/OpenRouter/Custom）
- [x] API Key 输入框：`type="password"`，右侧有切换显示/隐藏按钮
- [x] Base URL 输入框：Custom 类型必填，其他类型可选（有默认值）
- [x] "Auto-detect" 按钮：调用 `provider:detect-models` IPC，成功后自动填充模型列表
- [x] "Test" 按钮：调用 `provider:test-connection` IPC，显示结果区域（成功/失败+耗时）
- [x] 模型列表支持手动编辑（添加/删除模型行）
- [x] 删除 Provider 前弹出确认对话框
- [x] 保存成功后实时更新状态指示器

### 非功能验收
- [x] 表单校验：名称不能为空、API Key 不能为空、Custom 类型必须填写 Base URL
- [x] 表单未保存修改离开时弹出确认提示
- [ ] Provider 列表支持多选批量删除（可选）

#### Provider 面板主组件

```tsx
// renderer/src/components/settings/ProviderManagementPanel.tsx

import React, { useState, useEffect } from "react";
import { Plus, Trash2, Wifi, WifiOff, AlertCircle, Search } from "lucide-react";
import { useProviderStore } from "../../stores/providerStore";

const PROVIDER_TYPES: { value: ProviderType; label: string; icon: string }[] = [
  { value: "openai", label: "OpenAI", icon: "bot" },
  { value: "anthropic", label: "Anthropic", icon: "bot" },
  { value: "deepseek", label: "DeepSeek", icon: "bot" },
  { value: "gemini", label: "Gemini", icon: "bot" },
  { value: "mistral", label: "Mistral", icon: "bot" },
  { value: "openrouter", label: "OpenRouter", icon: "bot" },
  { value: "custom", label: "Custom (OpenAI 兼容)", icon: "settings" },
];

const STATUS_CONFIG = {
  connected: { color: "bg-green-500", icon: Wifi, label: "已连接" },
  untested: { color: "bg-yellow-500", icon: WifiOff, label: "未测试" },
  error: { color: "bg-red-500", icon: AlertCircle, label: "连接失败" },
};

export const ProviderManagementPanel: React.FC = () => {
  const providers = useProviderStore(s => s.providers);
  const [selectedId, setSelectedId] = useState<string | null>(null);
  const [formData, setFormData] = useState<ProviderFormData>(emptyForm());
  const [isDirty, setIsDirty] = useState(false);
  const [showApiKey, setShowApiKey] = useState(false);
  const [testing, setTesting] = useState(false);
  const [detecting, setDetecting] = useState(false);
  const [testResult, setTestResult] = useState<string | null>(null);

  const isEditing = !!formData.id;

  // 选择 Provider 时加载表单
  useEffect(() => {
    if (!selectedId) return;

    const provider = providers.find(p => p.id === selectedId);
    if (provider) {
      setFormData({
        id: provider.id,
        name: provider.name,
        type: provider.type,
        apiKey: "", // 不加载原始 apiKey（脱敏）
        baseURL: provider.baseURL || "",
        models: provider.models.map(m => ({
          id: m.id,
          contextWindow: m.contextWindow,
          supportsVision: m.supportsVision,
        })),
      });
      setIsDirty(false);
    }
  }, [selectedId, providers]);

  // 测试连接
  const handleTest = async () => {
    if (!selectedId) return;
    setTesting(true);
    setTestResult(null);

    try {
      const result = await window.electronAPI.testProvider(selectedId);
      setTestResult(result.message);
    } catch (error: any) {
      setTestResult(`测试失败: ${error.message}`);
    } finally {
      setTesting(false);
    }
  };

  // 探测模型
  const handleDetect = async () => {
    if (!selectedId) return;
    setDetecting(true);

    try {
      const models = await window.electronAPI.detectModels(selectedId);
      setFormData(prev => ({ ...prev, models }));
      setIsDirty(true);
      toast.success(`探测到 ${models.length} 个模型`);
    } catch (error: any) {
      toast.error(`模型探测失败: ${error.message}`);
    } finally {
      setDetecting(false);
    }
  };

  // 保存
  const handleSave = async () => {
    // 校验
    if (!formData.name.trim()) {
      toast.error("名称不能为空");
      return;
    }
    if (!formData.apiKey.trim() && !isEditing) {
      toast.error("API Key 不能为空");
      return;
    }
    if (formData.type === "custom" && !formData.baseURL.trim()) {
      toast.error("Custom 类型必须填写 Base URL");
      return;
    }

    try {
      if (isEditing) {
        await window.electronAPI.updateProvider(formData.id!, {
          name: formData.name,
          type: formData.type,
          apiKey: formData.apiKey || undefined, // 空表示不更新
          baseURL: formData.baseURL || undefined,
          models: formData.models,
        });
        toast.success("Provider 已更新");
      } else {
        const created = await window.electronAPI.createProvider({
          name: formData.name,
          type: formData.type,
          apiKey: formData.apiKey,
          baseURL: formData.baseURL || undefined,
          models: formData.models,
        });
        setSelectedId(created.id);
        toast.success("Provider 已创建");
      }
      setIsDirty(false);
      setFormData(prev => ({ ...prev, apiKey: "" })); // 清空 API Key
    } catch (error: any) {
      toast.error(`保存失败: ${error.message}`);
    }
  };

  // 删除
  const handleDelete = async () => {
    if (!selectedId) return;

    // 确认对话框
    const confirmed = await showConfirmDialog({
      title: "删除 Provider",
      message: `确定要删除 "${formData.name}" 吗？使用该 Provider 的 Agent 将无法正常工作。`,
      confirmText: "删除",
      danger: true,
    });

    if (!confirmed) return;

    try {
      await window.electronAPI.deleteProvider(selectedId);
      setSelectedId(null);
      setFormData(emptyForm());
      toast.success("Provider 已删除");
    } catch (error: any) {
      toast.error(`删除失败: ${error.message}`);
    }
  };

  return (
    <div className="flex h-full">
      {/* 左侧 Provider 列表 */}
      <div className="w-64 border-r border-gray-200 dark:border-gray-700 p-3 overflow-y-auto">
        <button
          onClick={() => {
            setSelectedId(null);
            setFormData(emptyForm());
            setIsDirty(false);
          }}
          className="w-full flex items-center gap-2 px-3 py-2 rounded-lg
                     bg-blue-600 text-white text-sm hover:bg-blue-700 transition-colors mb-3"
        >
          <Plus size={16} /> 添加 Provider
        </button>

        {providers.map(provider => {
          const status = STATUS_CONFIG[provider.status];
          const StatusIcon = status.icon;
          return (
            <button
              key={provider.id}
              onClick={() => setSelectedId(provider.id)}
              className={cn(
                "w-full flex items-center gap-3 px-3 py-2 rounded-lg text-left text-sm transition-colors mb-1",
                selectedId === provider.id
                  ? "bg-blue-50 dark:bg-blue-900/20 text-blue-700 dark:text-blue-300"
                  : "hover:bg-gray-100 dark:hover:bg-gray-800 text-gray-700 dark:text-gray-300"
              )}
            >
              <StatusIcon size={14} className={status.color.replace("bg-", "text-")} />
              <span className="flex-1 truncate">{provider.name}</span>
              <span className={cn("w-2 h-2 rounded-full", status.color)} />
            </button>
          );
        })}

        {providers.length === 0 && (
          <p className="text-sm text-gray-400 text-center mt-8">
            暂无 Provider，点击上方按钮添加
          </p>
        )}
      </div>

      {/* 右侧编辑区 */}
      <div className="flex-1 p-6 overflow-y-auto">
        {!selectedId && !isDirty ? (
          <div className="flex items-center justify-center h-full text-gray-400 text-sm">
            选择一个 Provider 进行编辑，或点击"添加 Provider"创建新的
          </div>
        ) : (
          <div className="max-w-lg space-y-4">
            {/* 类型选择 */}
            <FormField label="Provider 类型">
              <Select
                value={formData.type}
                onChange={type => {
                  setFormData(prev => ({ ...prev, type, baseURL: "" }));
                  setIsDirty(true);
                }}
                options={PROVIDER_TYPES.map(t => ({
                  value: t.value,
                  label: t.label,
                }))}
              />
            </FormField>

            {/* 名称 */}
            <FormField label="显示名称" required>
              <Input
                value={formData.name}
                onChange={name => {
                  setFormData(prev => ({ ...prev, name }));
                  setIsDirty(true);
                }}
                placeholder="如：我的 OpenAI、中转站 A"
              />
            </FormField>

            {/* API Key */}
            <FormField label="API Key" required={!isEditing} hint="密钥使用系统加密存储">
              <div className="relative">
                <Input
                  type={showApiKey ? "text" : "password"}
                  value={formData.apiKey}
                  onChange={apiKey => {
                    setFormData(prev => ({ ...prev, apiKey }));
                    setIsDirty(true);
                  }}
                  placeholder={isEditing ? "留空则保持原有密钥" : "sk-..."}
                />
                <button
                  onClick={() => setShowApiKey(!showApiKey)}
                  className="absolute right-3 top-1/2 -translate-y-1/2 text-gray-400 hover:text-gray-600"
                >
                  {showApiKey ? <EyeOff size={16} /> : <Eye size={16} />}
                </button>
              </div>
            </FormField>

            {/* Base URL */}
            <FormField
              label="Base URL"
              required={formData.type === "custom"}
              hint={formData.type !== "custom" ? "留空使用官方地址" : "Custom 类型必须填写"}
            >
              <Input
                value={formData.baseURL}
                onChange={baseURL => {
                  setFormData(prev => ({ ...prev, baseURL }));
                  setIsDirty(true);
                }}
                placeholder={getDefaultBaseURL(formData.type)}
              />
            </FormField>

            {/* 模型列表 */}
            <FormField label="模型列表" hint="点击 Auto-detect 自动获取，或手动添加">
              <ModelListEditor
                models={formData.models}
                onChange={models => {
                  setFormData(prev => ({ ...prev, models }));
                  setIsDirty(true);
                }}
              />
            </FormField>

            {/* 操作按钮区 */}
            <div className="flex flex-wrap gap-2 pt-4 border-t border-gray-200 dark:border-gray-700">
              <Button
                onClick={handleDetect}
                loading={detecting}
                variant="secondary"
                size="sm"
                icon={<Search size={14} />}
              >
                Auto-detect
              </Button>
              <Button
                onClick={handleTest}
                loading={testing}
                variant="secondary"
                size="sm"
                icon={<Wifi size={14} />}
                disabled={!selectedId}
              >
                Test 连接
              </Button>

              <div className="flex-1" />

              {isEditing && (
                <Button
                  onClick={handleDelete}
                  variant="danger"
                  size="sm"
                  icon={<Trash2 size={14} />}
                >
                  删除
                </Button>
              )}
              <Button
                onClick={handleSave}
                disabled={!isDirty}
                variant="primary"
                size="sm"
              >
                {isEditing ? "保存" : "创建"}
              </Button>
            </div>

            {/* 测试结果 */}
            {testResult && (
              <div className={cn(
                "p-3 rounded-lg text-sm",
                testResult.includes("成功")
                  ? "bg-green-50 dark:bg-green-900/20 text-green-700"
                  : "bg-red-50 dark:bg-red-900/20 text-red-700"
              )}>
                {testResult}
              </div>
            )}
          </div>
        )}
      </div>
    </div>
  );
};
```

#### 模型列表编辑器

```tsx
// renderer/src/components/settings/ModelListEditor.tsx

import React from "react";
import { Plus, Trash2 } from "lucide-react";

export const ModelListEditor: React.FC<{
  models: ModelFormItem[];
  onChange: (models: ModelFormItem[]) => void;
}> = ({ models, onChange }) => {
  const addModel = () => {
    onChange([...models, { id: "" }]);
  };

  const removeModel = (index: number) => {
    onChange(models.filter((_, i) => i !== index));
  };

  const updateModel = (index: number, field: keyof ModelFormItem, value: any) => {
    const updated = [...models];
    updated[index] = { ...updated[index], [field]: value };
    onChange(updated);
  };

  return (
    <div className="space-y-2">
      {models.map((model, index) => (
        <div key={index} className="flex items-center gap-2">
          <Input
            value={model.id}
            onChange={v => updateModel(index, "id", v)}
            placeholder="模型 ID，如 gpt-4o"
            className="flex-1"
          />
          <Input
            value={model.contextWindow || ""}
            onChange={v => updateModel(index, "contextWindow", parseInt(v) || undefined)}
            placeholder="上下文窗口"
            className="w-28"
            type="number"
          />
          <label className="flex items-center gap-1 text-xs text-gray-500 whitespace-nowrap">
            <input
              type="checkbox"
              checked={model.supportsVision || false}
              onChange={e => updateModel(index, "supportsVision", e.target.checked)}
            />
            视觉
          </label>
          <button
            onClick={() => removeModel(index)}
            className="p-1 text-gray-400 hover:text-red-500 transition-colors flex-shrink-0"
          >
            <Trash2 size={14} />
          </button>
        </div>
      ))}

      <button
        onClick={addModel}
        className="flex items-center gap-1 text-sm text-blue-600 hover:text-blue-700 transition-colors"
      >
        <Plus size={14} /> 添加模型
      </button>
    </div>
  );
};
```

## 备注

- 该面板通过 IPC 调用 F1.1 的 `ProviderManager`，不直接操作 electron-store
- 表单中的 apiKey 在编辑模式下为空字符串（不加载原值以保护安全），用户留空表示不更新
- Provider 类型图标和颜色统一在 UI 层的常量配置中定义
- 表单 "已修改但未保存" 的状态通过 `isDirty` 标志位管理，关闭面板/切换 Provider 时弹提示
