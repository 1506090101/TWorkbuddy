# F1.3 — Pi SDK 集成、WorkSession 与 Agent Runtime

> **Phase**: Phase 1 — 基础底座 + 代码安全
> **Priority**: P0
> **Status**: In Progress
> **Dependencies**: F1.1 (多 Provider 注册表)

## 概述

本功能是 Agent Buddy 与 Pi Agent SDK 的核心集成层，负责在主进程中创建、管理和生命周期控制 AgentSession。AgentSession 是 Pi SDK 中表示一次 AI Agent 交互的核心对象，封装了 LLM 调用、工具执行循环、对话历史和会话管理。

作为所有 Agent 功能的基础，该模块需要完成：SDK 初始化、AgentSession 创建与配置、prompt/abort/steer/setModel 等核心操作的封装、以及 Agent 事件流到渲染进程的转发。通过严格的主进程隔离，确保所有 LLM 调用和工具执行都在 Node.js 环境中有序进行，渲染进程仅通过 IPC 发送指令和接收事件。

V1 初始阶段使用 `SessionManager.inMemory()` 进行会话管理；V2 首轮已由主进程 `electron-store` 持久化 `WorkSession` 和 `WorkEvent`，后续可按规模迁移 SQLite。应用启动时自动恢复最近工作会话并检查 Provider 配置状态，若无可用 Provider 则在工作台展示友好引导。

## V2 需求调整：WorkSession Runtime

F1.3 在 V2 中不只管理一次性的 Agent Session，还要成为 Agent Workbuddy 的运行时底座。主进程维护可恢复的 `WorkSession`，接收 Composer 的上下文，驱动 Agent Runtime，并以统一 `WorkEvent` 事件流向渲染进程报告工作过程。

`WorkSession` 必须保存任务标题、项目引用、活动 Agent、会话模型覆盖、目标、消息/工具/权限/变更/验证事件和运行状态。渲染进程只订阅、展示和发起最小 IPC 请求；它不能作为会话历史或权限状态的唯一事实来源。

### V2 验收（首轮实现进度）

- [x] 主进程可创建、列出、加载、重命名、归档和恢复 `WorkSession`。
- [x] 会话持久化任务、项目引用、目标、活动 Agent、模型覆盖和 `WorkEvent` 时间线；应用重启后可恢复。
- [x] `agent:prompt` 接收 `ComposerContext`，而不是仅接收裸文本消息。
- [ ] Agent Runtime 发送统一 `WorkEvent`：用户指令、输出、思考、工具开始/更新/结束、权限请求/决定、文件变更、测试、错误和总结。
- [x] 每个 `WorkEvent` 带 `sessionId`、时间戳、类型、状态和必要的安全脱敏载荷。
- [x] 取消、超时和运行失败会写入会话时间线，并使会话返回可继续状态。
- [x] 运行时不将 API Key、未授权文件正文或系统环境信息发送到渲染进程。

## 技术设计

### 数据模型

```typescript
// Agent 会话配置
interface AgentSessionConfig {
  model: {
    providerId: string;
    modelId: string;
  };
  thinkingLevel: "off" | "low" | "medium" | "high";
  tools: ToolDefinition[];         // Pi 内置工具 + 自定义工具
  customTools?: CustomToolDef[];
  sessionManager: SessionManager;  // 初始使用 inMemory
  systemPrompt?: string;
}

// Agent 事件类型
type AgentEvent =
  | { type: "token"; data: string }                     // 流式 token
  | { type: "tool_call"; data: ToolCallInfo }           // 工具调用开始
  | { type: "tool_result"; data: ToolResultInfo }       // 工具调用结果
  | { type: "thinking"; data: string }                  // 思考过程
  | { type: "completed"; data: { finishReason: string } }  // 完成
  | { type: "error"; data: { message: string; code?: string } }  // 错误
  | { type: "aborted" }                                 // 被中止

interface ToolCallInfo {
  id: string;
  toolName: string;
  params: Record<string, any>;
}

interface ToolResultInfo {
  id: string;
  toolName: string;
  result: any;
  duration: number;
  error?: string;
}

// 发送消息请求
interface PromptRequest {
  agentId?: string;
  message: {
    role: "user";
    content: ContentBlock[];
  };
}

// 发送消息响应
interface PromptResponse {
  sessionId: string;
}
```

### IPC 通道

| 通道 | 方向 | 参数 | 返回值 | 说明 |
|------|------|------|--------|------|
| `agent:init` | invoke | `AgentSessionConfig` | `{ sessionId: string }` | 初始化 Agent 会话 |
| `agent:prompt` | invoke | `PromptRequest` | `PromptResponse` | 发送消息 |
| `agent:abort` | send | `{ sessionId: string }` | 无 | 中止生成 |
| `agent:set-model` | invoke | `{ sessionId: string; model: { providerId: string; modelId: string } }` | `void` | 切换模型 |
| `agent:event` | handle→send | — | `AgentEvent` | 事件推送到渲染进程 |
| `agent:get-status` | invoke | 无 | `{ hasProvider: boolean; sessionId?: string }` | 获取状态 |

### 组件结构

本功能主进程组件：

```
AgentSessionManager (main process)
├── createSession(config): string       // 创建 AgentSession
├── prompt(sessionId, message): void    // 发送消息
├── abort(sessionId): void              // 中止
├── setModel(sessionId, model): void    // 切换模型
├── destroySession(sessionId): void     // 销毁会话
├── getOrCreateSession(agentId): string // 获取或懒创建会话
└── forwardEvents(sessionId, window): Disposable  // 事件注册
```

### 关键实现逻辑

#### AgentSessionManager 核心实现

```typescript
// main/agent/agent-session-manager.ts

import { createAgentSession, SessionManager } from "@earendil-works/pi-coding-agent";
import { BrowserWindow, ipcMain } from "electron";
import { providerManager } from "../providers/provider-manager";
import { modelRouter } from "./model-router";

class AgentSessionManager {
  private sessions: Map<string, AgentSession> = new Map();
  private eventDisposables: Map<string, () => void> = new Map();

  /**
   * 创建新的 AgentSession
   */
  async createSession(config: {
    agentId?: string;
    systemPrompt?: string;
    thinkingLevel?: string;
  }, window: BrowserWindow): Promise<{ sessionId: string }> {
    // 检查 Provider 配置
    const providers = providerManager.list();
    if (providers.length === 0) {
      throw new Error("NO_PROVIDER_CONFIGURED");
    }

    // 获取模型配置
    const modelAssignment = modelRouter.getAssignment(config.agentId || "default");
    const { modelId, envVars } = providerManager.getModel(
      modelAssignment.chat.providerId,
      modelAssignment.chat.modelId
    );

    // 注入环境变量
    for (const [key, value] of Object.entries(envVars)) {
      process.env[key] = value;
    }

    // 创建 SessionManager（初始阶段使用内存模式）
    const sessionManager = SessionManager.inMemory();

    // 获取 Pi 内置工具 + 自定义工具
    const tools = this.getBuiltinTools();
    const customTools = this.getCustomTools();

    // 创建 AgentSession
    const session = createAgentSession({
      model: modelId,
      thinkingLevel: config.thinkingLevel || "off",
      tools,
      customTools,
      sessionManager,
      systemPrompt: config.systemPrompt,
    });

    const sessionId = `session_${Date.now()}`;
    this.sessions.set(sessionId, session);

    // 注册事件转发
    this.forwardEvents(sessionId, session, window);

    return { sessionId };
  }

  /**
   * 发送消息到 Agent
   */
  async prompt(sessionId: string, message: PromptRequest["message"]): Promise<void> {
    const session = this.sessions.get(sessionId);
    if (!session) throw new Error(`Session "${sessionId}" not found`);

    await session.prompt({
      role: message.role,
      content: message.content,
    });
  }

  /**
   * 中止 Agent 当前生成
   */
  abort(sessionId: string): void {
    const session = this.sessions.get(sessionId);
    if (!session) throw new Error(`Session "${sessionId}" not found`);
    session.abort();
  }

  /**
   * 动态切换模型
   */
  setModel(sessionId: string, providerId: string, modelId: string): void {
    const session = this.sessions.get(sessionId);
    if (!session) throw new Error(`Session "${sessionId}" not found`);

    const { envVars } = providerManager.getModel(providerId, modelId);
    for (const [key, value] of Object.entries(envVars)) {
      process.env[key] = value;
    }

    session.setModel(modelId);
  }

  /**
   * 获取或懒创建会话
   */
  async getOrCreateSession(
    agentId: string,
    window: BrowserWindow
  ): Promise<string> {
    // 查找已有的活跃会话
    const existing = Array.from(this.sessions.entries())
      .find(([_, s]) => (s as any).agentId === agentId);

    if (existing) return existing[0];

    // 创建新会话
    const result = await this.createSession({ agentId }, window);
    return result.sessionId;
  }

  /**
   * 转发 Pi SDK 事件到渲染进程
   */
  private forwardEvents(
    sessionId: string,
    session: AgentSession,
    window: BrowserWindow
  ): void {
    const onToken = (token: string) => {
      window.webContents.send("agent:event", {
        sessionId,
        type: "token",
        data: token,
      });
    };

    const onToolCall = (toolCall: any) => {
      window.webContents.send("agent:event", {
        sessionId,
        type: "tool_call",
        data: {
          id: toolCall.id,
          toolName: toolCall.name,
          params: toolCall.params,
        },
      });
    };

    const onToolResult = (result: any) => {
      window.webContents.send("agent:event", {
        sessionId,
        type: "tool_result",
        data: {
          id: result.id,
          toolName: result.name,
          result: result.result,
          duration: result.duration,
          error: result.error,
        },
      });
    };

    const onCompleted = (finishReason: string) => {
      window.webContents.send("agent:event", {
        sessionId,
        type: "completed",
        data: { finishReason },
      });
      this.cleanup(sessionId);
    };

    const onError = (error: Error) => {
      window.webContents.send("agent:event", {
        sessionId,
        type: "error",
        data: { message: error.message },
      });
    };

    // 注册事件监听
    session.on("token", onToken);
    session.on("toolCall", onToolCall);
    session.on("toolResult", onToolResult);
    session.on("completed", onCompleted);
    session.on("error", onError);

    // 返回清理函数
    const dispose = () => {
      session.off("token", onToken);
      session.off("toolCall", onToolCall);
      session.off("toolResult", onToolResult);
      session.off("completed", onCompleted);
      session.off("error", onError);
    };

    this.eventDisposables.set(sessionId, dispose);
  }

  /**
   * 清理会话资源
   */
  cleanup(sessionId: string): void {
    const dispose = this.eventDisposables.get(sessionId);
    if (dispose) {
      dispose();
      this.eventDisposables.delete(sessionId);
    }
    this.sessions.delete(sessionId);
  }

  /**
   * 销毁所有会话（应用退出时）
   */
  destroyAll(): void {
    for (const [sessionId] of this.sessions) {
      this.cleanup(sessionId);
    }
  }

  /**
   * 获取状态（供渲染进程查询）
   */
  getStatus(): { hasProvider: boolean; sessionId?: string } {
    const providers = providerManager.list();
    const hasProvider = providers.length > 0;
    const activeSession = Array.from(this.sessions.keys())[0];

    return {
      hasProvider,
      sessionId: activeSession,
    };
  }
}

// 单例
export const agentSessionManager = new AgentSessionManager();
```

#### IPC 处理注册

```typescript
// main/agent/agent-ipc.ts

export function registerAgentIpc(window: BrowserWindow): void {
  ipcMain.handle("agent:init", async (_event, config: AgentSessionConfig) => {
    try {
      const result = await agentSessionManager.createSession(config, window);
      return { success: true, data: result };
    } catch (error: any) {
      if (error.message === "NO_PROVIDER_CONFIGURED") {
        return {
          success: false,
          error: "NO_PROVIDER",
          message: "请先配置至少一个 LLM Provider",
        };
      }
      return { success: false, error: error.message };
    }
  });

  ipcMain.handle("agent:prompt", async (_event, request: PromptRequest) => {
    try {
      const sessionId = await agentSessionManager.getOrCreateSession(
        request.agentId || "default",
        window
      );
      await agentSessionManager.prompt(sessionId, request.message);
      return { success: true, data: { sessionId } };
    } catch (error: any) {
      return { success: false, error: error.message };
    }
  });

  ipcMain.on("agent:abort", (_event, { sessionId }) => {
    agentSessionManager.abort(sessionId);
  });

  ipcMain.handle("agent:set-model", async (_event, { sessionId, model }) => {
    try {
      agentSessionManager.setModel(sessionId, model.providerId, model.modelId);
      return { success: true };
    } catch (error: any) {
      return { success: false, error: error.message };
    }
  });

  ipcMain.handle("agent:get-status", async () => {
    return agentSessionManager.getStatus();
  });
}
```

#### 渲染进程事件订阅

```typescript
// renderer/src/hooks/useAgent.ts

import { useEffect } from "react";
import { useChatStore } from "../stores/chatStore";

export function useAgent() {
  const appendToken = useChatStore(s => s.appendToken);
  const addToolCall = useChatStore(s => s.addToolCall);
  const complete = useChatStore(s => s.complete);
  const setError = useChatStore(s => s.setError);

  useEffect(() => {
    const unsubscribe = window.electronAPI.onAgentEvent((event) => {
      switch (event.type) {
        case "token":
          appendToken(event.data);
          break;
        case "tool_call":
          addToolCall(event.data);
          break;
        case "tool_result":
          updateToolResult(event.data);
          break;
        case "completed":
          complete(event.data.finishReason);
          break;
        case "error":
          setError(event.data.message);
          break;
        case "aborted":
          complete("aborted");
          break;
      }
    });

    return unsubscribe;
  }, []);
}

export function useSendMessage() {
  const send = useCallback(async (message: PromptRequest["message"]) => {
    const result = await window.electronAPI.agentPrompt({
      agentId: "default",
      message,
    });

    if (!result.success && result.error === "NO_PROVIDER") {
      // 显示引导 UI
      useUIStore.getState().showProviderGuide();
    }
  }, []);

  return send;
}
```
