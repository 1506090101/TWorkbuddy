# F1.5 — Agent Composer

> **Phase**: Phase 1 — 基础底座 + 代码安全
> **Priority**: P0
> **Status**: In Progress
> **Dependencies**: F0.4 (UI 组件库), F1.2 (视觉模型路由), F1.3 (Agent Session)

## 概述

Agent Composer 是用户组织一次 Agent 工作的入口，位于工作台底部。它不是普通聊天输入框：除了任务文本，还负责收集当前会话模型、Thinking、文件、插件上下文和会话目标，并将它们作为显式 `ComposerContext` 发送给 Agent Runtime。

Composer 核心功能包括：自适应文本输入、Enter 发送 / Shift+Enter 换行、`+` 添加文件、当前会话模型和 Thinking 选择、插件菜单、会话目标入口、附件预览、Vision 路由提示以及发送/停止控制。文件首轮支持图片、UTF-8 文本和代码文件；插件首轮只记录显式选择和可用状态，真实执行遵循 F1.6/F7.x。

Composer 必须持续显示当前 Agent、会话生效模型和目标状态；这些控件是工作上下文，不是隐藏在设置中的二级操作。

### V2 需求调整

Composer 是工作台的主要任务入口，视觉上采用紧凑的开发工作台输入区。输入区支持多行任务描述；`+` 菜单负责添加图片、文本和代码文件，并提供插件与目标入口；模型选择器负责当前会话即时覆盖；底部显示 Thinking、附件、插件和目标的上下文状态，并提供发送/停止操作。

提交对象必须是 `ComposerContext`，不能只发送字符串。附件、插件和目标均需由用户显式选择，主进程负责校验引用、大小、类型和权限；发送、停止、空任务、运行中重复提交和失败恢复都必须有明确状态。

## 验收标准

### 功能验收
- [ ] 自适应高度 Textarea：初始单行，内容增加自动扩展，最大 200px 后出现滚动条
- [ ] Enter 键发送消息，Shift+Enter 换行
- [ ] 图片上传按钮：点击打开文件选择器，支持多选（png/jpg/gif/webp）
- [ ] 粘贴图片：Ctrl+V 粘贴剪贴板中的图片，自动添加到附件区
- [ ] 图片预览区：缩略图网格展示（最多显示 4 张），每张图右上角有删除按钮
- [ ] Vision Model 状态提示：有图片时显示将使用的 Vision Model 名称
- [ ] 发送/停止按钮切换：Agent 运行时显示红色停止按钮，空闲时显示发送按钮
- [ ] 空消息禁用：无文本且无图片时发送按钮 `disabled`
- [ ] 发送后自动清空输入框和图片
- [ ] 纯空格/换行文本视为空消息

### 非功能验收
- [ ] 图片大小限制：单张 ≤ 20MB，超出时 Toast 提示
- [ ] 图片格式校验：仅允许 image/png, image/jpeg, image/gif, image/webp
- [ ] 粘贴检测：通过 Clipboard API 检测图片类型
- [ ] Textarea 调整不触发布局抖动

## 技术设计

### 数据模型

```typescript
// 输入栏状态
interface InputBarState {
  text: string;
  images: PendingImage[];
  isGenerating: boolean;
  activeAgentId: string;
  activeModelInfo: {
    chat: { providerId: string; modelId: string };
    vision?: { providerId: string; modelId: string } | null;
  };
}

// 待发送图片
interface PendingImage {
  id: string;
  dataUrl: string;           // base64 data URL（预览用）
  base64Data: string;        // 纯 base64（不含前缀）
  mediaType: string;         // image/png, image/jpeg, etc.
  fileName: string;
  fileSize: number;          // bytes
}

// 发送的消息结构
interface SendMessagePayload {
  text: string;
  images: {
    base64Data: string;
    mediaType: string;
  }[];
  agentId: string;
}
```

### IPC 通道

本功能不新增独立 IPC 通道，通过 F1.3 的 `agent:prompt` 发送消息，通过 `agent:abort` 停止生成。

| 通道 | 方向 | 说明 |
|------|------|------|
| `agent:prompt` | invoke | 发送消息（含图片数据） |
| `agent:abort` | send | 停止 Agent 生成 |

### 关键实现逻辑

#### InputBar 组件核心

```tsx
// renderer/src/components/chat/InputBar.tsx

import React, { useState, useRef, useCallback, useEffect } from "react";
import { Send, Square, ImagePlus } from "lucide-react";
import { useInputBarStore } from "../../stores/inputBarStore";
import { useChatStore } from "../../stores/chatStore";
import { useAgent } from "../../hooks/useAgent";

const MAX_IMAGE_SIZE = 20 * 1024 * 1024; // 20MB
const ALLOWED_IMAGE_TYPES = ["image/png", "image/jpeg", "image/gif", "image/webp"];
const MAX_TEXTAREA_HEIGHT = 200;
const MAX_IMAGES = 5;

export const InputBar: React.FC = () => {
  const textareaRef = useRef<HTMLTextAreaElement>(null);
  const fileInputRef = useRef<HTMLInputElement>(null);

  const [text, setText] = useState("");
  const [images, setImages] = useState<PendingImage[]>([]);
  const isGenerating = useChatStore(s => s.isGenerating);
  const sendMessage = useAgent().send;

  // 自适应高度
  const adjustTextareaHeight = useCallback(() => {
    const el = textareaRef.current;
    if (!el) return;

    el.style.height = "auto";
    const newHeight = Math.min(el.scrollHeight, MAX_TEXTAREA_HEIGHT);
    el.style.height = `${newHeight}px`;
    el.style.overflowY = el.scrollHeight > MAX_TEXTAREA_HEIGHT ? "auto" : "hidden";
  }, []);

  // 文本变化
  const handleTextChange = (e: React.ChangeEvent<HTMLTextAreaElement>) => {
    setText(e.target.value);
    adjustTextareaHeight();
  };

  // 键盘处理
  const handleKeyDown = (e: React.KeyboardEvent<HTMLTextAreaElement>) => {
    if (e.key === "Enter" && !e.shiftKey) {
      e.preventDefault();
      handleSend();
    }
  };

  // 处理粘贴事件（支持图片粘贴）
  const handlePaste = async (e: React.ClipboardEvent) => {
    const items = Array.from(e.clipboardData.items);

    for (const item of items) {
      if (item.type.startsWith("image/")) {
        e.preventDefault();
        const file = item.getAsFile();
        if (file) {
          await addImageFromFile(file);
        }
      }
    }
  };

  // 上传图片
  const handleFileSelect = async (e: React.ChangeEvent<HTMLInputElement>) => {
    const files = Array.from(e.target.files || []);
    for (const file of files) {
      await addImageFromFile(file);
    }
    // 重置 input 以允许重复选择同一文件
    e.target.value = "";
  };

  // 添加图片
  const addImageFromFile = async (file: File): Promise<void> => {
    // 格式校验
    if (!ALLOWED_IMAGE_TYPES.includes(file.type)) {
      toast.error(`不支持的图片格式: ${file.type}，仅支持 PNG/JPG/GIF/WebP`);
      return;
    }

    // 大小校验
    if (file.size > MAX_IMAGE_SIZE) {
      toast.error(`图片过大 (${formatSize(file.size)})，最大允许 20MB`);
      return;
    }

    // 数量限制
    if (images.length >= MAX_IMAGES) {
      toast.error(`最多上传 ${MAX_IMAGES} 张图片`);
      return;
    }

    const dataUrl = await fileToDataUrl(file);
    const base64Data = dataUrl.split(",")[1]; // 去掉 data:image/xxx;base64, 前缀

    setImages(prev => [...prev, {
      id: `img_${Date.now()}_${Math.random().toString(36).slice(2, 7)}`,
      dataUrl,
      base64Data,
      mediaType: file.type,
      fileName: file.name,
      fileSize: file.size,
    }]);
  };

  // 删除图片
  const removeImage = (id: string) => {
    setImages(prev => prev.filter(img => img.id !== id));
  };

  // 发送消息
  const handleSend = async () => {
    const trimmedText = text.trim();
    const hasContent = trimmedText.length > 0 || images.length > 0;

    if (!hasContent || isGenerating) return;

    const payload: SendMessagePayload = {
      text: trimmedText,
      images: images.map(img => ({
        base64Data: img.base64Data,
        mediaType: img.mediaType,
      })),
      agentId: useChatStore.getState().activeAgentId || "default",
    };

    // 添加用户消息到 chatStore
    useChatStore.getState().addMessage({
      role: "user",
      content: [
        { type: "text", text: trimmedText },
        ...images.map(img => ({
          type: "image" as const,
          source: { data: img.dataUrl, media_type: img.mediaType },
        })),
      ],
    });

    // 清空输入
    setText("");
    setImages([]);
    if (textareaRef.current) {
      textareaRef.current.style.height = "auto";
    }

    // 发送
    await sendMessage(payload);
  };

  // 停止生成
  const handleAbort = () => {
    window.electronAPI.agentAbort();
  };

  // 是否可发送
  const canSend = (text.trim().length > 0 || images.length > 0) && !isGenerating;

  return (
    <div className="border-t border-gray-200 dark:border-gray-700 bg-white dark:bg-gray-900 p-4">
      {/* 图片预览区 */}
      {images.length > 0 && (
        <ImagePreviewArea images={images} onRemove={removeImage} />
      )}

      {/* 文本输入区 */}
      <div className="flex items-end gap-2">
        {/* 图片上传按钮 */}
        <button
          onClick={() => fileInputRef.current?.click()}
          className="p-2 rounded-lg text-gray-400 hover:text-gray-600 hover:bg-gray-100
                     dark:hover:text-gray-300 dark:hover:bg-gray-800 transition-colors"
          title="上传图片"
        >
          <ImagePlus size={20} />
        </button>
        <input
          ref={fileInputRef}
          type="file"
          accept="image/png,image/jpeg,image/gif,image/webp"
          multiple
          className="hidden"
          onChange={handleFileSelect}
        />

        {/* Textarea */}
        <textarea
          ref={textareaRef}
          value={text}
          onChange={handleTextChange}
          onKeyDown={handleKeyDown}
          onPaste={handlePaste}
          placeholder="输入消息... (Enter 发送，Shift+Enter 换行)"
          rows={1}
          className="flex-1 resize-none rounded-lg border border-gray-300 dark:border-gray-600
                     bg-transparent px-3 py-2 text-sm focus:outline-none focus:ring-2
                     focus:ring-blue-500 dark:text-white placeholder-gray-400
                     min-h-[40px] max-h-[200px] overflow-y-auto"
        />

        {/* 发送/停止按钮 */}
        {isGenerating ? (
          <button
            onClick={handleAbort}
            className="p-2 rounded-lg bg-red-500 text-white hover:bg-red-600 transition-colors"
            title="停止生成"
          >
            <Square size={20} fill="currentColor" />
          </button>
        ) : (
          <button
            onClick={handleSend}
            disabled={!canSend}
            className={cn(
              "p-2 rounded-lg transition-colors",
              canSend
                ? "bg-blue-600 text-white hover:bg-blue-700"
                : "bg-gray-200 text-gray-400 dark:bg-gray-700 cursor-not-allowed"
            )}
            title="发送消息"
          >
            <Send size={20} />
          </button>
        )}
      </div>

      {/* Vision Model 提示（来自 F1.2） */}
      <VisionModelIndicator images={images} />
    </div>
  );
};
```

#### 辅助函数

```typescript
// renderer/src/utils/image.ts

export function fileToDataUrl(file: File): Promise<string> {
  return new Promise((resolve, reject) => {
    const reader = new FileReader();
    reader.onload = () => resolve(reader.result as string);
    reader.onerror = reject;
    reader.readAsDataURL(file);
  });
}

export function clipboardToImageDataUrl(
  item: DataTransferItem
): Promise<string | null> {
  return new Promise((resolve) => {
    const file = item.getAsFile();
    if (!file) {
      resolve(null);
      return;
    }
    fileToDataUrl(file).then(resolve).catch(() => resolve(null));
  });
}

export function formatSize(bytes: number): string {
  if (bytes < 1024) return `${bytes} B`;
  if (bytes < 1024 * 1024) return `${(bytes / 1024).toFixed(1)} KB`;
  return `${(bytes / (1024 * 1024)).toFixed(1)} MB`;
}
```

## UI/UX 规范

- **输入区域**：固定在主对话区底部，上方有 1px 边框分隔，背景与消息区分开（白色/暗色）
- **Textarea**：无边框风格（只保留底部聚焦指示器），聚焦时蓝色 ring 效果
- **按钮微交互**：hover 颜色过渡 150ms ease-out；点击缩放反馈（`active:scale-95`）
- **图片删除按钮**：默认隐藏（`opacity-0`），hover 图片缩略图时显示（`group-hover:opacity-100`）
- **停止按钮**：红色圆形按钮，与蓝色发送按钮视觉对比强烈
- **Vision Model 提示**：灰色小字，位于输入区域最下方，格式如 `图片将使用 Vision Model: openai/gpt-4o`

## 测试要点

- **单元测试**: 图片格式和大小校验；trim 空文本检测；`fileToDataUrl` 转换
