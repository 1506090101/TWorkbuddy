# F1.9 — 项目自动感知

> **Phase**: Phase 1 — 基础底座 + 代码安全
> **Priority**: P1
> **Status**: In Progress
> **Dependencies**: F1.3 (Pi SDK 集成)

## 概述

Agent Buddy 的核心场景是辅助开发者在项目目录中工作。传统的 AI 助手每次对话都需要用户解释"这是什么项目""用的什么技术栈""怎么构建怎么测试"，不仅低效而且浪费大量 token。本功能实现在打开工作目录时自动检测项目类型、识别技术栈和框架、读取构建配置，并将所有信息组装为 `ProjectContext` 注入 Agent 的 system context。

感知流程分为多个阶段：首先通过扫描标识文件（package.json / Cargo.toml / go.mod 等）识别项目类型；然后深入解析这些文件提取依赖列表、框架和构建工具；接着扫描目录结构识别源码目录、测试目录和入口文件；最后整合 Git 状态信息，构建完整的 ProjectContext。Agent 拿到这个上下文后可以直接工作——"用 yarn dev 启动项目""查看 src/App.tsx 的主入口""运行 npm test"——这些信息已经预先告知 Agent。

该功能在用户打开目录时自动触发（< 2 秒完成），结果缓存在 `{project}/.agentbuddy/context.json` 中，后续打开同一项目直接读取缓存并验证变化。

## V2 需求调整：项目作为会话上下文

V2 不把项目感知做成独立设置页。用户在工作台关联目录后，主进程自动检测并缓存安全摘要，右侧面板呈现技术栈、常用脚本和目录结构；后续 Agent prompt 注入同一份裁剪摘要。首轮缓存存于用户目录 `~/.agentbuddy/projects/`，避免首次打开项目时向用户仓库写入文件。

### 功能验收

- [ ] 检测标识文件并识别项目类型：package.json → node, Cargo.toml → rust, go.mod → go, pom.xml → java, requirements.txt → python
- [ ] 多个标识文件同时存在时识别为 "mixed" 类型，并列出所有检测到的语言
- [ ] 识别框架：从 package.json dependencies 中检测 react/vue/express/next/django/flask 等
- [ ] 识别包管理器：npm / yarn / pnpm / pip / cargo / go / maven
- [ ] 识别构建系统：vite / webpack / make / cmake / esbuild
- [ ] 读取构建脚本和测试脚本（如 package.json scripts）
- [ ] 执行 gitStatus 获取版本状态
- [ ] 扫描目录结构识别源码目录、测试目录、配置目录、入口文件
- [ ] 构建 ProjectContext 并在 Agent 会话启动时注入 system context
- [ ] 结果缓存，二次打开时快速加载
- [ ] 未知项目类型时标记为 "unknown"，仍可正常使用

### 非功能验收

- [ ] 感知流程在 2 秒内完成（不含 Git 操作和大型目录扫描）
- [ ] 缓存命中时加载 < 50ms
- [ ] 文件扫描过滤 node_modules / dist / .git / build 等目录
- [ ] 感知异常不影响 Agent 正常启动（降级为基础上下文）

## 技术设计

### 数据模型

```typescript
// 项目类型
type ProjectType =
  "node" | "python" | "rust" | "go" | "java" | "cpp" | "mixed" | "unknown";

// 项目上下文
interface ProjectContext {
  rootPath: string;
  type: ProjectType;
  language: string;
  framework?: string;
  frameworkVersion?: string;
  packageManager?: string;
  buildSystem?: string;
  testCommand?: string;
  lintCommand?: string;
  buildCommand?: string;
  startCommand?: string;
  dependencies: DependencyInfo[];
  devDependencies: DependencyInfo[];
  scripts?: Record<string, string>;
  gitInfo?: GitStatus; // 来自 F1.10
  structure: ProjectStructure;
  detectedAt: number; // 探测时间戳
}

interface DependencyInfo {
  name: string;
  version: string;
  isDev: boolean;
}

interface ProjectStructure {
  sourceDirs: string[]; // src/, lib/, app/
  testDirs: string[]; // __tests__/, tests/, spec/
  configFiles: string[]; // 配置文件列表
  entryPoints: string[]; // main.ts, index.js, main.py...
}

// 缓存格式
interface ProjectContextCache {
  rootPath: string;
  context: ProjectContext;
  fileHashes: Record<string, string>; // 关键文件的 hash，用于检测变化
  cachedAt: number;
}
```

### 关键实现逻辑

#### 项目感知器核心

```typescript
// main/project/project-detector.ts

import * as fs from "fs";
import * as path from "path";
import * as glob from "glob";

const IDENTIFIER_FILES: Record<string, ProjectType> = {
  "package.json": "node",
  "Cargo.toml": "rust",
  "go.mod": "go",
  "pom.xml": "java",
  "build.gradle": "java",
  "requirements.txt": "python",
  "setup.py": "python",
  "pyproject.toml": "python",
  "CMakeLists.txt": "cpp",
  Makefile: "cpp",
};

const FRAMEWORK_PATTERNS: Record<string, string[]> = {
  node: [
    "react",
    "vue",
    "angular",
    "next",
    "nuxt",
    "express",
    "koa",
    "fastify",
    "nestjs",
    "svelte",
    "solid",
    "remix",
    "astro",
  ],
  python: ["django", "flask", "fastapi", "sqlalchemy"],
  rust: ["actix-web", "axum", "rocket", "tokio"],
  go: ["gin", "echo", "fiber", "chi"],
  java: ["spring-boot", "quarkus", "micronaut"],
};

const FRAMEWORK_DEPENDENCIES: Record<string, string[]> = {
  react: ["react"],
  vue: ["vue"],
  next: ["next"],
  express: ["express"],
  django: ["django"],
  flask: ["flask"],
  fastapi: ["fastapi"],
  "actix-web": ["actix-web"],
  gin: ["github.com/gin-gonic/gin"],
  "spring-boot": ["spring-boot-starter"],
};

class ProjectDetector {
  /**
   * 主入口：探测项目
   */
  async detect(rootPath: string): Promise<ProjectContext> {
    const startTime = Date.now();

    // 1. 尝试加载缓存
    const cached = await this.loadCachedContext(rootPath);
    if (cached && (await this.isCacheValid(rootPath, cached))) {
      return cached;
    }

    // 2. 检测项目类型
    const type = this.detectType(rootPath);

    // 3. 解析依赖
    const dependencies = await this.parseDependencies(rootPath, type);

    // 4. 检测框架
    const framework = this.detectFramework(type, dependencies);

    // 5. 检测包管理器
    const packageManager = this.detectPackageManager(rootPath, type);

    // 6. 检测构建系统
    const buildSystem = this.detectBuildSystem(rootPath, type);

    // 7. 读取脚本
    const scripts = await this.detectScripts(rootPath, type);

    // 8. 扫描目录结构
    const structure = await this.scanStructure(rootPath);

    // 9. 构建完整上下文
    const context: ProjectContext = {
      rootPath,
      type,
      language: this.getLanguage(type),
      framework: framework?.name,
      frameworkVersion: framework?.version,
      packageManager,
      buildSystem,
      testCommand: scripts?.test,
      lintCommand: scripts?.lint,
      buildCommand: scripts?.build,
      startCommand: scripts?.start || scripts?.dev,
      dependencies: dependencies.filter((d) => !d.isDev),
      devDependencies: dependencies.filter((d) => d.isDev),
      scripts,
      structure,
      detectedAt: Date.now(),
    };

    // 10. 缓存
    await this.cacheContext(rootPath, context);

    return context;
  }

  /**
   * 检测项目类型
   */
  private detectType(rootPath: string): ProjectType {
    const detected: ProjectType[] = [];

    for (const [fileName, type] of Object.entries(IDENTIFIER_FILES)) {
      if (fs.existsSync(path.join(rootPath, fileName))) {
        if (!detected.includes(type)) {
          detected.push(type);
        }
      }
    }

    if (detected.length === 0) return "unknown";
    if (detected.length === 1) return detected[0];
    return "mixed";
  }

  /**
   * 解析依赖列表
   */
  private async parseDependencies(
    rootPath: string,
    type: ProjectType,
  ): Promise<DependencyInfo[]> {
    const dependencies: DependencyInfo[] = [];

    try {
      if (["node", "mixed"].includes(type)) {
        const pkgPath = path.join(rootPath, "package.json");
        if (fs.existsSync(pkgPath)) {
          const pkg = JSON.parse(fs.readFileSync(pkgPath, "utf-8"));
          for (const [name, version] of Object.entries(
            pkg.dependencies || {},
          )) {
            dependencies.push({
              name,
              version: String(version).replace(/^[\^~]/, ""),
              isDev: false,
            });
          }
          for (const [name, version] of Object.entries(
            pkg.devDependencies || {},
          )) {
            dependencies.push({
              name,
              version: String(version).replace(/^[\^~]/, ""),
              isDev: true,
            });
          }
        }
      }

      if (["python", "mixed"].includes(type)) {
        const reqPath = path.join(rootPath, "requirements.txt");
        if (fs.existsSync(reqPath)) {
          const content = fs.readFileSync(reqPath, "utf-8");
          for (const line of content.split("\n")) {
            const match = line.match(/^([a-zA-Z0-9_-]+)([>=<~!]+.+)?$/);
            if (match) {
              dependencies.push({
                name: match[1],
                version: match[2]?.replace(/[>=<~!]+/, "") || "latest",
                isDev: false,
              });
            }
          }
        }
      }

      if (["rust", "mixed"].includes(type)) {
        const cargoPath = path.join(rootPath, "Cargo.toml");
        if (fs.existsSync(cargoPath)) {
          const content = fs.readFileSync(cargoPath, "utf-8");
          const depSection = content.match(
            /\[dependencies\]([\s\S]*?)(?:\[|\z)/,
          );
          if (depSection) {
            for (const line of depSection[1].split("\n")) {
              const match = line.match(/^([a-zA-Z0-9_-]+)\s*=\s*"([^"]+)"/);
              if (match) {
                dependencies.push({
                  name: match[1],
                  version: match[2],
                  isDev: false,
                });
              }
            }
          }
        }
      }

      // ... 其他语言类似
    } catch (error) {
      console.error("Failed to parse dependencies:", error);
    }

    return dependencies;
  }

  /**
   * 检测框架
   */
  private detectFramework(
    type: ProjectType,
    dependencies: DependencyInfo[],
  ): { name: string; version: string } | undefined {
    const depNames = dependencies.map((d) => d.name.toLowerCase());

    const typePatterns = FRAMEWORK_PATTERNS[type] || [];
    for (const framework of typePatterns) {
      const requiredDeps = FRAMEWORK_DEPENDENCIES[framework] || [];
      const hasAllDeps = requiredDeps.every((d) => depNames.includes(d));
      if (hasAllDeps) {
        const dep = dependencies.find((d) => d.name === requiredDeps[0]);
        return { name: framework, version: dep?.version || "unknown" };
      }
    }

    return undefined;
  }

  /**
   * 检测包管理器
   */
  private detectPackageManager(rootPath: string, type: ProjectType): string {
    // node 生态
    if (["node", "mixed"].includes(type)) {
      if (fs.existsSync(path.join(rootPath, "pnpm-lock.yaml"))) return "pnpm";
      if (fs.existsSync(path.join(rootPath, "yarn.lock"))) return "yarn";
      if (fs.existsSync(path.join(rootPath, "package-lock.json"))) return "npm";
      if (fs.existsSync(path.join(rootPath, "bun.lockb"))) return "bun";
      return "npm"; // 默认
    }

    // python 生态
    if (["python", "mixed"].includes(type)) {
      if (fs.existsSync(path.join(rootPath, "poetry.lock"))) return "poetry";
      if (fs.existsSync(path.join(rootPath, "Pipfile.lock"))) return "pipenv";
      if (fs.existsSync(path.join(rootPath, "uv.lock"))) return "uv";
      return "pip";
    }

    // rust
    if (type === "rust") return "cargo";
    // go
    if (type === "go") return "go";
    // java
    if (type === "java") {
      if (fs.existsSync(path.join(rootPath, "build.gradle"))) return "gradle";
      return "maven";
    }

    return "unknown";
  }

  /**
   * 检测构建系统
   */
  private detectBuildSystem(rootPath: string, type: ProjectType): string {
    if (["node", "mixed"].includes(type)) {
      const pkgPath = path.join(rootPath, "package.json");
      if (fs.existsSync(pkgPath)) {
        const pkg = JSON.parse(fs.readFileSync(pkgPath, "utf-8"));
        const deps = { ...pkg.dependencies, ...pkg.devDependencies };

        if ("vite" in deps) return "vite";
        if ("webpack" in deps) return "webpack";
        if ("esbuild" in deps) return "esbuild";
        if ("turbopack" in deps) return "turbopack";
        return "node-scripts"; // 使用 package.json scripts
      }
    }

    if (["cpp", "mixed"].includes(type)) {
      if (fs.existsSync(path.join(rootPath, "CMakeLists.txt"))) return "cmake";
      if (fs.existsSync(path.join(rootPath, "Makefile"))) return "make";
    }

    return "unknown";
  }

  /**
   * 读取脚本
   */
  private async detectScripts(
    rootPath: string,
    type: ProjectType,
  ): Promise<Record<string, string> | undefined> {
    if (["node", "mixed"].includes(type)) {
      const pkgPath = path.join(rootPath, "package.json");
      if (fs.existsSync(pkgPath)) {
        const pkg = JSON.parse(fs.readFileSync(pkgPath, "utf-8"));
        return pkg.scripts || {};
      }
    }

    return undefined;
  }

  /**
   * 扫描目录结构
   */
  private async scanStructure(rootPath: string): Promise<ProjectStructure> {
    const structure: ProjectStructure = {
      sourceDirs: [],
      testDirs: [],
      configFiles: [],
      entryPoints: [],
    };

    // 常见的源码目录
    const sourceDirs = [
      "src",
      "lib",
      "app",
      "packages",
      "source",
      "Sources",
      "pkg",
      "internal",
      "cmd",
    ];
    // 常见的测试目录
    const testDirs = [
      "__tests__",
      "tests",
      "test",
      "spec",
      "e2e",
      "test-suite",
      "__mocks__",
      "fixtures",
    ];
    // 常见的配置文件
    const configPatterns = [
      "tsconfig*.json",
      ".eslintrc*",
      ".prettierrc*",
      ".env*",
      "docker-compose*.yml",
      "Dockerfile",
      ".gitignore",
      "vitest.config.*",
      "jest.config.*",
    ];

    // 扫描源码目录
    for (const dir of sourceDirs) {
      const dirPath = path.join(rootPath, dir);
      if (fs.existsSync(dirPath) && fs.statSync(dirPath).isDirectory()) {
        structure.sourceDirs.push(dir);
      }
    }

    // 扫描测试目录
    for (const dir of testDirs) {
      const dirPath = path.join(rootPath, dir);
      if (fs.existsSync(dirPath) && fs.statSync(dirPath).isDirectory()) {
        structure.testDirs.push(dir);
      }
    }

    // 扫描配置文件
    for (const pattern of configPatterns) {
      const files = glob.sync(pattern, { cwd: rootPath, nodir: true });
      structure.configFiles.push(...files);
    }

    // 检测入口文件
    const entryPatterns = [
      "src/index.{ts,tsx,js,jsx}",
      "src/main.{ts,tsx,js,jsx}",
      "src/App.{ts,tsx,js,jsx}",
      "main.py",
      "app.py",
      "src/main.rs",
      "main.go",
      "cmd/main.go",
    ];
    for (const pattern of entryPatterns) {
      const files = glob.sync(pattern, { cwd: rootPath, nodir: true });
      structure.entryPoints.push(...files);
    }

    return structure;
  }

  /**
   * 获取语言名称
   */
  private getLanguage(type: ProjectType): string {
    const mapping: Record<ProjectType, string> = {
      node: "JavaScript/TypeScript",
      python: "Python",
      rust: "Rust",
      go: "Go",
      java: "Java",
      cpp: "C/C++",
      mixed: "Multi-language",
      unknown: "Unknown",
    };
    return mapping[type];
  }

  /**
   * 缓存上下文
   */
  private async cacheContext(
    rootPath: string,
    context: ProjectContext,
  ): Promise<void> {
    const cacheDir = path.join(rootPath, ".agentbuddy");
    if (!fs.existsSync(cacheDir)) {
      fs.mkdirSync(cacheDir, { recursive: true });
    }

    const cachePath = path.join(cacheDir, "context.json");
    const cache: ProjectContextCache = {
      rootPath,
      context,
      fileHashes: {},
      cachedAt: Date.now(),
    };

    fs.writeFileSync(cachePath, JSON.stringify(cache, null, 2));
  }

  /**
   * 加载缓存
   */
  private async loadCachedContext(
    rootPath: string,
  ): Promise<ProjectContext | null> {
    const cachePath = path.join(rootPath, ".agentbuddy", "context.json");
    if (!fs.existsSync(cachePath)) return null;

    try {
      const cache: ProjectContextCache = JSON.parse(
        fs.readFileSync(cachePath, "utf-8"),
      );
      return cache.context;
    } catch {
      return null; // 缓存损坏则重新探测
    }
  }

  /**
   * 验证缓存有效性（简单检查：package.json 等关键文件是否变化）
   */
  private async isCacheValid(
    rootPath: string,
    cachedContext: ProjectContext,
  ): Promise<boolean> {
    // 检查缓存时效（1 小时内有效）
    const age = Date.now() - cachedContext.detectedAt;
    if (age > 60 * 60 * 1000) return false;

    // 检查关键标识文件是否存在
    const keyFiles = [
      "package.json",
      "Cargo.toml",
      "go.mod",
      "pom.xml",
      "requirements.txt",
    ];
    for (const file of keyFiles) {
      const filePath = path.join(rootPath, file);
      if (fs.existsSync(filePath)) {
        return true; // 至少有一个关键文件存在则缓存有效
      }
    }

    return false;
  }
}

export const projectDetector = new ProjectDetector();
```

```typescript
// main/agent/context-builder.ts

function buildSystemContext(projectContext: ProjectContext): string {
  const lines: string[] = [
    "## 项目上下文",
    `- **项目类型**: ${projectContext.language}`,
    `- **框架**: ${projectContext.framework || "未检测到"}`,
    `- **包管理器**: ${projectContext.packageManager}`,
    `- **构建系统**: ${projectContext.buildSystem}`,
    "",
  ];

  if (projectContext.scripts) {
    lines.push("### 可用脚本");
    for (const [name, command] of Object.entries(projectContext.scripts)) {
      lines.push(`- \`${name}\`: \`${command}\``);
    }
    lines.push("");
  }

  if (projectContext.structure.sourceDirs.length > 0) {
    lines.push(
      `### 源码目录: ${projectContext.structure.sourceDirs.join(", ")}`,
    );
  }

  if (projectContext.structure.entryPoints.length > 0) {
    lines.push(
      `### 入口文件: ${projectContext.structure.entryPoints.join(", ")}`,
    );
  }

  if (projectContext.dependencies.length > 0) {
    const keyDeps = projectContext.dependencies
      .filter((d) => !d.isDev)
      .slice(0, 10)
      .map((d) => `${d.name}@${d.version}`)
      .join(", ");
    lines.push(`### 关键依赖: ${keyDeps}`);
  }

  return lines.join("\n");
}
```

## UI/UX 规范

- **项目感知进度**：打开目录后，标题栏或侧边栏显示项目检测结果标签（如 TypeScript + React + Vite 小标签）
- **检测失败**：不影响正常使用，标签显示 "Unknown Project"
- **手动刷新**：侧边栏右键菜单提供 "重新检测项目" 选项

## 测试要点

- **单元测试**: 各语言/框架检测逻辑（mock 文件系统）；标识文件存在性判断；mixed 类型识别
- **集成测试**: 完整检测流程（创建临时项目目录）；缓存读写；上下文字符串构建
- **E2E 测试**: 打开一个真实项目目录 → 检测结果显示

## 开放问题

1. monorepo 项目的检测策略——是否需要为每个子包单独生成 ProjectContext？
2. "mixed" 类型项目（同时有 package.json 和 requirements.txt）的 framework 检测优先级？
3. 依赖列表是否包含传递依赖（如解析 lock 文件）？Phase 1 建议仅直接依赖。
4. 项目检测结果是否需要用户确认或手动修正？
