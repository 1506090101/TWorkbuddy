# F1.4 — Agent 工作流消息流

> **Phase**: Phase 1 — 基础底座 + 代码安全
> **Priority**: P0
> **Status**: In Progress
> **Dependencies**: F0.3 (布局系统), F0.4 (UI 组件库), F1.3 (Pi SDK 集成)

## 概述

V1 将聊天 UI 定义为 Agent 对话消息流。V2 将其升级为 **Agent 工作流消息流**：对话只是任务输入和决策记录，主内容还包括思考、工具调用、权限确认、文件变更、测试、错误和最终总结。实现参考 Codex Desktop 的紧凑工作流交互，但不复制品牌、文案或界面细节。

时间线需要处理普通文本、Markdown、代码块、工具活动、权限、文件变更、测试、图片附件、思考和错误等工作事件。滚动行为需智能化——新事件到达时自动滚到底部，但用户主动上滚查看历史时暂停自动滚动，并显示返回底部操作。

V2 工作台使用 `workSessionStore` 订阅主进程的 `WorkEvent`，并通过 `WorkTimeline` 渲染可恢复的事件序列；旧 `useAgent`/`chatStore` 保留用于 V1 兼容。流式 Agent 输出以同一事件 ID 增量更新，工具活动使用可展开操作行，消息虚拟化预留接口（Phase 2 接入 @tanstack/react-virtual）。

### V2 需求调整

- 中央区域以时间线和状态行组织工作，不以连续聊天气泡表达 Agent 工作过程。
- 事件类型至少覆盖 `message`、`thinking`、`tool_call`、`permission`、`file_change`、`test`、`error` 和 `summary`。
- 每个事件展示来源 Agent、时间、状态和关联 `goalId`；工具参数、权限影响、文件路径和测试输出与普通正文分离。
- 工具调用、权限请求、文件变更和测试结果必须可展开、可定位、可审查；失败事件必须提供恢复入口或明确下一步。
- 时间线必须支持流式更新、历史恢复、运行中停止和目标事件筛选。

## 技术设计

### 数据模型

```typescript
// 消息角色
type MessageRole = "user" | "assistant" | "system" | "tool";

// 消息内容块
type MessageContentBlock =
  | { type: "text"; text: string }
  | { type: "image"; source: { data: string; media_type: string }; alt?: string }
  | { type: "tool_call"; id: string; name: string; params: Record<string, any> }
  | { type: "tool_result"; id: string; name: string; result: any; error?: string };

// 单条消息
interface ChatMessage {
  id: string;
  role: MessageRole;
  content: MessageContentBlock[];
  agentId?: string;          // AI 消息的来源 Agent
  agentName?: string;        // Agent 显示名称
  agentIcon?: string;        // Lucide 图标名
  agentColor?: string;       // Agent 主题色
  timestamp: number;
  status: "streaming" | "completed" | "error" | "aborted";
  errorMessage?: string;
  toolCalls?: ToolCallInfo[];
}

// 消息流状态
interface ChatState {
  messages: ChatMessage[];
  isGenerating: boolean;
  activeAgentId?: string;
  currentMessageId?: string;  // 正在流式输出的消息 ID
  thinkingText: string;       // 当前思考内容

  // 操作
  addMessage: (msg: Omit<ChatMessage, "id" | "timestamp">) => void;
  appendToken: (token: string) => void;
  appendThinking: (text: string) => void;
  completeMessage: (finishReason: string) => void;
  setError: (error: string) => void;
  clearMessages: () => void;
}
```

### IPC 通道

本功能不直接新增 IPC 通道，通过 F1.3 的 `agent:event` 事件流获取数据。渲染进程通过 `useAgent` Hook 订阅如下事件：

| 事件类型 | 数据 | 触发操作 |
|----------|------|---------|
| `token` | string | `appendToken(token)` 追加到当前消息 |
| `thinking` | string | `appendThinking(text)` 更新思考过程 |
| `tool_call` | ToolCallInfo | 插入工具调用卡片 |
| `tool_result` | ToolResultInfo | 更新工具调用结果 |
| `completed` | { finishReason } | 完成消息，停止光标动画 |
| `error` | { message } | 显示错误状态 |
| `aborted` | 无 | 标记消息为已中止 |

### 关键实现逻辑

#### 消息存储与增量更新

```typescript
// renderer/src/stores/chatStore.ts

import { create } from "zustand";
import { immer } from "zustand/middleware/immer";

export const useChatStore = create<ChatState>()(
  immer((set, get) => ({
    messages: [],
    isGenerating: false,
    currentMessageId: undefined,

    addMessage: (msg) => {
      const message: ChatMessage = {
        ...msg,
        id: `msg_${Date.now()}_${Math.random().toString(36).slice(2, 9)}`,
        timestamp: Date.now(),
        status: msg.role === "assistant" ? "streaming" : "completed",
      };
      set(state => {
        state.messages.push(message);
        state.isGenerating = message.role === "assistant";
        state.currentMessageId = message.id;
      });
    },

    appendToken: (token) => {
      set(state => {
        const msg = state.messages.find(
          m => m.id === state.currentMessageId
        );
        if (!msg) return;

        // 找到或创建文本内容块
        const lastBlock = msg.content[msg.content.length - 1];
        if (lastBlock && lastBlock.type === "text") {
          lastBlock.text += token;
        } else {
          msg.content.push({ type: "text", text: token });
        }
      });
    },

    completeMessage: (finishReason) => {
      set(state => {
        const msg = state.messages.find(
          m => m.id === state.currentMessageId
        );
        if (msg) {
          msg.status = finishReason === "aborted" ? "aborted" : "completed";
        }
        state.isGenerating = false;
        state.currentMessageId = undefined;
      });
    },

    setError: (error) => {
      set(state => {
        const msg = state.messages.find(
          m => m.id === state.currentMessageId
        );
        if (msg) {
          msg.status = "error";
          msg.errorMessage = error;
        }
        state.isGenerating = false;
      });
    },

    clearMessages: () => set(state => {
      state.messages = [];
      state.isGenerating = false;
    }),
  }))
);
```

#### 智能滚动逻辑

```typescript
// renderer/src/hooks/useSmartScroll.ts

import { useRef, useCallback, useState, useEffect } from "react";

export function useSmartScroll(deps: any[]) {
  const containerRef = useRef<HTMLDivElement>(null);
  const [isUserScrolling, setIsUserScrolling] = useState(false);
  const [showScrollButton, setShowScrollButton] = useState(false);
  const autoScrollRef = useRef(true);

  // 检测用户是否上滚
  const handleScroll = useCallback(() => {
    const el = containerRef.current;
    if (!el) return;

    const distanceFromBottom =
      el.scrollHeight - el.scrollTop - el.clientHeight;

    autoScrollRef.current = distanceFromBottom < 200;
    setIsUserScrolling(!autoScrollRef.current);
    setShowScrollButton(distanceFromBottom > 200);
  }, []);

  // 内容更新时自动滚动
  useEffect(() => {
    if (autoScrollRef.current && containerRef.current) {
      containerRef.current.scrollTo({
        top: containerRef.current.scrollHeight,
        behavior: "smooth",
      });
    }
  }, deps); // deps 通常是 messages.length

  const scrollToBottom = useCallback(() => {
    containerRef.current?.scrollTo({
      top: containerRef.current.scrollHeight,
      behavior: "smooth",
    });
    autoScrollRef.current = true;
  }, []);

  return {
    containerRef,
    isUserScrolling,
    showScrollButton,
    scrollToBottom,
    onScroll: handleScroll,
  };
}
```

#### Markdown 渲染（含增量优化）

```tsx
// renderer/src/components/chat/MarkdownRenderer.tsx

import React, { useMemo } from "react";
import ReactMarkdown from "react-markdown";
import remarkGfm from "remark-gfm";
import rehypeHighlight from "rehype-highlight"; // 或 Shiki
import { CodeBlock } from "./CodeBlock";

interface MarkdownRendererProps {
  content: string;
  isStreaming?: boolean;  // 流式时优化渲染策略
}

export const MarkdownRenderer: React.FC<MarkdownRendererProps> = ({
  content,
  isStreaming,
}) => {
  // 流式输出时：减少不必要的 Markdown 解析
  // 策略：只在遇到换行或 Markdown 语法标记时才更新解析结果
  const stableContent = useMemo(() => {
    if (!isStreaming) return content;
    // 流式时去掉末尾不完整的行/标记
    const lastNewline = content.lastIndexOf("\n");
    return lastNewline > 0
      ? content.slice(0, lastNewline) + "\n"
      : content;
  }, [content, isStreaming]);

  return (
    <ReactMarkdown
      remarkPlugins={[remarkGfm]}
      components={{
        code({ node, className, children, ...props }) {
          const match = /language-(\w+)/.exec(className || "");
          const isInline = !match && !String(children).includes("\n");

          if (isInline) {
            return (
              <code className="px-1 py-0.5 rounded bg-gray-100 dark:bg-gray-700 text-sm" {...props}>
                {children}
              </code>
            );
          }

          return (
            <CodeBlock
              language={match ? match[1] : ""}
              code={String(children).replace(/\n$/, "")}
            />
          );
        },
      }}
    >
      {stableContent}
    </ReactMarkdown>
  );
};
```

#### 代码块组件

```tsx
// renderer/src/components/chat/CodeBlock.tsx

import React, { useState } from "react";
import { Copy, Check } from "lucide-react";

interface CodeBlockProps {
  language: string;
  code: string;
}

export const CodeBlock: React.FC<CodeBlockProps> = ({ language, code }) => {
  const [copied, setCopied] = useState(false);

  const handleCopy = async () => {
    await navigator.clipboard.writeText(code);
    setCopied(true);
    setTimeout(() => setCopied(false), 2000);
  };

  return (
    <div className="relative group my-3 rounded-lg border border-gray-200 dark:border-gray-700 overflow-hidden">
      {/* 顶部栏：语言标识 + 复制按钮 */}
      <div className="flex items-center justify-between px-4 py-2 bg-gray-50 dark:bg-gray-800 border-b border-gray-200 dark:border-gray-700">
        <span className="text-xs text-gray-500 font-mono">
          {language || "text"}
        </span>
        <button
          onClick={handleCopy}
          className="p-1 rounded hover:bg-gray-200 dark:hover:bg-gray-700 text-gray-400 hover:text-gray-600 transition-colors"
          title="复制代码"
        >
          {copied ? <Check size={14} /> : <Copy size={14} />}
        </button>
      </div>

      {/* 代码高亮区域 */}
      <pre className="p-4 overflow-x-auto text-sm leading-relaxed">
        <code className={`language-${language}`}>{code}</code>
      </pre>
    </div>
  );
};
```

## UI/UX 规范

- **消息气泡**：用户消息右对齐 `bg-blue-600` 白色文字，AI 消息左对齐白色/灰色背景，最大宽度 80%
- **代码块**：圆角 8px，灰色背景（`bg-gray-50`），预包裹 `<pre>` 使用等宽字体 `JetBrains Mono`
- **复制按钮**：默认隐藏（`opacity-0`），hover 代码块区域时显示（`group-hover:opacity-100`），点击后变为对勾图标 2 秒
- **流式光标**：CSS 动画闪烁（`animate-pulse`），宽度 2px，高度与行内文字一致，蓝色
- **滚动到底部按钮**：固定在消息区域右下角，半透明圆形按钮 + 向下箭头图标
- **"正在思考..." 指示器**：浅灰色文字 + 三点跳动动画，位于消息列表底部
- **Agent 标识**：小型图标（20px）+ Agent 名称，颜色使用 Agent 配置的主题色
