# F1.11 — Diff 审查与 Checkpoint 回滚

> **Phase**: Phase 1 — 基础底座 + 代码安全
> **Priority**: P0
> **Status**: In Progress
> **Dependencies**: F1.6 (工具权限确认)

## 概述

Agent 修改代码后的审查机制是 Agent Buddy 安全体系的核心防线。用户必须拥有对 Agent 所有文件变更的可控审查能力——不接受全盘接受/全盘拒绝的粗暴模式，而是支持逐 hunk（代码块变更）级别的审查、修改和选择性应用。

本功能实现两套机制：**Checkpoint（快照回滚）** 和 **Diff 审查**。在 `beforeToolCall` 钩子中，系统自动为即将修改的文件创建 Checkpoint（保存文件当前状态的完整快照）；在 `afterToolCall` 钩子中，系统生成结构化 Diff 并在 UI 中展示。用户可以在侧边面板或消息内的 Inline Diff（F1.13）中查看每个 hunk 的变更，逐行决定 accept / reject。

Checkpoint 时间线允许用户回滚到任意历史节点——当 Agent 的修改方向不对时，可以立即恢复到某个 Checkpoint，而非从头开始。可视化 Diff 以统一 diff 格式展示，新增行绿底、删除行红底、修改行黄底，与 GitHub 的 PR review 体验一致。

## V2 需求调整：写入即生成可审查变更

V2 首轮将审查链直接接入 F1.6 的 `write` 与 `edit`：用户授权后、真正写盘前，主进程以相对项目路径创建 Checkpoint；写盘后生成持久化 `Changeset` 并在右侧上下文显示。用户可接受记录、拒绝并恢复该文件，或按 Checkpoint 回滚该节点及其后的文件快照。快照和审查数据保存在用户目录，不写入项目仓库。

### V2 验收（首轮实现进度）

- [x] `write`/`edit` 在实际写入前创建带时间、工具、描述、文件快照和 SHA-256 的主进程 Checkpoint；权限拒绝或写入失败不会保留无效快照。
- [x] 写入后生成持久化单文件 `Changeset`、增删行数和结构化 hunk，并将 Checkpoint/Changeset ID 记录到 `file_change` 工作事件。
- [x] 右侧面板展示待审文件、统一 hunk 视图、绿/红增删行、接受/拒绝按钮与最近 Checkpoint；拒绝 hunk 会由主进程恢复文件。
- [x] Checkpoint 回滚会恢复目标节点及其后的最早快照文件；创建后文件会被删除。

### 功能验收

- [ ] `beforeToolCall` 钩子自动创建 Checkpoint，保存即将修改的文件当前状态
- [ ] Checkpoint 记录：id / timestamp / description / files(changed) / trigger(agent|user)
- [ ] `afterToolCall` 钩子生成结构化 Diff（unified diff format）
- [ ] UI 侧边面板展示可视化 Diff（文件列表 + 每个文件的 hunk 列表）
- [ ] 逐 hunk accept / reject 按钮
- [ ] "全部接受" / "全部回滚" 快捷操作按钮
- [ ] Checkpoint 时间线展示，可点击回滚到任意节点
- [ ] 回滚操作：恢复 Checkpoint 时的文件内容
- [ ] 可视化 Diff 颜色：新增(绿底)、删除(红底)、修改(黄底)
- [ ] accept 的 hunk 保留在文件，reject 的 hunk 恢复原内容
- [ ] 内联编辑能力（用户可微调 Agent 改动）

### 非功能验收

- [ ] 文件快照使用内容 hash 存储，相同内容不重复存储
- [ ] Checkpoint 过期清理策略（30 分钟后自动清理，或手动清理）
- [ ] Diff 生成使用 Git 内置的 diff 算法（与 Git 统一视图一致）
- [ ] 大型文件（>5000 行）的 Diff 生成 < 500ms

## 技术设计

### 数据模型

```typescript
// Checkpoint（文件快照节点）
interface Checkpoint {
  id: string;
  sessionId: string;
  timestamp: number;
  description: string; // 描述，如 "Agent 修改 src/utils.ts"
  files: FileSnapshot[]; // 变更前的文件快照
  trigger: "agent" | "user";
  toolName?: string; // 触发此 Checkpoint 的工具名
  revertedFrom?: string; // 如果是从回滚操作的恢复，记录来源
}

interface FileSnapshot {
  path: string; // 相对项目根路径
  content: string; // 变更前的完整文件内容
  hash: string; // SHA-256 内容哈希
  size: number; // 文件大小 (bytes)
}

// 变更集
interface Changeset {
  id: string;
  sessionId: string;
  checkpointId?: string; // 从哪个 Checkpoint 计算
  files: FileChange[];
  totalAdditions: number;
  totalDeletions: number;
  createdAt: number;
}

interface FileChange {
  path: string;
  status: "added" | "modified" | "deleted" | "renamed";
  oldPath?: string; // 重命名时的原路径
  additions: number;
  deletions: number;
  hunks: DiffHunk[];
}

interface DiffHunk {
  index: number;
  oldStart: number;
  oldLines: number;
  newStart: number;
  newLines: number;
  header: string; // "@@ -1,5 +1,7 @@"
  lines: DiffLine[];
  decision: "pending" | "accept" | "reject";
}

interface DiffLine {
  type: "context" | "addition" | "deletion";
  content: string;
  oldLineNumber?: number;
  newLineNumber?: number;
}

// Checkpoint 审查状态
interface CheckpointReviewState {
  changesets: Changeset[]; // 所有变更集
  activeChangesetId?: string; // 当前正在审查的变更集
  decisions: Map<string, DiffHunk>; // hunk 级别的决策
  isReviewing: boolean; // 是否正在审查中
}
```

### 关键实现逻辑

#### Checkpoint 管理器

```typescript
// main/change/checkpoint-manager.ts

import * as fs from "fs";
import * as path from "path";
import { createHash } from "crypto";

class CheckpointManager {
  private checkpoints: Map<string, Checkpoint[]> = new Map(); // sessionId → checkpoints

  /**
   * 为即将修改的文件创建 Checkpoint
   * 在 beforeToolCall 钩子中调用
   */
  createCheckpoint(
    sessionId: string,
    description: string,
    files: string[], // 工具将修改的文件列表
    trigger: "agent" | "user" = "agent",
  ): Checkpoint {
    const snapshots: FileSnapshot[] = [];

    for (const filePath of files) {
      try {
        const content = fs.readFileSync(filePath, "utf-8");
        const hash = createHash("sha256").update(content).digest("hex");
        const size = Buffer.byteLength(content, "utf-8");

        snapshots.push({ path: filePath, content, hash, size });
      } catch {
        // 文件不存在（即将创建），不需要快照
      }
    }

    const checkpoint: Checkpoint = {
      id: `cp_${Date.now()}_${Math.random().toString(36).slice(2, 7)}`,
      sessionId,
      timestamp: Date.now(),
      description,
      files: snapshots,
      trigger,
    };

    // 存储到会话的 Checkpoint 列表中
    const sessionCheckpoints = this.checkpoints.get(sessionId) || [];
    sessionCheckpoints.push(checkpoint);
    this.checkpoints.set(sessionId, sessionCheckpoints);

    return checkpoint;
  }

  /**
   * 回滚到指定 Checkpoint
   */
  rollback(sessionId: string, checkpointId: string): void {
    const sessionCheckpoints = this.checkpoints.get(sessionId);
    if (!sessionCheckpoints) throw new Error("No checkpoints found");

    // 找到目标 Checkpoint 的索引
    const targetIndex = sessionCheckpoints.findIndex(
      (cp) => cp.id === checkpointId,
    );
    if (targetIndex === -1)
      throw new Error(`Checkpoint "${checkpointId}" not found`);

    // 收集从目标 Checkpoint 之后的所有快照文件
    const filesToRestore = new Set<string>();
    for (let i = targetIndex; i < sessionCheckpoints.length; i++) {
      for (const snap of sessionCheckpoints[i].files) {
        filesToRestore.add(snap.path);
      }
    }

    // 从目标 Checkpoint 中恢复文件
    const targetCheckpoint = sessionCheckpoints[targetIndex];
    for (const filePath of filesToRestore) {
      const snapshot = targetCheckpoint.files.find((s) => s.path === filePath);
      if (snapshot) {
        fs.writeFileSync(filePath, snapshot.content, "utf-8");
      } else {
        // 目标 Checkpoint 中没有此文件的快照 → 文件在 Checkpoint 之后才创建 → 删除
        if (fs.existsSync(filePath)) {
          fs.unlinkSync(filePath);
        }
      }
    }

    // 移除回滚点之后的 Checkpoint（它们已经被撤销）
    sessionCheckpoints.splice(targetIndex + 1);
    this.checkpoints.set(sessionId, sessionCheckpoints);
  }

  /**
   * 生成 Checkpoint 描述
   */
  generateDescription(toolName: string, params: Record<string, any>): string {
    switch (toolName) {
      case "write":
        return `写入文件 ${params.file_path}`;
      case "edit":
        return `编辑 ${params.file_path}: ${(params.old_string as string).slice(0, 30)}...`;
      case "bash":
        return `执行命令: ${(params.command as string).slice(0, 50)}`;
      default:
        return `${toolName} 操作`;
    }
  }

  /**
   * 获取会话的 Checkpoint 时间线
   */
  listCheckpoints(sessionId: string): Checkpoint[] {
    return this.checkpoints.get(sessionId) || [];
  }

  /**
   * 清理会话的所有 Checkpoint
   */
  clearSession(sessionId: string): void {
    this.checkpoints.delete(sessionId);
  }

  /**
   * 过期清理（可定时执行）
   */
  cleanExpired(maxAge: number = 30 * 60 * 1000): void {
    const now = Date.now();
    for (const [sessionId, checkpoints] of this.checkpoints.entries()) {
      const filtered = checkpoints.filter((cp) => now - cp.timestamp < maxAge);
      if (filtered.length === 0) {
        this.checkpoints.delete(sessionId);
      } else {
        this.checkpoints.set(sessionId, filtered);
      }
    }
  }
}

export const checkpointManager = new CheckpointManager();
```

#### Diff 生成器

```typescript
// main/change/diff-generator.ts

import { execSync } from "child_process";
import * as fs from "fs";
import * as tmp from "tmp";

class DiffGenerator {
  /**
   * 生成两个文件内容之间的 Diff
   * @param oldContent Checkpoint 时保存的原始内容
   * @param newContent 修改后的文件内容
   * @param filePath 文件路径标识
   */
  generateFromContents(
    oldContent: string,
    newContent: string,
    filePath: string,
  ): DiffResult {
    // 创建临时文件用 Git diff
    const oldFile = tmp.fileSync();
    const newFile = tmp.fileSync();

    fs.writeFileSync(oldFile.name, oldContent, "utf-8");
    fs.writeFileSync(newFile.name, newContent, "utf-8");

    try {
      const output = execSync(
        `git diff --no-index --unified=3 "${oldFile.name}" "${newFile.name}"`,
        { encoding: "utf-8", maxBuffer: 50 * 1024 * 1024 },
      );

      return this.parseDiff(output, filePath);
    } finally {
      oldFile.removeCallback();
      newFile.removeCallback();
    }
  }

  /**
   * 从 Checkpoint 和当前文件生成 Changeset
   */
  generateChangeset(sessionId: string, checkpointId?: string): Changeset {
    const checkpoint = checkpointId
      ? checkpointManager
          .listCheckpoints(sessionId)
          .find((cp) => cp.id === checkpointId)
      : checkpointManager.listCheckpoints(sessionId).at(-1);

    if (!checkpoint) {
      return {
        id: `cs_${Date.now()}`,
        sessionId,
        files: [],
        totalAdditions: 0,
        totalDeletions: 0,
        createdAt: Date.now(),
      };
    }

    const files: FileChange[] = [];
    let totalAdditions = 0;
    let totalDeletions = 0;

    for (const snapshot of checkpoint.files) {
      const currentContent = fs.existsSync(snapshot.path)
        ? fs.readFileSync(snapshot.path, "utf-8")
        : "";

      const diff = this.generateFromContents(
        snapshot.content,
        currentContent,
        snapshot.path,
      );

      files.push({
        path: snapshot.path,
        status: snapshot.content === currentContent ? "modified" : "modified",
        additions: diff.additions,
        deletions: diff.deletions,
        hunks: diff.hunks.map((hunk, index) => ({
          ...hunk,
          index,
          decision: "pending" as const,
        })),
      });

      totalAdditions += diff.additions;
      totalDeletions += diff.deletions;
    }

    return {
      id: `cs_${Date.now()}`,
      sessionId,
      checkpointId: checkpoint.id,
      files,
      totalAdditions,
      totalDeletions,
      createdAt: Date.now(),
    };
  }

  /**
   * 解析 Git unified diff 格式
   */
  private parseDiff(
    rawDiff: string,
    filePath: string,
  ): {
    hunks: Omit<DiffHunk, "index" | "decision">[];
    additions: number;
    deletions: number;
  } {
    const lines = rawDiff.split("\n");
    const hunks: Omit<DiffHunk, "index" | "decision">[] = [];
    let currentHunk: Omit<DiffHunk, "index" | "decision"> | null = null;
    let additions = 0;
    let deletions = 0;
    let oldLineNum = 0;
    let newLineNum = 0;

    const hunkHeaderRegex = /^@@ -(\d+),?(\d+)? \+(\d+),?(\d+)? @@(.*)/;

    for (const line of lines) {
      const match = line.match(hunkHeaderRegex);

      if (match) {
        if (currentHunk) hunks.push(currentHunk);

        currentHunk = {
          oldStart: parseInt(match[1]),
          oldLines: parseInt(match[2] || "1"),
          newStart: parseInt(match[3]),
          newLines: parseInt(match[4] || "1"),
          header: line,
          lines: [],
        };

        oldLineNum = currentHunk.oldStart;
        newLineNum = currentHunk.newStart;
        continue;
      }

      if (!currentHunk) continue;

      if (line.startsWith("+") && !line.startsWith("+++")) {
        currentHunk.lines.push({
          type: "addition",
          content: line.slice(1),
          newLineNumber: newLineNum++,
        });
        additions++;
      } else if (line.startsWith("-") && !line.startsWith("---")) {
        currentHunk.lines.push({
          type: "deletion",
          content: line.slice(1),
          oldLineNumber: oldLineNum++,
        });
        deletions++;
      } else if (line.startsWith(" ") || line === "") {
        currentHunk.lines.push({
          type: "context",
          content: line.slice(1) || "",
          oldLineNumber: oldLineNum++,
          newLineNumber: newLineNum++,
        });
      }
    }

    if (currentHunk && currentHunk.lines.length > 0) {
      hunks.push(currentHunk);
    }

    return { hunks, additions, deletions };
  }

  /**
   * 应用 accept/reject 决策到文件
   */
  applyDecisions(
    filePath: string,
    hunks: DiffHunk[],
    snapshot: FileSnapshot,
  ): void {
    const lines = snapshot.content.split("\n");
    const acceptedHunks = hunks.filter((h) => h.decision === "accept");

    if (acceptedHunks.length === hunks.length) {
      // 全部接受 → 保持当前内容不变
      return;
    }

    if (acceptedHunks.length === 0) {
      // 全部拒绝 → 恢复原始内容
      fs.writeFileSync(filePath, snapshot.content, "utf-8");
      return;
    }

    // 部分接受 → 重建文件内容
    const result: string[] = [];
    let currentOldLine = 1;

    // 按原始行号排序
    const sortedHunks = [...hunks].sort((a, b) => a.oldStart - b.oldStart);

    for (const hunk of sortedHunks) {
      // 复制 hunk 之前的上下文行
      while (currentOldLine < hunk.oldStart) {
        result.push(lines[currentOldLine - 1] || "");
        currentOldLine++;
      }

      if (hunk.decision === "accept") {
        // 接受 → 用新内容
        for (const line of hunk.lines) {
          if (line.type !== "deletion") {
            result.push(line.content);
          }
        }
      } else {
        // 拒绝 → 保留旧内容
        for (const line of hunk.lines) {
          if (line.type !== "addition") {
            result.push(line.content);
          }
        }
      }

      currentOldLine = hunk.oldStart + hunk.oldLines;
    }

    // 复制剩余行
    while (currentOldLine <= lines.length) {
      result.push(lines[currentOldLine - 1] || "");
      currentOldLine++;
    }

    fs.writeFileSync(filePath, result.join("\n"), "utf-8");
  }
}

export const diffGenerator = new DiffGenerator();
```

const HunkView: React.FC<{
  hunk: DiffHunk;
  onAccept: () => void;
  onReject: () => void;
}> = ({ hunk, onAccept, onReject }) => {
  const isPending = hunk.decision === "pending";

  return (
    <div
      className={cn(
        "border-b border-gray-100 dark:border-gray-800",
        hunk.decision === "accept" && "opacity-60",
        hunk.decision === "reject" && "opacity-30 line-through",
      )}
    >
      {/* Hunk 头部 */}
      <div className="flex items-center justify-between px-2 py-1 bg-gray-50 dark:bg-gray-800 text-xs">

        {isPending && (
          <div className="flex gap-1">
            <button
              onClick={onAccept}
              className="p-0.5 rounded hover:bg-green-100 text-green-600"
              title="接受"
            >
              <Check size={14} />
            </button>
            <button
              onClick={onReject}
              className="p-0.5 rounded hover:bg-red-100 text-red-600"
              title="拒绝"
            >
              <X size={14} />
            </button>
          </div>
        )}
      </div>

      {/* Diff 行 */}
      <div className="font-mono text-xs leading-6">
        {hunk.lines.map((line, i) => (
          <div
            key={i}
            className={cn(
              "px-2 whitespace-pre",
              line.type === "addition" &&
                "bg-green-50 dark:bg-green-900/20 text-green-800 dark:text-green-200",
              line.type === "deletion" &&
                "bg-red-50 dark:bg-red-900/20 text-red-800 dark:text-red-200",
              line.type === "context" && "text-gray-600 dark:text-gray-400",
            )}
          >
            <span className="select-none text-gray-400 w-8 inline-block text-right mr-2 text-[10px]">
              {line.type === "addition"
                ? "+"
                : line.type === "deletion"
                  ? "-"
                  : " "}
              {line.newLineNumber || line.oldLineNumber || ""}
            </span>
            {line.content}
          </div>
        ))}
      </div>
    </div>
  );
};

## UI/UX 规范

- **Diff 审查面板**：右侧面板（360px），可折叠，折叠时通过底部通知角标提示有变更待审查
- **Diff 颜色方案**：新增行 `bg-green-50` 绿色文字；删除行 `bg-red-50` 红色文字；上下文行灰色
- **Hunk accept/reject 按钮**：鼠标 hover 到 hunk 时显示（类似 GitHub PR review）
- **检查点时间线**：竖排时间线样式，每个节点显示时间 + 描述，最后一个节点高亮
- **回滚确认**：点击回滚弹出确认对话框 "将恢复 X 个文件到 ${timestamp} 的状态"

## 测试要点

- **单元测试**: Checkpoint 创建/回滚的文件恢复逻辑；Diff 生成和解析；hunk 级别 apply/reject 的正确性
- **集成测试**: beforeToolCall → Checkpoint → 工具执行 → afterToolCall → Diff 生成 的完整链路；回滚后 Agent 能否继续正常工作
- **E2E 测试**: Agent 修改文件 → 侧边面板展示 Diff → 用户 accept 部分 hunk → 文件正确更新
