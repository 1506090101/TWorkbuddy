# F2.3 — Agent 结果展示与切换

> **Phase**: Phase 2 — Agent 编排 + 代码理解
> **Priority**: P1
> **Status**: Not Started
> **Dependencies**: F2.1 (Agent 定义模型与管理)

## 概述

Agent 结果展示与切换功能让用户可以灵活选择 Agent 输出结果的展示方式。当用户拉起一个子 Agent（如代码审核 Agent）执行任务时，Agent 的输出有两种展示模式：主对话模式将结果作为消息直接插入主对话流，主 Agent 和用户都能看到并据此继续工作；侧边面板模式将结果在右侧面板独立展示，不干扰主对话流，用户自行决定是否让主 Agent 处理。

这种双模式设计适应不同使用场景：当子 Agent 的结果需要立即被主 Agent 处理时（如审核意见需要主 Agent 据此修改代码），主对话模式更高效；当子 Agent 的结果仅供用户参考（如文档生成、技术调研），侧边面板模式避免污染主对话上下文。用户可在设置中配置默认模式，也可在每次调用 Agent 时临时选择。

## V2 需求调整：结果是工作事件

Agent 结果展示服务于开发任务，不是第二套聊天窗口。一次 Agent 调用应关联父 `WorkSession`，必要时在独立分支中执行，并通过 `WorkEvent` 持久化流式输出、工具活动、文件变更、测试和最终结果。`inline` 模式将可审查结果回注主工作流，`panel` 模式在右侧结果面板展示；两种模式都必须保留来源 Agent、目标、状态和分支关系。

默认展示模式在设置中保存，每次调用可以临时覆盖。面板结果支持多个结果切换、Markdown/代码展示、运行中切换模式，以及用户明确触发“发送到主工作流”。模式切换不得中断 Agent 执行，也不得绕过权限和主进程持久化。

## 验收标准

### 功能验收
- [ ] 主对话模式：Agent 结果作为 assistant 消息插入主对话流，标注来源 Agent
- [ ] 侧边面板模式：Agent 结果在右侧面板独立展示，不进入主对话流
- [ ] 设置中心可配置默认展示模式（主对话 / 侧边面板）
- [ ] 每次 Agent 调用时可临时选择展示模式（不改变全局默认）
- [ ] 侧边面板模式下，用户可选择"发送到主对话"将结果插入主对话流
- [ ] 主对话模式下，Agent 结果消息显示来源 Agent 的图标和名称
- [ ] 侧边面板模式下，面板标题显示当前 Agent 名称和图标
- [ ] 侧边面板支持流式输出实时展示
- [ ] 侧边面板内容支持 Markdown 渲染和代码高亮
- [ ] 多个 Agent 结果在侧边面板中可切换查看（Tab 或列表）
- [ ] Agent 运行中可在两种模式间实时切换（流式输出不中断）

### 非功能验收
- [ ] 模式切换不中断流式输出
- [ ] 侧边面板流式输出延迟 < 100ms（与主对话模式一致）
- [ ] 侧边面板中 Markdown 渲染性能与主对话一致

```typescript
// shared/types/agent-display.ts

/** Agent 结果展示模式 */
type AgentDisplayMode = "inline" | "panel";

/** Agent 结果展示配置 */
interface AgentDisplayConfig {
  defaultMode: AgentDisplayMode;     // 默认模式
  perAgentOverrides: Record<string, AgentDisplayMode>;  // 按 Agent 覆盖
}

/** Agent 结果面板项 */
interface AgentResultPanelItem {
  id: string;                         // 结果项 ID
  agentId: string;                    // 来源 Agent
  agentName: string;
  agentIcon: string;
  agentColor: string;
  sessionId: string;                  // 分支会话 ID
  content: string;                   // 结果内容（流式更新）
  isStreaming: boolean;
  createdAt: number;
  mergedToChat: boolean;             // 是否已发送到主对话
}

/** Agent 调用时的临时模式选择 */
interface AgentInvocationOptions {
  parentSessionId: string;
  agentId: string;
  displayMode?: AgentDisplayMode;     // 临时覆盖，不设置则使用默认
  prompt: string;                     // 子 Agent 任务
  goalId?: string;                    // 关联父任务目标
}
```

### 关键实现逻辑

**Agent 调用与模式路由**:

```typescript
// main/services/agent-dispatcher.ts

import { AgentDefinition } from "../../shared/types/agent";
import { AgentDisplayMode } from "../../shared/types/agent-display";

export class AgentDispatcher {
  /**
   * 拉起 Agent 执行任务
   * 根据展示模式决定结果路由
   */
  async invokeAgent(opts: {
    parentSessionId: string;
    agentId: string;
    prompt: string;
    displayMode?: AgentDisplayMode;   // 临时覆盖
  }): Promise<{ sessionId: string }> {
    const agent = await this.agentManager.get(opts.agentId);
    
    // 决定展示模式
    const displayMode = opts.displayMode 
      ?? this.displayConfig.perAgentOverrides[opts.agentId]
      ?? this.displayConfig.defaultMode;

    // 创建分支会话（复用 F2.2 的分支系统）
    const { sessionId } = await this.branchManager.createBranch({
      parentSessionId: opts.parentSessionId,
      agentId: opts.agentId,
      branchType: "agent-invocation",
    });

    // 根据展示模式设置事件路由
    if (displayMode === "panel") {
      // 侧边面板模式：Agent 事件推送到面板
      this.agentEventEmitter.on(`agent:event:${sessionId}`, (event) => {
        this.ipcServer.sendToRenderer("agent:panel-event", {
          type: event.type,
          sessionId,
          agentId: opts.agentId,
          agentName: agent.name,
          agentIcon: agent.icon,
          agentColor: agent.color,
          content: event.content,
          isStreaming: event.type === "text-delta",
        });
      });
    } else {
      // 主对话模式：Agent 事件推送到主对话流
      this.agentEventEmitter.on(`agent:event:${sessionId}`, (event) => {
        this.ipcServer.sendToRenderer("agent:event", {
          ...event,
          sessionId: opts.parentSessionId,  // 推送到主会话
          agentId: opts.agentId,
          agentName: agent.name,
          agentIcon: agent.icon,
        });
      });
    }

    // 在分支会话中执行 Agent
    this.executeAgentInBackground(sessionId, agent, opts.prompt);

    return { sessionId };
  }

  /**
   * 将面板结果发送到主对话
   */
  async sendToChat(panelItemId: string): Promise<{ messageId: string }> {
    const item = await this.getPanelItem(panelItemId);
    if (item.mergedToChat) {
      throw new Error("Already sent to chat");
    }

    // 获取分支最后一条 AI 消息
    const branchSession = await this.sessionStore.get(item.sessionId);
    const lastMessage = [...branchSession.messages]
      .reverse()
      .find(m => m.role === "assistant");

    if (!lastMessage) throw new Error("No result to send");

    // 合并到主会话
    const { messageId } = await this.branchManager.mergeBranch({
      sessionId: item.sessionId,
      parentSessionId: branchSession.parentId!,
    });

    // 更新面板项状态
    await this.updatePanelItem(panelItemId, { mergedToChat: true });

    return { messageId };
  }
}
```

**渲染进程状态管理**:

```typescript
// renderer/src/stores/agentResultStore.ts

import { create } from "zustand";
import { AgentResultPanelItem, AgentDisplayMode } from "../../../shared/types/agent-display";

interface AgentResultState {
  panelItems: AgentResultPanelItem[];
  activeItemId: string | null;
  defaultMode: AgentDisplayMode;
  
  // 操作
  addPanelItem: (item: AgentResultPanelItem) => void;
  updatePanelItem: (id: string, update: Partial<AgentResultPanelItem>) => void;
  removePanelItem: (id: string) => void;
  setActiveItem: (id: string) => void;
  setDefaultMode: (mode: AgentDisplayMode) => void;
}

export const useAgentResultStore = create<AgentResultState>((set, get) => ({
  panelItems: [],
  activeItemId: null,
  defaultMode: "inline",
  
  addPanelItem: (item) => set((state) => ({
    panelItems: [...state.panelItems, item],
    activeItemId: item.id,
  })),
  
  updatePanelItem: (id, update) => set((state) => ({
    panelItems: state.panelItems.map(item =>
      item.id === id ? { ...item, ...update } : item
    ),
  })),
  
  removePanelItem: (id) => set((state) => ({
    panelItems: state.panelItems.filter(item => item.id !== id),
    activeItemId: state.activeItemId === id 
      ? state.panelItems[0]?.id ?? null 
      : state.activeItemId,
  })),
  
  setActiveItem: (id) => set({ activeItemId: id }),
  
  setDefaultMode: (mode) => set({ defaultMode: mode }),
}));
```

**面板事件订阅**:

```typescript
// renderer/src/hooks/useAgentPanel.ts

import { useEffect } from "react";
import { useAgentResultStore } from "../stores/agentResultStore";

export function useAgentPanel() {
  const { addPanelItem, updatePanelItem } = useAgentResultStore();

  useEffect(() => {
    // 订阅面板事件
    const unsubscribe = window.electronAPI.onAgentPanelEvent((event) => {
      switch (event.type) {
        case "start":
          addPanelItem({
            id: event.sessionId,
            agentId: event.agentId,
            agentName: event.agentName,
            agentIcon: event.agentIcon,
            agentColor: event.agentColor,
            sessionId: event.sessionId,
            content: "",
            isStreaming: true,
            createdAt: Date.now(),
            mergedToChat: false,
          });
          break;
        
        case "text-delta":
          updatePanelItem(event.sessionId, (prev) => ({
            content: prev.content + event.content,
          }));
          break;
        
        case "done":
          updatePanelItem(event.sessionId, { isStreaming: false });
          break;
      }
    });

    return unsubscribe;
  }, []);
}
```

## UI/UX 规范

- **右侧面板**：Agent 结果在右侧面板（360px 宽，可折叠）展示
- **Tab 切换**：多个 Agent 结果以 Tab 形式切换，每个 Tab 显示 Agent 图标
- **流式输出**：面板中流式文本输出与主对话一致的逐 token 追加和光标动画
- **"发送到主对话"**：面板底部按钮，点击后将结果插入主对话流
- **模式切换**：Agent 运行中，面板顶部有切换按钮可实时切换到主对话模式
- **空状态**：未调用 Agent 时，面板显示引导提示："使用 Ctrl+/ 切换 Agent"
- **Agent 调用时选择**：Ctrl+/ 呼出 Agent 菜单时，选择 Agent 后追加模式选择（Inline / Panel）
