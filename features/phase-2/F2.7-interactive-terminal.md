# F2.7 — 交互式终端

> **Phase**: Phase 2 — Agent 编排 + 代码理解
> **Priority**: P1
> **Status**: Not Started
> **Dependencies**: F0.3 (统一布局系统)

## 概述

交互式终端功能提供持久化的终端会话，解决了 Pi SDK 内置 `bash` 工具只能一次性执行命令、无法处理需要交互输入的命令的问题。通过 node-pty 创建伪终端（pseudo-terminal）进程，Agent 和用户可以共享同一个终端会话，支持启动 dev server 并持续监控输出、进入 REPL 交互式测试代码片段、执行需要输入确认的命令（如 `npm install` 选择选项、`git rebase -i`）。

终端 UI 使用 xterm.js 渲染，支持完整的终端特性（颜色、光标、滚动、选择复制）。终端位于底部面板，可与主对话区切换显示。Agent 在终端中执行的命令和用户手动输入的命令共享同一终端，实现"Agent 运行命令→用户观察输出→用户继续操作"的无缝协作。

- [ ] Agent 和用户共享同一个终端会话
- [ ] 支持 dev server 持续监控（如 `npm run dev` 长时间运行）
- [ ] 支持 REPL 交互式测试（如 `node -i` / `python -i`）
- [ ] 支持需要输入确认的命令（如 `npm install` 选项选择）
- [ ] 多终端会话管理（可创建多个终端，Tab 切换）

- [ ] 终端会话关闭时正确清理 pty 进程

## 技术设计

### 数据模型

```typescript
// shared/types/terminal.ts

/** 终端会话 */
interface TerminalSession {
  id: string;
  cwd: string;                       // 工作目录
  shell: string;                     // shell 类型（bash/zsh/powershell/cmd）
  active: boolean;
  title: string;                     // 终端标签标题
  cols: number;
  rows: number;
  createdAt: number;
}

/** 命令历史 */
interface CommandHistory {
  sessionId: string;
  command: string;
  source: "agent" | "user";          // 谁执行的命令
  timestamp: number;
  exitCode?: number;
}

/** 终端输出（增量获取） */
interface TerminalOutput {
  sessionId: string;
  data: string;                      // 终端输出数据（含 ANSI 转义码）
  cursorPosition?: { row: number; col: number };
  hasMore: boolean;
}

/** 交互式命令执行结果 */
interface CommandResult {
  sessionId: string;
  stdout: string;
  exitCode: number;
  duration: number;
}

/** 终端事件 */
interface TerminalEvent {
  type: "data" | "exit" | "resize";
  sessionId: string;
  data?: string;
  exitCode?: number;
  cols?: number;
  rows?: number;
}
```

### IPC 通道

| 通道 | 方向 | 参数 | 返回值 | 说明 |
|------|------|------|--------|------|
| `terminal:create` | invoke→handle | `{ cwd: string; shell?: string }` | `{ sessionId: string }` | 创建终端会话 |
| `terminal:send-input` | invoke→handle | `{ sessionId: string; input: string }` | `{ success: boolean }` | 发送输入 |
| `terminal:get-output` | invoke→handle | `{ sessionId: string; since?: number }` | `TerminalOutput` | 获取输出 |
| `terminal:resize` | invoke→handle | `{ sessionId: string; cols: number; rows: number }` | `{ success: boolean }` | 调整大小 |
| `terminal:close` | invoke→handle | `{ sessionId: string }` | `{ success: boolean }` | 关闭会话 |
| `terminal:list` | invoke→handle | `{}` | `TerminalSession[]` | 获取所有终端列表 |
| `terminal:data` | handle→invoke | `TerminalEvent` | `void` | 终端数据事件推送（实时输出） |
| `terminal:run-interactive` | invoke→handle | `{ command: string; cwd: string; waitForPrompt?: string; timeout?: number }` | `CommandResult` | Agent 执行交互式命令 |

### 关键实现逻辑

**TerminalManager（主进程，node-pty 管理）**:

```typescript
// main/services/terminal-manager.ts

import { spawn, IPty } from "node-pty";
import { app } from "electron";
import * as os from "os";
import { TerminalSession, TerminalOutput, CommandResult, TerminalEvent } from "../../shared/types/terminal";

export class TerminalManager {
  private sessions: Map<string, {
    pty: IPty;
    session: TerminalSession;
    outputBuffer: string[];        // 输出缓冲区（按行存储）
    commandHistory: CommandHistory[];
  }> = new Map();

  /** 创建终端会话 */
  async createSession(opts: {
    cwd: string;
    shell?: string;
  }): Promise<{ sessionId: string }> {
    const shell = opts.shell || this.getDefaultShell();
    const id = generateId();
    
    const pty = spawn(shell, [], {
      name: "xterm-color",
      cols: 80,
      rows: 24,
      cwd: opts.cwd,
      env: { ...process.env, TERM: "xterm-256color" },
    });

    const session: TerminalSession = {
      id,
      cwd: opts.cwd,
      shell,
      active: true,
      title: `${shell.split("/").pop()} (${id.slice(0, 4)})`,
      cols: 80,
      rows: 24,
      createdAt: Date.now(),
    };

    // 监听 pty 输出，转发到渲染进程
    pty.onData((data: string) => {
      const entry = this.sessions.get(id);
      if (entry) {
        entry.outputBuffer.push(data);
        // 限制缓冲区大小（保留最近 10000 行）
        if (entry.outputBuffer.length > 10000) {
          entry.outputBuffer.shift();
        }
      }
      // 推送到渲染进程
      this.ipcServer.sendToRenderer("terminal:data", {
        type: "data",
        sessionId: id,
        data,
      });
    });

    // 监听 pty 退出
    pty.onExit(({ exitCode }) => {
      this.ipcServer.sendToRenderer("terminal:data", {
        type: "exit",
        sessionId: id,
        exitCode,
      });
      this.sessions.delete(id);
    });

    this.sessions.set(id, {
      pty,
      session,
      outputBuffer: [],
      commandHistory: [],
    });

    return { sessionId: id };
  }

  /** 发送输入到终端 */
  async sendInput(sessionId: string, input: string): Promise<void> {
    const entry = this.sessions.get(sessionId);
    if (!entry) throw new Error(`Terminal session ${sessionId} not found`);
    entry.pty.write(input);
    
    // 记录命令历史（来源标记由调用方决定）
    if (input.includes("\r") || input.includes("\n")) {
      entry.commandHistory.push({
        sessionId,
        command: input.trim(),
        source: "user",  // 从 IPC 调用默认为用户输入
        timestamp: Date.now(),
      });
    }
  }

  /** Agent 执行交互式命令 */
  async runInteractive(opts: {
    command: string;
    cwd: string;
    waitForPrompt?: string;     // 等待的提示符模式
    timeout?: number;           // 超时毫秒
    sessionId?: string;        // 复用已有会话
  }): Promise<CommandResult> {
    // 创建或复用终端会话
    let sessionId = opts.sessionId;
    if (!sessionId || !this.sessions.has(sessionId)) {
      const result = await this.createSession({ cwd: opts.cwd });
      sessionId = result.sessionId;
    }

    const entry = this.sessions.get(sessionId)!;
    const startTime = Date.now();
    let output = "";

    // 设置输出监听
    const outputPromise = new Promise<string>((resolve, reject) => {
      const timer = setTimeout(() => {
        resolve(output);
      }, opts.timeout || 30000);

      const onData = (data: string) => {
        output += data;
        // 检测提示符或命令完成
        if (opts.waitForPrompt && data.includes(opts.waitForPrompt)) {
          clearTimeout(timer);
          entry.pty.removeListener("data", onData);
          resolve(output);
        }
      };
      entry.pty.onData(onData);
    });

    // 发送命令
    entry.pty.write(opts.command + "\r");
    entry.commandHistory.push({
      sessionId,
      command: opts.command,
      source: "agent",
      timestamp: startTime,
    });

    const stdout = await outputPromise;
    const exitCode = 0; // 交互式命令的退出码需要从输出解析

    return {
      sessionId,
      stdout,
      exitCode,
      duration: Date.now() - startTime,
    };
  }

  /** 调整终端大小 */
  async resize(sessionId: string, cols: number, rows: number): Promise<void> {
    const entry = this.sessions.get(sessionId);
    if (!entry) throw new Error(`Terminal session ${sessionId} not found`);
    entry.pty.resize(cols, rows);
    entry.session.cols = cols;
    entry.session.rows = rows;
  }

  /** 关闭终端会话 */
  async closeSession(sessionId: string): Promise<void> {
    const entry = this.sessions.get(sessionId);
    if (!entry) return;
    entry.pty.kill();
    this.sessions.delete(sessionId);
  }

  /** 获取默认 shell */
  private getDefaultShell(): string {
    if (os.platform() === "win32") {
      return process.env.COMSPEC || "cmd.exe";
    }
    return process.env.SHELL || "/bin/bash";
  }

  /** 应用退出时清理所有终端 */
  disposeAll(): void {
    for (const [, entry] of this.sessions) {
      entry.pty.kill();
    }
    this.sessions.clear();
  }
}
```

**渲染进程 xterm.js 集成**:

```typescript
// renderer/src/components/terminal/TerminalView.tsx

import { useEffect, useRef } from "react";
import { Terminal } from "xterm";
import { FitAddon } from "xterm-addon-fit";
import { SearchAddon } from "xterm-addon-search";

export function TerminalView({ sessionId }: { sessionId: string }) {
  const termRef = useRef<HTMLDivElement>(null);
  const xtermRef = useRef<Terminal | null>(null);

  useEffect(() => {
    const term = new Terminal({
      fontSize: 13,
      fontFamily: "JetBrains Mono, Fira Code, monospace",
      cursorBlink: true,
      theme: {
        background: "#1e1e1e",
        foreground: "#d4d4d4",
        cursor: "#d4d4d4",
      },
    });

    const fitAddon = new FitAddon();
    const searchAddon = new SearchAddon();
    term.loadAddon(fitAddon);
    term.loadAddon(searchAddon);
    term.open(termRef.current!);
    fitAddon.fit();

    xtermRef.current = term;

    // 订阅终端数据事件
    const unsubscribe = window.electronAPI.onTerminalData((event: TerminalEvent) => {
      if (event.sessionId === sessionId) {
        if (event.type === "data") {
          term.write(event.data);
        } else if (event.type === "exit") {
          term.write(`\r\n[Process exited with code ${event.exitCode}]\r\n`);
        }
      }
    });

    // 用户输入转发到 pty
    term.onData((data: string) => {
      window.electronAPI.terminalSendInput(sessionId, data);
    });

    // 窗口大小变化时自适应
    const resizeObserver = new ResizeObserver(() => {
      fitAddon.fit();
      window.electronAPI.terminalResize(sessionId, term.cols, term.rows);
    });
    resizeObserver.observe(termRef.current!);

    return () => {
      unsubscribe();
      resizeObserver.disconnect();
      term.dispose();
    };
  }, [sessionId]);

  return <div ref={termRef} className="h-full w-full" />;
}
```

## 备注

- node-pty 和 xterm.js 版本需要匹配 Electron 的 Node.js 版本
- 终端面板与 F0.3 统一布局系统的底部面板共享容器
- Agent 使用终端工具需要用户确认（permissions: "confirm"），因为终端可以执行任意命令
- 应用退出时（app.before-quit）需要调用 disposeAll() 清理所有 pty 进程
