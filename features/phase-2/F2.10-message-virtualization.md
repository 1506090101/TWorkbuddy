# F2.10 — 消息列表虚拟化

> **Phase**: Phase 2 — Agent 编排 + 代码理解
> **Priority**: P1
> **Status**: Not Started
> **Dependencies**: F1.4 (聊天 UI — 消息流)

## 概述

消息列表虚拟化功能解决大量消息时的渲染性能问题。当会话消息达到数百甚至上万条时，传统的全量渲染方式会导致严重的性能问题——每条消息包含 Markdown 渲染、代码高亮、工具调用卡片等复杂内容，DOM 节点数量急剧增长，滚动和交互都会卡顿。

通过使用 `@tanstack/react-virtual` 实现虚拟滚动，只渲染当前可见区域内的消息（加上少量缓冲区），不可见的消息不占用 DOM 节点。同时配合 Markdown 渲染结果缓存（避免重渲染时重新解析 Markdown）和工具调用卡片懒加载（滚动到可见时才渲染详情），即使万条消息也能保持流畅的滚动体验。

## 验收标准

### 功能验收
- [ ] 使用 `@tanstack/react-virtual` 实现虚拟滚动，只渲染可见区域消息
- [ ] 支持动态高度消息（每条消息高度不同，根据内容自动计算）
- [ ] Markdown 渲染结果缓存（同一条消息重渲染时不重新解析 Markdown）
- [ ] 工具调用卡片懒加载（滚动到可见时才渲染详情，不可见时显示摘要）
- [ ] 流式输出消息正确追加和更新（虚拟列表中的最后一条消息动态更新）
- [ ] 自动滚动到底部（新消息时），用户上滚时暂停自动滚动
- [ ] 滚动到底部按钮（用户上滚时显示）
- [ ] 消息搜索结果高亮定位（搜索匹配时滚动到对应位置）
- [ ] 向上加载历史消息（滚动到顶部时加载更早的消息）
- [ ] 代码块语法高亮（Shiki）在虚拟化环境中正常工作
- [ ] 图片附件在虚拟化环境中正确渲染

### 非功能验收
- [ ] 10000 条消息滚动帧率 > 55fps
- [ ] 1000 条消息首次渲染 < 500ms
- [ ] 滚动到任意位置的时间 < 100ms
- [ ] 内存占用：10000 条消息 < 200MB（含 Markdown 缓存）
- [ ] 流式输出时滚动不卡顿

### 关键实现逻辑

**虚拟滚动实现**:

```typescript
// renderer/src/components/chat/VirtualMessageList.tsx

import { useRef, useState, useEffect, useCallback, useMemo } from "react";
import { useVirtualizer } from "@tanstack/react-virtual";
import { Message } from "../../../shared/types/session";
import { MessageBubble } from "./MessageBubble";
import { useMarkdownCache } from "../../hooks/useMarkdownCache";

interface Props {
  messages: Message[];
  isStreaming: boolean;
  streamingContent: string;
  onScrollToTop?: () => void;      // 加载更多历史消息
}

export function VirtualMessageList({
  messages,
  isStreaming,
  streamingContent,
  onScrollToTop,
}: Props) {
  const parentRef = useRef<HTMLDivElement>(null);
  const [scrollState, setScrollState] = useState<ScrollState>({
    isAtBottom: true,
    showScrollToBottom: false,
    firstVisibleIndex: 0,
    lastVisibleIndex: 0,
  });

  // 动态高度测量缓存
  const heightCache = useRef<Map<number, number>>(new Map());

  // 虚拟化
  const virtualizer = useVirtualizer({
    count: messages.length + (isStreaming ? 1 : 0), // +1 为流式消息
    getScrollElement: () => parentRef.current,
    estimateSize: (index) => heightCache.current.get(index) ?? 200, // 估算高度
    measureElement: (elem) => {
      // 动态测量实际高度并缓存
      const height = elem.getBoundingClientRect().height;
      const index = Number(elem.dataset.index);
      heightCache.current.set(index, height);
      return height;
    },
    overscan: 5, // 缓冲区：额外渲染 5 条
    getItemKey: (index) => messages[index]?.id ?? "streaming",
  });

  // 自动滚动到底部
  useEffect(() => {
    if (scrollState.isAtBottom && messages.length > 0) {
      virtualizer.scrollToIndex(messages.length - 1, { align: "end" });
    }
  }, [messages.length, scrollState.isAtBottom]);

  // 滚动事件处理
  const handleScroll = useCallback(() => {
    if (!parentRef.current) return;
    const { scrollTop, scrollHeight, clientHeight } = parentRef.current;
    const isAtBottom = scrollHeight - scrollTop - clientHeight < 50;
    const isAtTop = scrollTop === 0;

    setScrollState((prev) => ({
      ...prev,
      isAtBottom,
      showScrollToBottom: !isAtBottom,
    }));

    // 滚动到顶部时加载更多
    if (isAtTop && onScrollToTop) {
      onScrollToTop();
    }
  }, [onScrollToTop]);

  // 滚动到搜索结果
  const scrollToMessage = useCallback((messageId: string) => {
    const index = messages.findIndex(m => m.id === messageId);
    if (index >= 0) {
      virtualizer.scrollToIndex(index, { align: "center" });
    }
  }, [messages, virtualizer]);

  const virtualItems = virtualizer.getVirtualItems();

  return (
    <div
      ref={parentRef}
      onScroll={handleScroll}
      style={{ overflow: "auto", height: "100%", position: "relative" }}
    >
      {/* 虚拟列表总高度容器 */}
      <div
        style={{
          height: `${virtualizer.getTotalSize()}px`,
          position: "relative",
        }}
      >
        {virtualItems.map((virtualItem) => {
          const message = messages[virtualItem.index];
          const isLastMessage = virtualItem.index === messages.length - 1;
          const isStreamingItem = isStreaming && isLastMessage;

          return (
            <div
              key={virtualItem.key}
              data-index={virtualItem.index}
              ref={virtualizer.measureElement}
              style={{
                position: "absolute",
                top: 0,
                left: 0,
                width: "100%",
                transform: `translateY(${virtualItem.start}px)`,
              }}
            >
              <MessageBubble
                message={message}
                isStreaming={isStreamingItem}
                streamingContent={isStreamingItem ? streamingContent : undefined}
              />
            </div>
          );
        })}
      </div>

      {/* 滚动到底部按钮 */}
      {scrollState.showScrollToBottom && (
        <ScrollToBottomButton
          onClick={() => virtualizer.scrollToIndex(messages.length - 1, { align: "end" })}
        />
      )}
    </div>
  );
}
```

**Markdown 渲染缓存**:

```typescript
// renderer/src/hooks/useMarkdownCache.ts

import { useRef, useCallback } from "react";
import { hashContent } from "../utils/hash";

interface CacheEntry {
  html: string;
  codeBlocks: Map<string, string>;  // codeBlockKey -> highlighted HTML
}

/**
 * Markdown 渲染缓存
 * 同一条消息重渲染时不重新解析 Markdown
 * 缓存键 = messageId + content hash
 */
export function useMarkdownCache() {
  const cache = useRef<Map<string, CacheEntry>>(new Map());
  const maxSize = 500; // 最大缓存条数

  const getCacheKey = useCallback((messageId: string, content: string) => {
    return `${messageId}:${hashContent(content)}`;
  }, []);

  const getCached = useCallback((messageId: string, content: string) => {
    const key = getCacheKey(messageId, content);
    return cache.current.get(key);
  }, [getCacheKey]);

  const setCached = useCallback((messageId: string, content: string, entry: CacheEntry) => {
    const key = getCacheKey(messageId, content);
    
    // LRU 策略：超过最大缓存数时删除最早的
    if (cache.current.size >= maxSize) {
      const firstKey = cache.current.keys().next().value;
      if (firstKey) cache.current.delete(firstKey);
    }
    
    cache.current.set(key, entry);
  }, [getCacheKey]);

  const invalidate = useCallback((messageId: string) => {
    // 删除某条消息的所有缓存版本
    for (const key of cache.current.keys()) {
      if (key.startsWith(`${messageId}:`)) {
        cache.current.delete(key);
      }
    }
  }, []);

  return { getCached, setCached, invalidate };
}
```

**工具调用卡片懒加载**:

```typescript
// renderer/src/components/chat/ToolCallCard.tsx

import { useState, useRef, useEffect } from "react";
import { ToolCall, ToolCardLazyState } from "../../../shared/types/virtual-list";

interface Props {
  toolCall: ToolCall;
  isVisible: boolean;  // 是否在可见区域
}

export function ToolCallCard({ toolCall, isVisible }: Props) {
  const [state, setState] = useState<ToolCardLazyState>({
    isExpanded: false,
    isLoading: false,
  });

  // Intersection Observer 检测可见性
  const ref = useRef<HTMLDivElement>(null);
  const [inViewport, setInViewport] = useState(false);

  useEffect(() => {
    if (!ref.current) return;
    const observer = new IntersectionObserver(
      ([entry]) => setInViewport(entry.isIntersecting),
      { rootMargin: "100px" } // 提前 100px 触发
    );
    observer.observe(ref.current);
    return () => observer.disconnect();
  }, []);

  const handleExpand = () => {
    if (!state.isExpanded) {
      setState({ isExpanded: true, isLoading: true });
      // 懒加载详情（延迟渲染，避免一次性渲染大量详情）
      requestAnimationFrame(() => {
        setState({ isExpanded: true, isLoading: false });
      });
    } else {
      setState({ isExpanded: false, isLoading: false });
    }
  };

  // 不在可见区域时只渲染摘要
  if (!inViewport) {
    return (
      <div ref={ref} className="tool-card-summary">
        <span className="tool-name">{toolCall.tool}</span>
        <span className="tool-status">{toolCall.result ? "✓" : "..."}</span>
      </div>
    );
  }

  return (
    <div ref={ref} className="tool-card">
      <div className="tool-card-header" onClick={handleExpand}>
        <ToolIcon name={toolCall.tool} />
        <span className="tool-name">{toolCall.tool}</span>
        <span className="tool-params-summary">
          {summarizeParams(toolCall.params)}
        </span>
        <ChevronIcon expanded={state.isExpanded} />
      </div>
      
      {state.isExpanded && !state.isLoading && (
        <div className="tool-card-detail">
          <div className="tool-params">
            <pre>{JSON.stringify(toolCall.params, null, 2)}</pre>
          </div>
          <div className="tool-result">
            <pre>{toolCall.result}</pre>
          </div>
        </div>
      )}
      
      {state.isLoading && <Spinner />}
    </div>
  );
}

function summarizeParams(params: Record<string, any>): string {
  // 简短摘要：取第一个关键参数的值
  const keys = Object.keys(params);
  if (keys.length === 0) return "";
  const firstKey = keys[0];
  const value = String(params[firstKey]);
  return value.length > 50 ? value.slice(0, 50) + "..." : value;
}
```

**流式消息处理**:

```typescript
// renderer/src/components/chat/StreamingMessage.tsx

/**
 * 流式输出消息的特殊处理
 * 在虚拟列表中作为最后一项，高度动态变化
 * 需要触发虚拟化器重新测量高度
 */
export function StreamingMessage({ content }: { content: string }) {
  const ref = useRef<HTMLDivElement>(null);
  const prevLength = useRef(0);

  useEffect(() => {
    // 内容变化时通知虚拟化器重新测量
    if (ref.current && content.length !== prevLength.current) {
      // 触发 ResizeObserver 或手动通知
      const event = new Event("resize");
      window.dispatchEvent(event);
      prevLength.current = content.length;
    }
  }, [content]);

  return (
    <div ref={ref}>
      <MarkdownRenderer content={content} isStreaming={true} />
      <StreamingCursor />
    </div>
  );
}
```

## 开放问题

1. 动态高度测量的性能开销——每次内容变化都重新测量，是否需要防抖或批量测量？
2. Markdown 缓存的内存管理——500 条缓存是否合理？是否需要基于内存使用量动态调整？
3. 向上加载历史消息时如何保持滚动位置不跳动——需要在加载前记录位置，加载后恢复偏移量

## 备注

- 此功能是 F1.4 聊天 UI 的性能优化升级，不改变消息展示效果，只改变渲染机制
- `@tanstack/react-virtual` 替代 F1.4 中预留的虚拟化接口
- Markdown 渲染缓存使用 LRU 策略，避免无限增长内存
- 虚拟列表的 overscan（缓冲区）设为 5 条，平衡渲染性能和滚动流畅度
- 流式输出消息作为虚拟列表的最后一项，需要特殊处理高度动态变化
