# F2.1 — Agent 定义与工作台切换

> **Phase**: Phase 2 — Agent 编排 + 代码理解
> **Priority**: P0
> **Status**: In Progress
> **Dependencies**: F1.1 (多 Provider 注册表), F1.3 (Pi SDK 集成与 Session 管理), F1.8 (模型分配与会话覆盖)

## 概述

Agent 定义模型与管理是 Phase 2 的核心基础设施。它定义了"什么是 Agent"的类型系统，提供了创建、编辑、删除 Agent 的完整管理界面，并支持通过 Markdown 格式导出和导入 Agent 定义，实现版本管理和分享。

在 Agent Buddy 中，Agent 不是一个简单的"角色选择"下拉框，而是一个完整的定义实体——包含模型分配（Chat/Vision/ThinkingLevel）、系统提示词、可用工具范围、加载的 Skills、触发条件等维度。不同的 Agent 适用于不同的任务场景：主 Agent 负责日常开发编码，代码审核 Agent 只用只读工具审查代码，测试生成 Agent 读取代码并写入测试文件，文档生成 Agent 生成和更新文档。

产品内置 4 个预设 Agent，用户可以修改或删除它们，也可以从零创建自定义 Agent。Agent 定义以 Markdown 文件（frontmatter + 正文）格式存储，支持双向同步——UI 表单编辑后自动更新 Markdown 文件，Markdown 文件修改后也能同步到 UI。

### V2 工作台关系

Agent 定义是可复用的能力配置；`WorkSession.activeAgentId` 是当前任务实际使用的 Agent。顶部和 Composer 负责切换当前会话 Agent，右侧面板展示其工具白名单、Skills、插件可用状态和模型来源。切换只影响后续事件，历史事件保留产生它们的 Agent。Agent 白名单永远不能代替 F1.6 的权限确认。

## V2 需求调整：Agent 作为工作上下文

Agent 不只存在于设置页。工作台顶部和 Composer 必须提供当前会话 Agent 的选择与说明；切换 Agent 会更新后续 `ComposerContext` 的 Agent、默认模型、工具范围、Skills 和系统提示，但不重写已发生的工作事件。Agent 的工具/插件可用状态必须在 Composer 和右侧上下文中可见。

```typescript
// shared/types/agent.ts

/** 模型分配 */
interface ModelAssignment {
  chat: string; // "anthropic/claude-sonnet-4" 格式: providerId/modelId
  vision?: string; // 可选，Vision 模型
  thinking: "off" | "low" | "medium" | "high";
}

/** 触发条件配置 */
interface TriggerConfig {
  type: "manual" | "keyword" | "event";
  value?: string; // keyword 类型时的关键词，event 类型时的事件名
}

/** Agent 定义 */
interface AgentDefinition {
  id: string; // 如 "code-reviewer"
  name: string; // "代码审核专家"
  description: string; // "审核代码变更，给出改进建议"
  modelAssignment: ModelAssignment;
  systemPrompt: string; // 系统提示词正文
  tools: string[]; // ["read", "grep", "ls"] — 可用工具范围
  skills: string[]; // ["code-review-standards.md"] — 加载的 Skills 文件名
  triggers: TriggerConfig[]; // 触发条件列表
  icon: string; // Lucide 图标名，如 "shield-check"
  color: string; // 主题色 hex，如 "#534AB7"
  isDefault: boolean; // 是否为主 Agent
}

/** Agent 列表项（用于 UI 展示） */
interface AgentListItem {
  id: string;
  name: string;
  description: string;
  icon: string;
  color: string;
  isDefault: boolean;
  toolsCount: number;
  triggers: string[]; // 触发类型简述
}

/** 预设 Agent 定义 */
interface PresetAgent {
  definition: AgentDefinition;
  canDelete: boolean; // 主 Agent = false
  canEdit: boolean;
}
```

### 关键实现逻辑

**Agent 定义的存储与加载**:

```typescript
// main/services/agent-manager.ts

import { app } from "electron";
import * as path from "path";
import * as fs from "fs/promises";
import { AgentDefinition, AgentListItem } from "../../shared/types/agent";

const AGENTS_DIR = path.join(app.getPath("home"), ".agentbuddy", "agents");

export class AgentManager {
  private agents: Map<string, AgentDefinition> = new Map();
  private fileWatchers: Map<string, fs.FSWatcher> = new Map();

  /** 初始化：加载所有 Agent 定义文件 */
  async initialize(): Promise<void> {
    await fs.mkdir(AGENTS_DIR, { recursive: true });

    // 加载已有 Agent 文件
    const files = await fs.readdir(AGENTS_DIR);
    for (const file of files) {
      if (file.endsWith(".md")) {
        const content = await fs.readFile(path.join(AGENTS_DIR, file), "utf-8");
        const agent = this.parseMarkdown(content);
        if (agent) {
          this.agents.set(agent.id, agent);
          this.watchFile(file);
        }
      }
    }

    // 确保预设 Agent 存在
    await this.ensurePresetAgents();
  }

  /** 解析 Markdown 为 AgentDefinition */
  parseMarkdown(content: string): AgentDefinition | null {
    const frontmatterMatch = content.match(/^---\n([\s\S]*?)\n---\n([\s\S]*)$/);
    if (!frontmatterMatch) return null;

    const [, frontmatterText, body] = frontmatterMatch;
    const fm = this.parseFrontmatter(frontmatterText);

    return {
      id: fm.id,
      name: fm.name,
      description: fm.description,
      modelAssignment: {
        chat: fm.model?.chat || "",
        vision: fm.model?.vision,
        thinking: fm.model?.thinking || "off",
      },
      systemPrompt: body.trim(),
      tools: fm.tools || [],
      skills: fm.skills || [],
      triggers: (fm.triggers || ["manual"]).map((t: string) => ({
        type: t as "manual" | "keyword" | "event",
      })),
      icon: fm.icon || "bot",
      color: fm.color || "#3b82f6",
      isDefault: fm.isDefault === true,
    };
  }

  /** 将 AgentDefinition 序列化为 Markdown */
  serializeMarkdown(agent: AgentDefinition): string {
    const model = agent.modelAssignment;
    const frontmatter = [
      "---",
      `id: ${agent.id}`,
      `name: ${agent.name}`,
      `description: ${agent.description}`,
      `model:`,
      `  chat: ${model.chat}`,
      model.vision ? `  vision: ${model.vision}` : null,
      `  thinking: ${model.thinking}`,
      `tools: [${agent.tools.join(", ")}]`,
      agent.skills.length ? `skills: [${agent.skills.join(", ")}]` : null,
      `triggers: [${agent.triggers.map((t) => t.type).join(", ")}]`,
      `icon: ${agent.icon}`,
      `color: "${agent.color}"`,
      agent.isDefault ? `isDefault: true` : null,
      "---",
      "",
      agent.systemPrompt,
    ]
      .filter(Boolean)
      .join("\n");

    return frontmatter;
  }

  /** 监听文件变化（实现双向同步） */
  private watchFile(filename: string): void {
    const filePath = path.join(AGENTS_DIR, filename);
    const watcher = fs.watch(filePath, async (eventType) => {
      if (eventType === "change") {
        const content = await fs.readFile(filePath, "utf-8");
        const agent = this.parseMarkdown(content);
        if (agent) {
          this.agents.set(agent.id, agent);
          // 通知渲染进程
          this.notifyChange(agent.id);
        }
      }
    });
    this.fileWatchers.set(filename, watcher);
  }
}
```

```typescript
/** 根据 Agent 定义创建 AgentSession */
async function createAgentSessionFromDefinition(
  agent: AgentDefinition,
  providerManager: ProviderManager,
): Promise<AgentSession> {
  const [providerId, modelId] = agent.modelAssignment.chat.split("/");
  const provider = providerManager.getProvider(providerId);

  const session = await createAgentSession({
    model: modelId,
    thinkingLevel: agent.modelAssignment.thinking,
    tools: agent.tools, // 限制工具范围
    customTools: [], // 自定义工具在 F7.2 实现
    sessionManager: SessionManager.inMemory(),
    env: {
      [provider.envKey]: provider.apiKey, // 环境变量注入 API Key
      // baseURL 注入...
    },
  });

  // 注入系统提示词
  if (agent.systemPrompt) {
    await session.steer({ systemPrompt: agent.systemPrompt });
  }

  return session;
}
```

## UI/UX 规范

- **Agent 管理面板**：位于设置中心 Tab 3，采用列表+编辑双栏布局
- **Agent 卡片**：圆角卡片，左侧图标（带 Agent 主题色背景），右侧名称 + 描述 + 操作按钮

- **Markdown 预览**：编辑表单右侧实时展示 Markdown 预览，修改即时反映
- **图标选择器**：弹出网格面板，展示 Lucide 图标库，支持搜索过滤
- **颜色选择器**：提供预设色板（8色）+ 自定义 hex 输入
- **快速切换菜单**：Ctrl+/ 触发，浮动面板列出所有 Agent，键盘上下选择，Enter 确认
