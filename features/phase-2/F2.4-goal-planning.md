# F2.4 — 会话目标与目标规划编排

> **Phase**: Phase 2 — Agent 编排 + 代码理解
> **Priority**: P0
> **Status**: V2 首轮扩展已实现
> **Dependencies**: F2.1 (Agent 定义模型与管理), F2.2 (会话分支系统)

## 概述

目标规划编排功能让 Agent 能够将用户给出的高层目标自动拆解为可执行的子任务序列，跟踪每个任务的执行状态，并支持将子任务委派给其他专门的 Agent 执行。例如用户提出"帮我实现完整的用户登录注册功能"，Agent 会拆解为 8 个子任务：分析项目结构→设计数据模型→实现注册 API→实现登录 API→实现前端注册页→实现前端登录页→编写单元测试→集成测试。

任务系统支持四种编排策略：顺序执行（依赖链）、并行执行（独立任务）、条件分支（根据结果选择路径）、子 Agent 委派（交给专家 Agent）。任务面板 UI 实时展示任务列表、进度条和状态更新，用户可以手动干预——跳过任务、重新排序、修改任务内容。这使得 Agent 的工作过程透明可控，而非黑盒执行。

## V2 需求调整：先建立会话目标

复杂规划前，V2 先提供轻量的会话级 `Goal`：用户可从 Composer 创建、编辑或关联目标；目标与状态始终显示在顶部和右侧面板。F2.4 在这个稳定锚点之上扩展自动拆解、步骤、依赖、委派和编排，而不会把一次性 prompt 误当成长期任务。

`Goal` 是主工作台的任务锚点，不是聊天消息的附属字段。用户可以在新建任务时设置目标，也可以在工作过程中编辑、停止或重新规划；中央时间线中的任务、工具、变更和测试事件通过 `goalId` 与目标关联。后续自动拆解、并行执行和子 Agent 委派必须复用同一 `WorkSession`、`Goal` 和 `WorkEvent` 模型。

### V2 验收（首轮实现进度）

- [x] 主进程持久化 `Goal`：标题、描述、状态、会话 ID、可选步骤和完成结果。
- [x] Composer 和右侧面板可创建、编辑、关联当前会话目标；更新即时反映在顶部上下文栏和右侧目标面板。
- [x] 目标状态支持 `draft`、`active`、`blocked`、`completed`，状态变化写入 `WorkEvent`。
- [x] 首轮目标可没有步骤；启用规划后，步骤/任务仍与同一 `Goal` 和 `WorkSession` 关联。
- [x] 目标面板显示步骤进度与阻塞状态，允许用户修改目标、步骤和步骤状态。
- [x] 为目标补充停止、重新规划、阻塞原因和关联事件筛选。
- [ ] 子 Agent 委派、并行编排和复杂依赖必须保留为后续 F2.4 交付，不阻塞首轮会话目标使用。

### 当前实现边界

首轮将 `Goal` 作为 `WorkSession` 的持久化上下文：步骤按会话保存，完成比例由已完成步骤计算；目标状态、阻塞原因、停止/重新规划和步骤调整由主进程生成可审查 `WorkEvent`。每个新工作事件携带当前 `goalId`，中央时间线可筛选目标关联活动。此实现不包含自动计划工具、依赖关系、委派、分支或 SQLite 任务表，后续编排能力必须在该稳定会话锚点上扩展。

### 数据模型

```typescript
// shared/types/task.ts

/** 任务状态 */
type TaskStatus =
  "pending" | "in_progress" | "completed" | "blocked" | "failed";

/** 任务 */
interface Task {
  id: string;
  sessionId: string;
  title: string;
  description?: string;
  status: TaskStatus;
  dependencies: string[]; // 依赖的任务 ID 列表
  assignedAgentId?: string; // 委派的 Agent（如有）
  order: number; // 执行顺序
  result?: string; // 任务结果
  toolCalls?: {
    // 任务执行中的工具调用记录
    tool: string;
    params: Record<string, any>;
    result: string;
    timestamp: number;
  }[];
  branchSessionId?: string; // 委派任务时的分支会话 ID
  createdAt: number;
  updatedAt: number;
}

/** 任务计划（plan 工具的返回） */
interface TaskPlan {
  goal: string; // 原始目标
  tasks: Task[];
  strategy: "sequential" | "parallel" | "conditional" | "delegation";
}

/** 任务进度 */
interface TaskProgress {
  total: number;
  completed: number;
  inProgress: number;
  blocked: number;
  failed: number;
  pending: number;
  percentage: number; // completed / total * 100
}

/** 委派任务结果 */
interface DelegationResult {
  taskId: string;
  branchSessionId: string;
  result: string;
  status: TaskStatus;
}
```

```sql
-- tasks.db

CREATE TABLE tasks (
  id TEXT PRIMARY KEY,
  session_id TEXT NOT NULL,
  title TEXT NOT NULL,
  description TEXT,
  status TEXT DEFAULT 'pending',
  dependencies TEXT,           -- JSON array of task IDs
  assigned_agent_id TEXT,
  "order" INTEGER NOT NULL,
  result TEXT,
  tool_calls TEXT,             -- JSON array
  branch_session_id TEXT,
  created_at INTEGER NOT NULL,
  updated_at INTEGER NOT NULL
);

CREATE INDEX idx_tasks_session ON tasks(session_id);
CREATE INDEX idx_tasks_status ON tasks(status);
CREATE INDEX idx_tasks_order ON tasks("order");
```

**任务管理器**:

```typescript
// main/services/task-manager.ts

export class TaskManager {
  /**
   * 创建任务计划
   * Agent 通过 plan 工具传入拆解的子任务
   */
  async createPlan(opts: {
    sessionId: string;
    goal: string;
    subtasks: Array<{
      title: string;
      description?: string;
      dependsOn?: number[];
      delegateToAgentId?: string;
    }>;
  }): Promise<Task[]> {
    const tasks: Task[] = [];

    for (let i = 0; i < opts.subtasks.length; i++) {
      const st = opts.subtasks[i];
      const dependencies = (st.dependsOn || [])
        .map((idx) => tasks[idx - 1]?.id)
        .filter(Boolean);

      const task: Task = {
        id: generateId(),
        sessionId: opts.sessionId,
        title: st.title,
        description: st.description,
        status: dependencies.length ? "blocked" : "pending",
        dependencies,
        assignedAgentId: st.delegateToAgentId,
        order: i,
        createdAt: Date.now(),
        updatedAt: Date.now(),
      };

      tasks.push(task);
      await this.taskStore.save(task);
      this.notifyTaskEvent({ type: "created", task });
    }

    return tasks;
  }

  /**
   * 委派任务给子 Agent
   * 1. 创建子分支会话
   * 2. 在分支中使用指定 Agent 执行
   * 3. 完成后将结果合并回主会话
   */
  async delegateTask(opts: {
    taskId: string;
    agentId: string;
    instructions: string;
  }): Promise<{ branchSessionId: string }> {
    const task = await this.taskStore.get(opts.taskId);

    // 更新任务状态
    await this.updateTask(opts.taskId, {
      status: "in_progress",
      assignedAgentId: opts.agentId,
    });

    // 创建分支会话
    const { sessionId } = await this.branchManager.createBranch({
      parentSessionId: task.sessionId,
      agentId: opts.agentId,
      branchType: "task-delegation",
    });

    // 更新任务的分支会话 ID
    await this.updateTask(opts.taskId, { branchSessionId: sessionId });

    // 在分支中执行 Agent
    this.executeDelegatedTask(
      sessionId,
      opts.agentId,
      opts.instructions,
      async (result) => {
        // 执行完成后更新任务状态
        await this.updateTask(opts.taskId, {
          status: "completed",
          result: result,
        });

        // 合并结果回主会话
        await this.branchManager.mergeBranch({
          sessionId,
          parentSessionId: task.sessionId,
        });
      },
    );

    return { branchSessionId: sessionId };
  }

  /**
   * 获取任务进度
   */
  async getProgress(sessionId: string): Promise<TaskProgress> {
    const tasks = await this.taskStore.getBySession(sessionId);
    const total = tasks.length;
    const completed = tasks.filter((t) => t.status === "completed").length;
    const inProgress = tasks.filter((t) => t.status === "in_progress").length;
    const blocked = tasks.filter((t) => t.status === "blocked").length;
    const failed = tasks.filter((t) => t.status === "failed").length;
    const pending = tasks.filter((t) => t.status === "pending").length;

    return {
      total,
      completed,
      inProgress,
      blocked,
      failed,
      pending,
      percentage: total > 0 ? Math.round((completed / total) * 100) : 0,
    };
  }

  /**
   * 任务状态变更时检查依赖
   * 前置任务完成后，自动解除后续任务的 blocked 状态
   */
  async onTaskCompleted(taskId: string): Promise<void> {
    const task = await this.taskStore.get(taskId);
    const allTasks = await this.taskStore.getBySession(task.sessionId);

    // 找到依赖此任务的其他任务
    const dependents = allTasks.filter(
      (t) => t.dependencies.includes(taskId) && t.status === "blocked",
    );

    for (const dep of dependents) {
      // 检查所有依赖是否都已完成
      const allDepsCompleted = dep.dependencies.every((depId) => {
        const depTask = allTasks.find((t) => t.id === depId);
        return depTask?.status === "completed";
      });

      if (allDepsCompleted) {
        await this.updateTask(dep.id, { status: "pending" });
      }
    }
  }
}
```
