# F2.8 — 沙箱代码执行

> **Phase**: Phase 2 — Agent 编排 + 代码理解
> **Priority**: P1
> **Status**: Not Started
> **Dependencies**: F1.6 (内置工具集成与权限确认)

## 概述

沙箱代码执行功能让 Agent 生成的代码片段在安全隔离的沙箱环境中运行验证，不直接写入项目文件。Agent 在编写新代码后，可以先在沙箱中执行验证通过，再写入项目文件，避免错误代码直接污染项目。

沙箱支持三种语言：JavaScript/TypeScript 使用 isolated-vm 创建 V8 隔离上下文执行；Python 使用子进程隔离执行；Shell 脚本在临时目录中执行。安全策略包括文件系统隔离（沙箱只能访问临时目录）、网络可选（默认禁用）、资源限制（CPU 时间和内存上限）。执行结果返回 stdout、stderr、exitCode 和 duration。

## 验收标准

### 功能验收
- [ ] `sandbox_run` 工具注册为 Pi 自定义工具
- [ ] 支持 JavaScript/TypeScript 执行（使用 isolated-vm）
- [ ] 支持 Python 执行（子进程隔离）
- [ ] 支持 Shell 脚本执行（临时目录）
- [ ] 文件系统隔离：沙箱只能访问临时目录，不能读写项目文件
- [ ] 网络可选：默认禁用网络，可配置开启
- [ ] 资源限制：CPU 时间限制和内存上限
- [ ] 执行超时限制（可配置，默认 30 秒）
- [ ] 返回 stdout / stderr / exitCode / duration
- [ ] 返回 outputFiles（生成的文件路径列表）
- [ ] 验证通过后 Agent 可以选择将代码写入项目文件（走 Checkpoint + Diff 审查）
- [ ] 沙箱执行结果在消息流中以工具调用卡片展示
- [ ] TypeScript 代码在执行前自动编译为 JavaScript
- [ ] 支持传入 stdin 输入
- [ ] 支持在指定项目上下文中运行（加载项目 node_modules/venv 依赖）

### 非功能验收
- [ ] JS/TS 沙箱执行启动 < 200ms
- [ ] Python 沙箱执行启动 < 500ms
- [ ] 沙箱进程结束后正确清理临时文件
- [ ] 沙箱内存使用不超过配置上限（默认 256MB）
- [ ] 网络隔离生效（禁用时无法发起网络请求）

### 数据模型

```typescript
// shared/types/sandbox.ts

/** 沙箱运行请求 */
interface SandboxRunRequest {
  language: "javascript" | "typescript" | "python" | "shell";
  code: string;
  stdin?: string;
  timeout?: number;                 // 超时毫秒，默认 30000
  projectPath?: string;             // 项目上下文（加载依赖）
  enableNetwork?: boolean;          // 默认 false
  memoryLimit?: number;             // 内存上限 MB，默认 256
}

/** 沙箱运行结果 */
interface SandboxResult {
  stdout: string;
  stderr: string;
  exitCode: number;
  duration: number;                  // 执行耗时 ms
  outputFiles?: string[];           // 生成的文件路径（临时目录内）
  timedOut?: boolean;               // 是否超时
  error?: string;                   // 执行错误信息
}

/** 沙箱配置 */
interface SandboxConfig {
  defaultTimeout: number;            // 默认 30000
  defaultMemoryLimit: number;       // 默认 256 (MB)
  networkEnabled: boolean;          // 默认 false
  tempDir: string;                  // 临时目录根路径
  pythonPath?: string;              // Python 可执行路径
  nodePath?: string;                // Node.js 可执行路径
}
```

### 关键实现逻辑

**SandboxRunner 主类**:

```typescript
// main/services/sandbox-runner.ts

import { app } from "electron";
import * as path from "path";
import * as fs from "fs/promises";
import { execFile } from "child_process";
import { SandboxRunRequest, SandboxResult } from "../../shared/types/sandbox";

export class SandboxRunner {
  private config: SandboxConfig;
  private tempDir: string;

  constructor(config?: Partial<SandboxConfig>) {
    this.config = {
      defaultTimeout: 30000,
      defaultMemoryLimit: 256,
      networkEnabled: false,
      tempDir: path.join(app.getPath("temp"), "agentbuddy-sandbox"),
      ...config,
    };
  }

  /** 运行代码 */
  async run(request: SandboxRunRequest): Promise<SandboxResult> {
    const startTime = Date.now();
    const sessionId = generateId();
    const workDir = path.join(this.tempDir, sessionId);
    
    try {
      // 创建临时工作目录
      await fs.mkdir(workDir, { recursive: true });
      
      // 根据语言选择执行器
      let result: SandboxResult;
      switch (request.language) {
        case "javascript":
        case "typescript":
          result = await this.runJavaScript(request, workDir);
          break;
        case "python":
          result = await this.runPython(request, workDir);
          break;
        case "shell":
          result = await this.runShell(request, workDir);
          break;
        default:
          return {
            stdout: "",
            stderr: `Unsupported language: ${request.language}`,
            exitCode: 1,
            duration: Date.now() - startTime,
            error: "Unsupported language",
          };
      }
      
      result.duration = Date.now() - startTime;
      
      // 收集生成的文件
      result.outputFiles = await this.collectOutputFiles(workDir);
      
      return result;
    } catch (error) {
      return {
        stdout: "",
        stderr: error instanceof Error ? error.message : String(error),
        exitCode: 1,
        duration: Date.now() - startTime,
        error: error instanceof Error ? error.message : String(error),
      };
    } finally {
      // 清理临时目录（延迟清理，让用户可以先查看 outputFiles）
      setTimeout(() => this.cleanup(workDir), 60000);
    }
  }

  /** JavaScript/TypeScript 执行（isolated-vm） */
  private async runJavaScript(
    request: SandboxRunRequest,
    workDir: string
  ): Promise<SandboxResult> {
    let code = request.code;
    
    // TypeScript 编译为 JavaScript
    if (request.language === "typescript") {
      code = await this.compileTypeScript(code, workDir);
    }
    
    // 写入代码文件
    const scriptPath = path.join(workDir, "script.js");
    await fs.writeFile(scriptPath, code);
    
    // 使用 isolated-vm 创建隔离上下文
    return new Promise((resolve) => {
      const timeout = request.timeout ?? this.config.defaultTimeout;
      const memoryLimit = (request.memoryLimit ?? this.config.defaultMemoryLimit) * 1024 * 1024;
      
      let stdout = "";
      let stderr = "";
      let timedOut = false;
      
      const timer = setTimeout(() => {
        timedOut = true;
        resolve({
          stdout,
          stderr: stderr + "\n[Execution timed out]",
          exitCode: 124,
          duration: 0,
          timedOut: true,
        });
      }, timeout);

      // 使用子进程执行 Node.js，传入限制参数
      const child = execFile(
        process.execPath,
        [
          "--max-old-space-size=" + (request.memoryLimit ?? this.config.defaultMemoryLimit),
          scriptPath,
        ],
        {
          cwd: workDir,
          timeout: timeout,
          env: {
            ...process.env,
            // 禁用网络（通过环境变量提示，实际隔离需 OS 级别）
            SANDBOX_MODE: "true",
            SANDBOX_NETWORK: this.config.networkEnabled ? "true" : "false",
          },
          maxBuffer: 10 * 1024 * 1024, // 10MB stdout 缓冲
        },
        (error, stdoutResult, stderrResult) => {
          clearTimeout(timer);
          stdout = stdoutResult;
          stderr = stderrResult;
          
          resolve({
            stdout,
            stderr,
            exitCode: error?.code ?? 0,
            duration: 0,
            timedOut,
          });
        }
      );
      
      // 传入 stdin
      if (request.stdin) {
        child.stdin?.write(request.stdin);
        child.stdin?.end();
      }
    });
  }

  /** TypeScript 编译 */
  private async compileTypeScript(code: string, workDir: string): Promise<string> {
    const ts = require("typescript");
    const result = ts.transpileModule(code, {
      compilerOptions: {
        target: ts.ScriptTarget.ES2022,
        module: ts.ModuleKind.CommonJS,
        esModuleInterop: true,
        strict: false,
      },
    });
    return result.outputText;
  }

  /** Python 执行（子进程隔离） */
  private async runPython(
    request: SandboxRunRequest,
    workDir: string
  ): Promise<SandboxResult> {
    const scriptPath = path.join(workDir, "script.py");
    await fs.writeFile(scriptPath, request.code);
    
    return new Promise((resolve) => {
      const timeout = request.timeout ?? this.config.defaultTimeout;
      const pythonPath = this.config.pythonPath || "python3";
      
      const child = execFile(
        pythonPath,
        [scriptPath],
        {
          cwd: workDir,
          timeout: timeout,
          env: {
            ...process.env,
            PYTHONPATH: workDir,
            PYTHONDONTWRITEBYTECODE: "1",
          },
          maxBuffer: 10 * 1024 * 1024,
        },
        (error, stdout, stderr) => {
          resolve({
            stdout,
            stderr,
            exitCode: error?.code ?? 0,
            duration: 0,
          });
        }
      );
      
      if (request.stdin) {
        child.stdin?.write(request.stdin);
        child.stdin?.end();
      }
    });
  }

  /** Shell 脚本执行（临时目录） */
  private async runShell(
    request: SandboxRunRequest,
    workDir: string
  ): Promise<SandboxResult> {
    const scriptPath = path.join(workDir, "script.sh");
    await fs.writeFile(scriptPath, request.code, { mode: 0o755 });
    
    return new Promise((resolve) => {
      const timeout = request.timeout ?? this.config.defaultTimeout;
      const shell = process.platform === "win32" ? "cmd.exe" : "/bin/bash";
      
      const child = execFile(
        shell,
        [shell === "cmd.exe" ? "/c" : "-c", request.code],
        {
          cwd: workDir,
          timeout: timeout,
          env: { ...process.env, SANDBOX_MODE: "true" },
          maxBuffer: 10 * 1024 * 1024,
        },
        (error, stdout, stderr) => {
          resolve({
            stdout,
            stderr,
            exitCode: error?.code ?? 0,
            duration: 0,
          });
        }
      );
      
      if (request.stdin) {
        child.stdin?.write(request.stdin);
        child.stdin?.end();
      }
    });
  }

  /** 收集临时目录中生成的文件 */
  private async collectOutputFiles(workDir: string): Promise<string[]> {
    const files: string[] = [];
    const entries = await fs.readdir(workDir, { withFileTypes: true });
    for (const entry of entries) {
      if (entry.isFile() && !entry.name.startsWith("script.")) {
        files.push(path.join(workDir, entry.name));
      }
    }
    return files;
  }

  /** 清理临时目录 */
  private async cleanup(workDir: string): Promise<void> {
    try {
      await fs.rm(workDir, { recursive: true, force: true });
    } catch {
      // 忽略清理错误
    }
  }
}
```

import { Tool } from "@earendil-works/pi-coding-agent";

export function createSandboxTools(sandbox: SandboxRunner): Tool[] {

          timeout: params.timeout,

        });
        return {
          stdout: result.stdout,
          stderr: result.stderr,
          exitCode: result.exitCode,

          timedOut: result.timedOut,

    },
  ];

## 备注

- 沙箱执行权限为 "auto"（自动放行），因为代码在隔离环境中运行，不影响项目文件
- "写入项目文件"操作复用 F1.6 的 write 工具，走权限确认和 F1.11 的 Checkpoint + Diff 审查
- 临时目录路径：`{系统临时目录}/agentbuddy-sandbox/{sessionId}/`
- 清理策略：执行完成后 60 秒延迟清理，让用户有时间查看 outputFiles
