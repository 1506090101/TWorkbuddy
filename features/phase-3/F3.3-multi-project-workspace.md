# F3.3 — 多项目工作区

> **Phase**: Phase 3 — MCP 工具生态 + 多项目 (MCP & Multi-Project)
> **Priority**: P0
> **Status**: Not Started
> **Dependencies**: F1.9 (项目自动感知), F2.5 (代码知识图谱)

## 概述

开发者通常同时维护多个项目——前端项目、后端 API、基础设施脚本、甚至微服务架构下的多个服务。Agent Buddy 的多项目工作区允许用户同时管理多个项目，每个项目拥有独立的配置、记忆和知识图谱，同时支持跨项目代码参考和搜索。

核心能力包括：工作区模型（多项目 + 活跃项目切换）、每项目独立配置和记忆、跨项目参考（将其他项目作为"参考证据"引入当前会话，支持 read-only 和 read-execute 两种模式）、跨项目搜索（指定项目或全项目搜索）、实现对比（compareImplementations）。Agent 回答中会标注引用来源，用户可点击跳转到参考项目的对应文件。

这让 Agent 能理解"参考项目 B 的认证实现，在项目 A 中实现一个适配当前技术栈的认证模块"这样的跨项目任务，真正成为多项目协作的 AI 伙伴。

## 验收标准

### 功能验收
- [ ] Workspace 模型：支持添加多个项目，每个项目独立配置和记忆
- [ ] 活跃项目切换：侧边栏项目列表，点击切换当前活跃项目
- [ ] 项目标签页：每个项目一个标签页，独立会话和上下文
- [ ] 每项目独立配置：agentConfig / memoryDir / knowledgeScope 可独立设置
- [ ] 跨项目参考（read-only）：Agent 可读取参考项目的文件和代码结构，不能修改
- [ ] 跨项目参考（read-execute）：Agent 可读取 + 在参考项目中执行只读命令（测试、构建检查）
- [ ] 参考项目面板：展示当前会话引入的参考项目列表，可展开浏览其结构
- [ ] 跨项目搜索：支持指定项目搜索和全项目搜索
- [ ] 实现对比：compareImplementations 对比两个项目的实现差异
- [ ] 引用标注：Agent 回答中标注"参考自 project-B/src/auth/login.ts:42"
- [ ] 引用跳转：点击引用标注跳转到参考项目的对应文件和行号
- [ ] 参考项目的代码不出现在当前项目的 Git diff 中

### 非功能验收
- [ ] 项目切换响应时间 < 500ms（切换活跃项目时重新加载上下文）
- [ ] 跨项目搜索在 10+ 项目时仍保持快速响应
- [ ] 参考项目文件读取有权限边界（排除 `.env` 等敏感文件）

## 技术设计

### 数据模型

```typescript
// 多项目工作区
interface Workspace {
  id: string;
  name: string;
  projects: ProjectEntry[];
  activeProjectId: string;
}

// 项目条目（工作区中的项目）
interface ProjectEntry {
  id: string;
  name: string;
  path: string;
  context: ProjectContext;           // 自动感知的项目信息（3.12.3）
  gitInfo?: GitStatus;

  // 独立配置
  agentConfig?: string;              // 该项目专属的 Agent 配置
  memoryDir: string;                // 项目记忆目录
  knowledgeScope: "project" | "workspace";  // 知识库范围

  // 跨项目参考
  references: ProjectReference[];   // 引用的其他项目
  referencedBy: string[];           // 被哪些项目引用
}

// 项目参考配置
interface ProjectReference {
  projectId: string;
  alias: string;                    // 在当前项目中的别名
  mode: "read-only" | "read-execute";  // 只读参考 / 可读可执行
  purpose: string;                  // 参考目的说明
}

// 项目上下文（自动感知）
interface ProjectContext {
  rootPath: string;
  type: "node" | "python" | "rust" | "go" | "java" | "cpp" | "mixed" | "unknown";
  language: string;
  framework?: string;
  packageManager?: string;
  buildSystem?: string;
  testCommand?: string;
  lintCommand?: string;
  dependencies: DependencyInfo[];
  scripts?: Record<string, string>;
  gitInfo?: GitStatus;
  structure: ProjectStructure;
}

// 跨项目搜索选项
interface SearchOpts {
  type?: SymbolType;
  filePath?: string;
  limit?: number;
}

// 跨项目搜索结果
interface ProjectSearchResult {
  projectId: string;
  projectName: string;
  results: SearchResult[];
}

// 实现对比结果
interface ComparisonResult {
  fileA: { projectId: string; path: string; content: string };
  fileB: { projectId: string; path: string; content: string };
  diff: string;                     // unified diff
  similarity: number;              // 相似度百分比
  keyDifferences: string[];        // 关键差异列表
}
```

### 关键实现逻辑

**跨项目参考流程**：

```typescript
// main/services/workspace/CrossProjectManager.ts

class CrossProjectManager {
  // 用户："帮我实现一个用户认证模块，参考 project-B 里的认证实现"
  async handleCrossProjectReference(
    currentProjectId: string,
    referenceProjectId: string,
    task: string
  ): Promise<void> {
    // 1. 获取参考项目的项目上下文（结构、技术栈、入口文件）
    const refProject = await this.getProject(referenceProjectId);
    const refContext = refProject.context;

    // 2. 注入参考项目上下文到 Agent system context
    const contextInjection = `
## 参考项目: ${refProject.name} (alias: ${reference.alias})
- 技术栈: ${refContext.language} / ${refContext.framework}
- 目录结构: ${JSON.stringify(refContext.structure)}
- 参考模式: ${reference.mode}
- 参考目的: ${reference.purpose}
`;

    // 3. Agent 搜索参考项目中的认证相关代码（AST 符号搜索 + grep）
    const authSymbols = await this.knowledgeGraph.searchSymbols("auth", {
      project: referenceProjectId,
    });
    // → 返回参考项目中的认证相关符号

    // 4. 读取参考项目相关文件内容，提取实现模式
    for (const symbol of authSymbols.slice(0, 5)) {
      const code = await this.readReferenceFile(
        referenceProjectId,
        symbol.filePath,
        symbol.location.startLine,
        symbol.location.endLine
      );
      // 注入到 Agent 上下文
    }

    // 5. Agent 在当前项目的上下文中，生成适配当前技术栈的认证模块
    // → Agent 使用 write/edit 工具在当前项目创建文件

    // 6. 引用标注：Agent 回答中标注"参考自 project-B/src/auth/login.ts:42"
    // → 通过 ReferenceBadge 组件渲染
  }

  // 读取参考项目文件（受权限边界保护）
  async readReferenceFile(
    projectId: string,
    filePath: string,
    startLine?: number,
    endLine?: number
  ): Promise<string> {
    // 权限检查：排除敏感文件
    if (this.isSensitiveFile(filePath)) {
      throw new Error(`Access denied: ${filePath} is a sensitive file`);
    }

    const project = await this.getProject(projectId);
    const fullPath = path.join(project.path, filePath);

    // 检查路径是否在项目目录内（防止路径穿越）
    if (!fullPath.startsWith(project.path)) {
      throw new Error("Path traversal detected");
    }

    const content = await fs.readFile(fullPath, "utf-8");
    if (startLine && endLine) {
      const lines = content.split("\n");
      return lines.slice(startLine - 1, endLine).join("\n");
    }
    return content;
  }

  private isSensitiveFile(filePath: string): boolean {
    const sensitivePatterns = [
      /\.env/,
      /\.env\./,
      /secret/i,
      /credential/i,
      /\.pem$/,
      /id_rsa/,
      /id_ed25519/,
    ];
    return sensitivePatterns.some(p => p.test(filePath));
  }
}
```

**跨项目搜索**：

```typescript
// 在指定项目中搜索
async searchInProject(
  projectId: string,
  query: string,
  opts: SearchOpts
): Promise<SearchResult[]> {
  // 使用该项目的知识图谱进行符号搜索
  const results = await this.knowledgeGraph.searchSymbols(query, {
    ...opts,
    project: projectId,
  });
  return results;
}

// 跨所有项目搜索
async searchAcrossProjects(
  query: string,
  opts: SearchOpts
): Promise<ProjectSearchResult[]> {
  const workspace = await this.getWorkspace();
  const allResults: ProjectSearchResult[] = [];

  // 并行搜索所有项目
  const searchPromises = workspace.projects.map(async (project) => {
    const results = await this.searchInProject(project.id, query, opts);
    return {
      projectId: project.id,
      projectName: project.name,
      results,
    } as ProjectSearchResult;
  });

  const results = await Promise.all(searchPromises);
  return results.filter(r => r.results.length > 0);
}
```

```typescript
async compareImplementations(
  projectIdA: string, fileA: string,
  projectIdB: string, fileB: string
): Promise<ComparisonResult> {
  const projectA = await this.getProject(projectIdA);
  const projectB = await this.getProject(projectIdB);

  const contentA = await fs.readFile(path.join(projectA.path, fileA), "utf-8");
  const contentB = await fs.readFile(path.join(projectB.path, fileB), "utf-8");

  // 生成 unified diff
  const diff = createUnifiedDiff(contentA, contentB);

  // 计算相似度
  const similarity = calculateSimilarity(contentA, contentB);

  // 调用 LLM 分析关键差异
  const keyDifferences = await this.analyzeDifferences(contentA, contentB, fileA, fileB);

  return {
    fileA: { projectId: projectIdA, path: fileA, content: contentA },
    fileB: { projectId: projectIdB, path: fileB, content: contentB },
    diff,
    similarity,
    keyDifferences,
  };
}
```
