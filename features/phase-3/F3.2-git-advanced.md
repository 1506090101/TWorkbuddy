# F3.2 — Git 深度集成

> **Phase**: Phase 3 — MCP 工具生态 + 多项目 (MCP & Multi-Project)
> **Priority**: P1
> **Status**: Not Started
> **Dependencies**: F1.10 (Git 基础集成)

## 概述

F1.10 已实现了 Git 基础工具集（status/branch/log/diff/show/commit/branch/checkout/stash），让 Agent 能语义化地理解版本控制状态。F3.2 Git 深度集成在此基础上扩展，增加 `gitBlame`（行级 blame 信息）、`gitCreatePR`（GitHub/GitLab/Gitea PR 创建）、commit message 自动生成（基于 diff 调用 LLM）和合并冲突辅助解决能力。

这些扩展让 Agent 不仅能理解 Git 状态，还能参与更深层的代码协作流程——例如审核代码时追溯某行代码的修改历史、完成功能后自动创建 PR、以及遇到合并冲突时智能辅助解决。这使 Agent Buddy 成为一个覆盖完整 Git 工作流的开发伙伴。

## 验收标准

### 功能验收
- [ ] `gitBlame(file, startLine, endLine)`: 返回指定文件指定行范围的 blame 信息（commit hash、作者、日期、代码行）
- [ ] `gitCreatePR(opts)`: 支持创建 PR 到 GitHub / GitLab / Gitea，返回 PR URL
- [ ] commit message 自动生成：基于 git diff 内容调用 LLM 生成规范的 conventional commit message
- [ ] 合并冲突辅助解决：解析冲突文件，识别冲突块，Agent 提供合并建议
- [ ] Git 平台 Token 管理：通过配置中的 `type: "git-platform"` 管理 GitHub/GitLab/Gitea Token
- [ ] blame 结果在 UI 中可视化展示（行号 + 作者 + commit 信息）
- [ ] PR 创建前显示预览（标题、描述、目标分支、源分支）
- [ ] 自动生成的 commit message 可在提交前编辑

### 非功能验收
- [ ] gitBlame 对大文件（1000+ 行）响应时间 < 500ms
- [ ] PR 创建支持超时处理（网络异常时明确提示）
- [ ] Git 平台 Token 使用 safeStorage 加密存储
- [ ] 合并冲突解析支持标准冲突标记（`<<<<<<<` / `=======` / `>>>>>>>`）

// Blame 信息
interface BlameInfo {
  line: number;                    // 行号
  commit: string;                  // commit hash
  author: string;                  // 作者
  authorTime: number;              // 提交时间戳
  summary: string;                 // commit message 简要
  code: string;                    // 该行的代码内容
}

// PR 创建参数
interface CreatePRParams {
  title: string;
  body: string;                    // PR 描述
  base: string;                    // 目标分支
  head: string;                    // 源分支
}

// PR 创建结果
interface PRResult {
  url: string;                     // PR URL
  number: number;                  // PR 编号
  platform: "github" | "gitlab" | "gitea";
}

// 合并冲突块
interface ConflictBlock {
  startLine: number;
  endLine: number;
  ours: string;                    // 当前分支的内容
  theirs: string;                  // 传入分支的内容
  file: string;
}

// 冲突分析结果
interface ConflictAnalysis {
  conflicts: ConflictBlock[];
  suggestion: string;              // LLM 生成的合并建议
  autoResolvable: boolean;         // 是否可自动解决
}

// Git 平台配置
interface GitPlatformConfig {
  platform: "github" | "gitlab" | "gitea";
  token: string;                   // 加密存储
  apiUrl?: string;                  // 自定义 API 地址（企业版/自托管）
}

// Commit message 生成结果
interface GeneratedCommitMessage {
  type: string;                    // feat, fix, refactor, docs, test, chore...
  scope?: string;                   // 影响范围
  subject: string;                  // 简短描述
  body?: string;                    // 详细描述
  full: string;                     // 完整的 conventional commit message
}

### 关键实现逻辑

**gitBlame 实现**：

```typescript
// main/services/git/GitBlame.ts

async function gitBlame(
  repoPath: string,
  file: string,
  startLine: number,
  endLine: number
): Promise<BlameInfo[]> {
  // 使用 git blame --porcelain 获取机器可读格式
  const { stdout } = await execAsync(
    `git blame --porcelain -L ${startLine},${endLine} -- ${file}`,
    { cwd: repoPath }
  );

  const lines = stdout.split("\n");
  const results: BlameInfo[] = [];
  let current: Partial<BlameInfo> = {};

  for (const line of lines) {
    if (line.startsWith("author ")) {
      current.author = line.slice(7);
    } else if (line.startsWith("author-time ")) {
      current.authorTime = parseInt(line.slice(12)) * 1000;
    } else if (line.startsWith("summary ")) {
      current.summary = line.slice(8);
    } else if (line.match(/^[0-9a-f]{40}/)) {
      // commit hash 行
      if (current.line) {
        results.push(current as BlameInfo);
      }
      current = { commit: line.slice(0, 40) };
    } else if (line.startsWith("\t")) {
      current.code = line.slice(1);
    }
  }
  if (current.line) results.push(current as BlameInfo);

  return results;
}
```

**commit message 自动生成**：

```typescript
// main/services/git/CommitMessageGenerator.ts

async function generateCommitMessage(
  repoPath: string,
  staged: boolean = true
): Promise<GeneratedCommitMessage> {
  // 1. 获取 diff
  const { stdout: diff } = await execAsync(
    staged ? "git diff --cached" : "git diff",
    { cwd: repoPath, maxBuffer: 1024 * 1024 }
  );

  if (!diff.trim()) {
    throw new Error("No changes to commit");
  }

  // 2. 获取变更文件列表
  const { stdout: filesOutput } = await execAsync(
    staged ? "git diff --cached --name-only" : "git diff --name-only",
    { cwd: repoPath }
  );
  const files = filesOutput.trim().split("\n").filter(Boolean);

  // 3. 调用 LLM 生成 conventional commit message
  const prompt = `Analyze the following git diff and generate a conventional commit message.

Files changed: ${files.join(", ")}

Diff:
${diff.slice(0, 8000)} // 截断防止超长

Generate a commit message in conventional commits format:
- type (feat/fix/refactor/docs/test/chore/style/perf)
- scope (optional, affected module)
- subject (short description, imperative mood)
- body (optional, detailed description)

Respond in JSON format: { "type": "...", "scope": "...", "subject": "...", "body": "..." }`;

  const result = await pi.prompt(prompt, { model: getCheapestModel() });
  const parsed = JSON.parse(result.text);

  return {
    ...parsed,
    full: `${parsed.type}${parsed.scope ? `(${parsed.scope})` : ""}: ${parsed.subject}${parsed.body ? `\n\n${parsed.body}` : ""}`,
  };
}
```

**PR 创建（多平台支持）**：

```typescript
// main/services/git/PRCreator.ts

async function createPR(
  repoPath: string,
  params: CreatePRParams,
  platform: "github" | "gitlab" | "gitea"
): Promise<PRResult> {
  // 1. 获取远程仓库信息
  const { stdout: remoteUrl } = await execAsync("git remote get-url origin", { cwd: repoPath });
  const repoInfo = parseRemoteUrl(remoteUrl.trim()); // { owner, repo }

  // 2. 获取平台 Token
  const token = await getGitPlatformToken(platform);
  if (!token) throw new Error(`No token configured for ${platform}`);

  // 3. 根据平台调用不同 API
  switch (platform) {
    case "github":
      return createGitHubPR(repoInfo, params, token);
    case "gitlab":
      return createGitLabMR(repoInfo, params, token);
    case "gitea":
      return createGiteaPR(repoInfo, params, token);
  }
}

async function createGitHubPR(
  repo: { owner: string; repo: string },
  params: CreatePRParams,
  token: string
): Promise<PRResult> {
  const apiUrl = `https://api.github.com/repos/${repo.owner}/${repo.repo}/pulls`;
  const response = await fetch(apiUrl, {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${token}`,
      "Accept": "application/vnd.github.v3+json",
    },
    body: JSON.stringify({
      title: params.title,
      body: params.body,
      base: params.base,
      head: params.head,
    }),
  });

  if (!response.ok) {
    const error = await response.json();
    throw new Error(`GitHub PR creation failed: ${error.message}`);
  }

  const pr = await response.json();
  return {
    url: pr.html_url,
    number: pr.number,
    platform: "github",
  };
}
```

**合并冲突辅助解决**：

```typescript
// main/services/git/ConflictResolver.ts

async function analyzeConflicts(
  repoPath: string,
  files: string[]
): Promise<ConflictAnalysis> {
  const conflicts: ConflictBlock[] = [];

  for (const file of files) {
    const content = await fs.readFile(path.join(repoPath, file), "utf-8");
    const blocks = parseConflictMarkers(content, file);
    conflicts.push(...blocks);
  }

  // 调用 LLM 分析冲突并提供合并建议
  const conflictDescriptions = conflicts.map(c => `
File: ${c.file} (lines ${c.startLine}-${c.endLine})
Ours:
${c.ours}
Theirs:
${c.theirs}
`).join("\n---\n");

  const prompt = `Analyze these git merge conflicts and suggest a resolution.

${conflictDescriptions}

Provide a merged resolution that preserves both sides' intent. If conflicts are purely formatting or non-overlapping, mark as auto-resolvable.`;

  const result = await pi.prompt(prompt);
  const analysis = JSON.parse(result.text);

  return {
    conflicts,
    suggestion: analysis.suggestion,
    autoResolvable: analysis.autoResolvable,
  };
}

function parseConflictMarkers(content: string, file: string): ConflictBlock[] {
  const lines = content.split("\n");
  const blocks: ConflictBlock[] = [];
  let current: Partial<ConflictBlock> | null = null;

  for (let i = 0; i < lines.length; i++) {
    const line = lines[i];
    if (line.startsWith("<<<<<<<")) {
      current = { startLine: i + 1, ours: "", theirs: "", file };
    } else if (line.startsWith("=======") && current) {
      // 切换到 theirs
      (current as any)._collecting = "theirs";
    } else if (line.startsWith(">>>>>>>") && current) {
      current.endLine = i + 1;
      blocks.push(current as ConflictBlock);
      current = null;
    } else if (current) {
      if ((current as any)._collecting === "theirs") {
        current.theirs += (current.theirs ? "\n" : "") + line;
      } else {
        current.ours += (current.ours ? "\n" : "") + line;
      }
    }
  }

  return blocks;
}
```
