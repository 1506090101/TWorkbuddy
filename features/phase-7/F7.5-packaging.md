# F7.5 — 应用打包与分发

> **Phase**: Phase 7 — 精细化 (Polish)
> **Priority**: P0
> **Status**: Not Started
> **Dependencies**: None

## 概述

Agent Buddy 需要作为跨平台桌面应用分发给最终用户。F7.5 应用打包与分发改持 Windows（NSIS installer）、macOS（DMG）和 Linux（AppImage / deb）三平台打包，并内置自动更新机制——用户安装后无需手动下载新版本，应用自动检查更新并在后台下载安装。

本功能使用 `electron-builder` 作为打包工具，配置各平台的构建选项、代码签名（macOS 需要 Developer ID 证书）、自动更新（通过 `electron-updater` 从 GitHub Releases 或自建更新服务器拉取更新包）。

## PRD 对应

- **构建路径 Phase 7**: 应用打包与分发（Windows/macOS/Linux）+ 自动更新机制

## 验收标准

### 功能验收
- [ ] Windows 打包：生成 NSIS installer（`.exe`），支持 64 位
- [ ] macOS 打包：生成 DMG（`.dmg`），支持 Intel + Apple Silicon (Universal)
- [ ] Linux 打包：生成 AppImage（`.AppImage`）和 deb 包（`.deb`）
- [ ] 代码签名（macOS）：使用 Developer ID Application 证书签名
- [ ] 自动更新机制：应用启动时检查更新，后台下载，提示用户重启安装
- [ ] 更新源配置：支持 GitHub Releases 或自建更新服务器
- [ ] 应用图标和启动画面
- [ ] 安装包包含所有必要依赖（tree-sitter native 模块、better-sqlite3 等）

### 面验收
- [ ] 安装包大小合理（< 200MB）
- [ ] 首次启动时间 < 3s
- [ ] macOS 打包通过 Gatekeeper 验证

module.exports = {
  appId: "com.agentbuddy.app",

**自动更新**：

```typescript
// main/services/updater/AutoUpdater.ts

import { autoUpdater } from "electron-updater";

class AppUpdater {
  async initialize(): Promise<void> {
    autoUpdater.autoDownload = true;
    autoUpdater.autoInstallOnAppQuit = true;

    autoUpdater.on("checking-for-update", () => {
      this.sendStatus("checking");
    });

    autoUpdater.on("update-available", (info) => {
      this.sendStatus("available", info.version);
    });

    autoUpdater.on("update-not-available", () => {
      this.sendStatus("up-to-date");
    });

    autoUpdater.on("download-progress", (progress) => {
      this.sendStatus("downloading", progress.percent);
    });

    autoUpdater.on("update-downloaded", () => {
      this.sendStatus("downloaded");
      // 提示用户重启
    });

    // 启动时检查更新
    await autoUpdater.checkForUpdates();
  }
}
```
