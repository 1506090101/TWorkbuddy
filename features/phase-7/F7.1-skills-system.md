## 概述

Skills 系统是 Agent Buddy 可扩展性的核心机制之一。Skills 是 Markdown 文件，包含 frontmatter 元数据和指令正文，为 Agent 提供特定领域的知识和行为指令。例如一个"部署指南" Skill 可以教会 Agent 如何执行部署流程，一个"代码审核标准" Skill 可以让代码审核 Agent 遵循团队规范。

Skills 的加载方式是在 Agent 定义中指定要加载的 Skills 列表，Agent 启动时自动将 Skill 内容注入到 system prompt。用户可以在设置中心浏览、启用/禁用、编辑 Skills，也可以直接分享 Skills 文件——放入指定目录即可加载。这使得 Skills 成为一个轻量级、可分享的 Agent 能力扩展机制。

```typescript

interface Skill {
  id: string;                      // 文件名（不含扩展名）
  name: string;                    // 显示名称
  description: string;            // 简短描述
  version?: string;                // 版本
  author?: string;                 // 作者
  tags?: string[];                 // 标签
  enabled: boolean;                // 是否启用
  content: string;                 // 指令正文（Markdown）
  filePath: string;                // 文件路径
  createdAt: number;
  updatedAt: number;

// Skill frontmatter 格式
// ---
// name: 部署指南
// description: 教会 Agent 如何执行部署流程
// version: 1.0.0
// author: Agent Buddy
// tags: [devops, deploy]
// ---
```

### 关键实现逻辑

**Skill 加载与注入**：

```typescript
// main/services/skills/SkillManager.ts

class SkillManager {
  private skillsDir = path.join(os.homedir(), ".agentbuddy/skills");

  // 扫描 Skills 目录
  async listSkills(): Promise<Skill[]> {
    const files = await fs.readdir(this.skillsDir);
    const skills: Skill[] = [];

    for (const file of files.filter(f => f.endsWith(".md"))) {
      const filePath = path.join(this.skillsDir, file);
      const content = await fs.readFile(filePath, "utf-8");
      const { frontmatter, body } = parseFrontmatter(content);
      skills.push({
        id: file.replace(".md", ""),
        name: frontmatter.name || file.replace(".md", ""),
        description: frontmatter.description || "",
        version: frontmatter.version,
        author: frontmatter.author,
        tags: frontmatter.tags || [],
        enabled: frontmatter.enabled !== false,
        content: body,
        filePath,
        createdAt: (await fs.stat(filePath)).birthtime.getTime(),
        updatedAt: (await fs.stat(filePath)).mtime.getTime(),
      });
    }

    return skills;
  }

  // 为 Agent 加载 Skills 内容
  async loadSkillsForAgent(skillIds: string[]): Promise<string> {
    const skills = await this.listSkills();
    const enabled = skills.filter(s => skillIds.includes(s.id) && s.enabled);

    if (enabled.length === 0) return "";

    const parts: string[] = ["## Loaded Skills\n"];
    for (const skill of enabled) {
      parts.push(`### ${skill.name}\n${skill.content}\n`);
    }

    return parts.join("\n");
  }
}

// 在 Agent 初始化时注入
async function initializeAgent(agentDef: AgentDefinition): Promise<void> {
  // 加载 Skills 内容
  const skillsContent = await skillManager.loadSkillsForAgent(agentDef.skills);

  // 构建 system prompt
  const systemPrompt = `${agentDef.systemPrompt}\n\n${skillsContent}`;

  await pi.createAgentSession({
    model: agentDef.modelAssignment,
    systemPrompt,
    tools: agentDef.tools,
  });
}
```
