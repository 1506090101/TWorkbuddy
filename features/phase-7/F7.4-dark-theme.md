# F7.4 — 暗色主题完善

> **Phase**: Phase 7 — 精细化 (Polish)
> **Priority**: P1
> **Status**: Not Started
> **Dependencies**: F0.2 (统一设计系统)

## 概述

F0.2 统一设计系统已定义了暗色主题的 CSS 变量，但 Phase 1-6 开发的各功能模块在实现时可能未完全覆盖暗色模式适配。F7.4 暗色主题完善对全应用进行暗色主题的全面适配，包括所有 UI 组件、代码语法高亮（Shiki）、Markdown 渲染、Diff 可视化、图表（recharts）等，确保暗色主题下视觉一致性无违和感。

## PRD 对应

- **3.7.2 UI 风格**: 浅色主题为主，预留暗色主题支持（本功能完成暗色主题完整适配）

## 验收标准

### 功能验收
- [ ] 所有 UI 组件暗色模式适配（Button/Input/Card/Dialog/Tabs/Dropdown 等）
- [ ] 代码块语法高亮暗色主题（Shiki dark theme，如 `github-dark` / `one-dark-pro`）
- [ ] Markdown 渲染暗色适配（标题/段落/列表/表格/引用/代码块/链接颜色）
- [ ] Diff 可视化暗色适配（新增绿/删除红/修改黄在暗色背景下对比度足够）
- [ ] 图表暗色适配（recharts 饼图/折线图/条形图颜色和网格线）
- [ ] 终端（xterm.js）暗色主题
- [ ] 知识图谱可视化暗色适配
- [ ] 分支树可视化暗色适配
- [ ] 主题切换无闪烁（CSS variable 切换）
- [ ] 系统主题跟随模式（`prefers-color-scheme`）

### 非功能验收
- [ ] 暗色主题下文字对比度 ≥ 4.5:1（WCAG AA 标准）
- [ ] 所有交互状态（hover/active/focus/disabled）在暗色下可见

## 技术设计

### 关键实现逻辑

```typescript
// 主题切换通过在 <html> 上添加 data-theme 属性
// CSS 变量根据 data-theme 切换

// renderer/src/styles/theme-dark.css
:root[data-theme="dark"] {
  --color-bg-primary: #1a1b26;
  --color-bg-secondary: #24283b;
  --color-bg-tertiary: #2f334d;
  --color-text-primary: #c0caf5;
  --color-text-secondary: #a9b1d6;
  --color-text-muted: #565f89;
  --color-border: #3b4261;
  // ... 所有色系 11 级暗色值
}

// Shiki 代码高亮主题切换
function getCodeHighlighter(theme: "light" | "dark") {
  return theme === "dark" ? "github-dark" : "github-light";
}

// Markdown 渲染暗色适配
// 通过 CSS 变量控制 Markdown 元素颜色
.markdown-body {
  h1, h2, h3 { color: var(--color-text-primary); }
  p { color: var(--color-text-secondary); }
  a { color: var(--color-primary-400); }
  code {
    background: var(--color-bg-tertiary);
    color: var(--color-text-primary);
  }
  blockquote {
    border-left-color: var(--color-border);
    color: var(--color-text-muted);
  }
}
```

## UI/UX 规范

- 暗色主题以深蓝灰色为主基调（`#1a1b26` / `#24283b`）
- 代码高亮使用 `github-dark` 或 `one-dark-pro` 主题
- Diff 颜色：新增用深绿背景（`#1a3a2e`）/ 删除用深红背景（`#3a1e1e`）/ 修改用深黄背景（`#3a3a1e`）
- 图表使用高饱和度颜色在暗色背景上可见

## 测试要点

- **视觉测试**: 逐个页面/组件在暗色主题下截图对比
- **可访问性测试**: 使用 WCAG 对比度检查工具验证文字对比度
- **E2E 测试**: 切换明暗主题，验证所有界面无违和感
