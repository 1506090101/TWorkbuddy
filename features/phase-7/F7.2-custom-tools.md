# F7.2 — 自定义工具脚本

> **Phase**: Phase 7 — 精细化 (Polish)
> **Priority**: P1
> **Status**: Not Started
> **Dependencies**: F1.6 (内置工具集成与权限确认)

## 概述

内置工具（read/write/edit/bash/grep/find/ls）覆盖了通用的文件操作和命令执行场景，但开发者经常有特定需求——比如"打开浏览器"、"调用内部 API"、"格式化日志"等。自定义工具脚本系统允许用户通过 JavaScript/TypeScript 脚本定义自己的工具，扩展 Agent 的能力边界。

每个自定义工具包含 name（工具名）、description（描述）、parameters（参数 schema）、permissions（权限级别：auto/confirm）和 execute（执行函数）。工具脚本存储在 `~/.agentbuddy/tools/*.js`，Agent 启动时自动加载并注册到 Pi SDK。用户可以在工具管理界面创建、编辑、测试自定义工具，也可以分享工具脚本文件给他人。

  name: string;                    // 工具名
  description: string;            // 描述

    description: string;
    required?: boolean;

  permissions: "auto" | "confirm";
  filePath: string;
  enabled: boolean;
  lastTested?: number;
  lastTestResult?: { success: boolean; output?: string; error?: string };
}

### 关键实现逻辑

**自定义工具加载与注册**：

```typescript
// main/services/tools/CustomToolManager.ts

class CustomToolManager {
  private toolsDir = path.join(os.homedir(), ".agentbuddy/tools");

  // 加载并注册所有自定义工具
  async loadAndRegisterTools(): Promise<void> {
    const files = await fs.readdir(this.toolsDir);
    const jsFiles = files.filter(f => f.endsWith(".js"));

    for (const file of jsFiles) {
      try {
        const tool = await this.loadTool(path.join(this.toolsDir, file));
        if (tool.enabled) {
          await this.registerTool(tool);
        }
      } catch (error) {
        console.error(`Failed to load tool ${file}:`, error);
      }
    }
  }

  // 加载单个工具脚本
  private async loadTool(filePath: string): Promise<CustomTool & { execute: Function }> {
    // 使用动态 import 加载模块
    const module = await import(filePath);
    const toolDef = module.default || module;

    return {
      id: path.basename(filePath, ".js"),
      name: toolDef.name,
      description: toolDef.description,
      parameters: toolDef.parameters,
      permissions: toolDef.permissions || "confirm",
      execute: toolDef.execute,
      filePath,
      enabled: true,
    };
  }

  // 注册到 Pi SDK
  private async registerTool(tool: CustomTool & { execute: Function }): Promise<void> {
    pi.registerTool({
      name: tool.name,
      description: `[Custom] ${tool.description}`,
      parameters: tool.parameters,
      permissions: tool.permissions,
      execute: async (params) => {
        try {
          // 超时控制
          const result = await Promise.race([
            tool.execute(params),
            new Promise((_, reject) =>
              setTimeout(() => reject(new Error("Tool execution timeout")), 30000)
            ),
          ]);
          return result;
        } catch (error) {
          return { success: false, error: error.message };
        }
      },
    });
  }

  // 测试工具
  async testTool(id: string, params: Record<string, any>): Promise<{ success: boolean; output?: string; error?: string }> {
    const tool = await this.loadTool(path.join(this.toolsDir, `${id}.js`));
    try {
      const result = await tool.execute(params);
      return { success: true, output: JSON.stringify(result, null, 2) };
    } catch (error) {
      return { success: false, error: error.message };
    }
  }
}
```
