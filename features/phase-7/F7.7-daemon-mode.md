# F7.7 — 后台守护进程

> **Phase**: Phase 7 — 精细化 (Polish)
> **Priority**: P1
> **Status**: Not Started
> **Dependencies**: F6.1 (定时工作流引擎), F6.2 (消息平台网关)

## 概述

F6.1 定时工作流引擎和 F6.2 消息平台网关在主进程中运行，依赖 Electron 窗口的生命周期。当用户关闭窗口时，Cron 调度器和 Gateway 网关也会停止——这意味着定时任务不会执行、消息平台的消息不会被接收处理。F7.7 后台守护进程通过 System Tray 集成和守护进程模式，让关闭窗口后 Gateway 和调度器继续运行。

用户关闭窗口时应用最小化到系统托盘（而非退出），Cron 调度器和消息网关在后台持续运行。用户可以通过托盘图标右键菜单恢复窗口或完全退出。这让 Agent Buddy 成为一个真正的后台服务——定时任务按时执行，消息平台随时响应。

## PRD 对应

- **构建路径 Phase 7**: 后台守护进程模式（关闭窗口后 Gateway 和调度器继续运行）
- **3.11 消息平台网关**: Gateway 需要持续运行以接收消息

### 关键实现逻辑

```typescript
// main/services/daemon/TrayManager.ts

import { Tray, Menu, nativeImage, app } from "electron";

class TrayManager {
  private tray: Tray | null = null;
  private notificationCount = 0;

  initialize(mainWindow: BrowserWindow): void {
    // 创建托盘图标
    const icon = nativeImage.createFromPath(path.join(__dirname, "../../build/tray-icon.png"));
    this.tray = new Tray(icon);
    this.tray.setToolTip("Agent Buddy");

    this.updateMenu(mainWindow);

    // 点击托盘图标恢复窗口
    this.tray.on("click", () => {
      mainWindow.show();
      mainWindow.focus();
    });
  }

  private updateMenu(mainWindow: BrowserWindow): void {
    const contextMenu = Menu.buildFromTemplate([
      {
        label: "显示主窗口",
        click: () => {
          mainWindow.show();
          mainWindow.focus();
        },
      },
      {
        label: "设置",
        click: () => {
          mainWindow.show();
          mainWindow.webContents.send("navigate", "settings");
        },
      },
      { type: "separator" },
      {
        label: "工作流状态",
        submenu: [
          { label: `调度中: ${workflowEngine.getActiveCount()}` },
          { label: `下次运行: ${workflowEngine.getNextRunTime()}` },
        ],
      },
      {
        label: "渠道状态",
        submenu: this.getChannelStatusMenu(),
      },
      { type: "separator" },
      {
        label: "开机自启动",
        type: "checkbox",
        checked: app.getLoginItemSettings().openAtLogin,
        click: (item) => {
          app.setLoginItemSettings({ openAtLogin: item.checked });
        },
      },
      { type: "separator" },
      {
        label: "退出",
        click: () => {
          app.quit();
        },
      },
    ]);

    this.tray?.setContextMenu(contextMenu);
  }

  // 关闭窗口时拦截，最小化到托盘
  setupWindowCloseHandler(mainWindow: BrowserWindow): void {
    mainWindow.on("close", (event) => {
      if (!app.isQuitting) {
        event.preventDefault();
        mainWindow.hide();
        this.showNotification("Agent Buddy", "应用已最小化到托盘，后台服务继续运行");
      }
    });
  }

  // 显示通知并更新角标
  showNotification(title: string, body: string): void {
    if (process.platform === "win32") {
      this.tray?.displayBalloon({
        iconType: "info",
        title,
        content: body,
      });
    } else {
      const notification = new Notification({ title, body });
      notification.show();
    }

    this.notificationCount++;
    this.updateTrayIcon();
  }

  // 更新托盘图标状态（角标）
  private updateTrayIcon(): void {
    if (this.notificationCount > 0) {
      // 切换到有通知的图标
      const icon = nativeImage.createFromPath(
        path.join(__dirname, "../../build/tray-icon-active.png")
      );
      this.tray?.setImage(icon);
    } else {
      // 恢复正常图标
      const icon = nativeImage.createFromPath(
        path.join(__dirname, "../../build/tray-icon.png")
      );
      this.tray?.setImage(icon);
    }
  }

  // 清除通知角标
  clearNotifications(): void {
    this.notificationCount = 0;
    this.updateTrayIcon();
  }
}

// 全局退出标志
app.isQuitting = false;
app.on("before-quit", () => {
  app.isQuitting = true;
});
```

**守护进程模式**：

```typescript
// main/main.ts (Electron 主进程入口)

let mainWindow: BrowserWindow | null = null;
let trayManager: TrayManager | null = null;

async function createWindow(): Promise<void> {
  mainWindow = new BrowserWindow({
    width: 1280,
    height: 800,
    minWidth: 800,
    minHeight: 600,
    show: false, // 启动时不显示，加载完成后显示
    titleBarStyle: "hiddenInset",
    webPreferences: {
      preload: path.join(__dirname, "../preload/index.js"),
      contextIsolation: true,
      nodeIntegration: false,
      sandbox: true,
    },
  });

  // 加载页面
  await mainWindow.loadURL(
    process.env["ELECTRON_RENDERER_URL"] || `file://${path.join(__dirname, "../renderer/dist/index.html")}`
  );

  mainWindow.show();

  // 初始化托盘
  trayManager = new TrayManager();
  trayManager.initialize(mainWindow);
  trayManager.setupWindowCloseHandler(mainWindow);

  // 初始化后台服务（不依赖窗口生命周期）
  await workflowEngine.initialize();
  await messageGateway.initialize();
}

// 单实例锁（防止多开）
const gotTheLock = app.requestSingleInstanceLock();
if (!gotTheLock) {
  app.quit();
} else {
  app.on("second-instance", () => {
    // 第二个实例尝试启动时，恢复窗口
    if (mainWindow) {
      if (mainWindow.isMinimized()) mainWindow.restore();
      mainWindow.show();
      mainWindow.focus();
    }
  });

  app.whenReady().then(createWindow);

  // macOS: 点击 Dock 图标时恢复窗口
  app.on("activate", () => {
    if (mainWindow) {
      mainWindow.show();
      mainWindow.focus();
    }
  });
}
```
