# F7.3 — 会话分支树可视化

> **Phase**: Phase 7 — 精细化 (Polish)
> **Priority**: P2
> **Status**: Not Started
> **Dependencies**: F2.2 (会话分支系统)

## 概述

F2.2 会话分支系统实现了 Git-like 的主会话 + 子分支模型，拉起 Agent 时自动创建子分支，子分支继承主会话的智能摘要上下文，子分支输出可"合并"回主会话。但分支关系在列表中难以直观理解。F7.3 会话分支树可视化将分支关系以图形化方式展示——在侧边面板展示分支树结构，用户可以直观看到主会话与子分支的关系，点击分支跳转到对应会话。

这让复杂的会话分支关系变得清晰可视，用户可以快速理解"哪个 Agent 从哪里分出""结果是否已合并回主会话"，提升多 Agent 协作场景的导航体验。

## 技术设计

### 数据模型

```typescript
// 分支树节点
interface SessionTreeNode {
  sessionId: string;
  title: string;
  agentId: string;
  agentName: string;
  agentIcon: string;
  agentColor: string;
  isMain: boolean;                 // 是否为主会话
  isMerged: boolean;              // 是否已合并回父会话
  contextSummary?: string;        // 上下文摘要
  createdAt: number;
  messageCount: number;
  children: SessionTreeNode[];    // 子分支
}

// 分支树
interface SessionTree {
  root: SessionTreeNode;
  totalBranches: number;
  unmergedBranches: number;
}
```

### 关键实现逻辑

**分支树构建**：

```typescript
// main/services/session/SessionTreeBuilder.ts

async function buildSessionTree(rootSessionId: string): Promise<SessionTree> {
  const rootSession = await sessionManager.getSession(rootSessionId);
  const rootNode = await this.buildNode(rootSession);
  const totalBranches = this.countBranches(rootNode);
  const unmergedBranches = this.countUnmerged(rootNode);

  return { root: rootNode, totalBranches, unmergedBranches };
}

async function buildNode(session: Session): Promise<SessionTreeNode> {
  const agent = await agentManager.getAgent(session.agentId);
  const childSessions = await sessionManager.getChildSessions(session.id);

  return {
    sessionId: session.id,
    title: session.title,
    agentId: session.agentId,
    agentName: agent.name,
    agentIcon: agent.icon,
    agentColor: agent.color,
    isMain: session.parentId === undefined,
    isMerged: session.mergedToParent || false,
    contextSummary: session.contextSummary,
    createdAt: session.createdAt,
    messageCount: session.messages.length,
    children: await Promise.all(
      childSessions.map(child => this.buildNode(child))
    ),
  };
}
```

## UI/UX 规范

- **树形布局**：从左到右展开，根节点（主会话）在最左侧，子分支向右延伸
- **节点样式**：圆角矩形卡片，显示 Agent 图标 + 会话标题 + 消息数
- **主会话**：特殊边框和背景色高亮
- **已合并分支**：节点上有合并图标标记
- **活跃会话**：蓝色边框高亮
- **hover**：显示上下文摘要 tooltip
- **点击**：跳转到对应会话
