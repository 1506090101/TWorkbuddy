# F4.1 — 多层级记忆系统

> **Phase**: Phase 4 — 记忆系统 (Memory)
> **Priority**: P0
> **Status**: Not Started
> **Dependencies**: F1.3 (Pi SDK 集成与 Agent Session 管理)

## 概述

记忆是 AI Agent 从"一次性助手"进化为"长期工作伙伴"的关键能力。没有记忆的 Agent 每次会话都从零开始，无法记住用户的编码习惯、项目的架构决策、过去踩过的坑。Agent Buddy 的多层级记忆系统提供四层记忆：项目级记忆（`.agentbuddy/memory/`，存储架构决策、技术栈、编码规范、关键文件）、用户级偏好（`~/.agentbuddy/memory/`，存储编码习惯、工具链偏好、交互风格）、会话摘要（单次会话存储，下次打开时展示）、行为学习（`~/.agentbuddy/learning/`，追踪采纳/拒绝的模式和频率统计）。

记忆系统具备三种写入方式：自动写入（完成重要工作后追加到项目级日志，用户表达偏好时更新用户级偏好，Agent 建议被采纳/拒绝时更新行为学习）、主动建议（Agent 检测到有价值信息时提示"要记住吗？"）、用户手动管理（设置中心查看/编辑/删除）。会话开始时自动注入项目级和用户级记忆到 system context，会话进行中 Agent 决策时查询行为学习。

## PRD 对应

- **3.4.1 记忆层级**: 四层记忆（项目级/用户级/会话摘要/行为学习）的存储位置、内容和注入时机
- **3.4.2 记忆写入规则**: 自动写入（工作日志 append-only）、主动建议、用户手动管理
- **3.4.3 记忆注入机制**: 会话开始时注入 system context、会话进行中查询行为学习

## 技术设计

### 数据模型

```typescript
// 记忆条目
interface MemoryEntry {
  id: string;
  level: "project" | "user" | "session";
  key: string;                      // 记忆键，如 "coding-style" / "tech-stack" / "architecture-decision"
  value: string;                    // 记忆内容（Markdown 格式）
  projectId?: string;              // 项目级记忆关联的项目
  sourceChannel?: string;           // 来源渠道（desktop / wechat / dingtalk ...）
  createdAt: number;
  updatedAt: number;
}

// 行为学习记录
interface BehaviorPattern {
  id: string;
  pattern: string;                  // 行为模式描述，如 "user-prefers-tabs" / "rejects-semicolons"
  category: "preference" | "workflow" | "coding-style" | "tool-usage";
  action: "accepted" | "rejected"; // 用户的选择
  frequency: number;               // 出现次数
  context: string;                 // 触发上下文
  lastTriggered: number;
  createdAt: number;
}

// 会话摘要
interface SessionSummary {
  sessionId: string;
  summary: string;                 // LLM 生成的会话摘要
  tasks: string[];                 // 完成的任务列表
  keyDecisions: { decision: string; reason: string }[];
  filesModified: string[];
  createdAt: number;
}

// 记忆管理器
interface MemoryManager {
  // 读取
  getProjectMemory(projectId: string): Promise<MemoryEntry[]>;
  getUserMemory(): Promise<MemoryEntry[]>;
  getSessionSummary(sessionId: string): Promise<SessionSummary | null>;
  getBehaviorPatterns(category?: string): Promise<BehaviorPattern[]>;

  // 写入
  writeProjectMemory(projectId: string, key: string, value: string): Promise<void>;
  writeUserMemory(key: string, value: string): Promise<void>;
  recordBehavior(pattern: string, action: "accepted" | "rejected", context: string): Promise<void>;
  generateSessionSummary(sessionId: string): Promise<SessionSummary>;

  // 注入
  buildMemoryContext(projectId: string): Promise<string>; // 构建注入到 system context 的记忆

  // 管理
  updateMemory(id: string, value: string): Promise<void>;
  deleteMemory(id: string): Promise<void>;
  searchMemories(query: string): Promise<MemoryEntry[]>;
}
```

### 关键实现逻辑

**记忆注入机制**：

```typescript
// main/services/memory/MemoryManager.ts

class MemoryManager {
  // 会话开始时构建记忆上下文
  async buildMemoryContext(projectId: string): Promise<string> {
    const parts: string[] = [];

    // 1. 读取项目级记忆
    const projectMemory = await this.getProjectMemory(projectId);
    if (projectMemory.length > 0) {
      parts.push("## 项目记忆\n");
      for (const entry of projectMemory) {
        parts.push(`### ${entry.key}\n${entry.value}\n`);
      }
    }

    // 2. 读取用户级偏好
    const userMemory = await this.getUserMemory();
    if (userMemory.length > 0) {
      parts.push("\n## 用户偏好\n");
      for (const entry of userMemory) {
        parts.push(`### ${entry.key}\n${entry.value}\n`);
      }
    }

    // 3. 读取相关行为学习记录
    const patterns = await this.getBehaviorPatterns();
    const acceptedPatterns = patterns
      .filter(p => p.action === "accepted" && p.frequency >= 2)
      .map(p => p.pattern);
    if (acceptedPatterns.length > 0) {
      parts.push("\n## 行为学习（用户习惯）\n");
      parts.push(acceptedPatterns.map(p => `- ${p}`).join("\n"));
    }

    return parts.join("\n");
  }
}
```

**自动写入规则**：

```typescript
// 工作日志自动写入（append-only）
async function autoWriteProjectLog(
  projectId: string,
  work: string,
  details: string
): Promise<void> {
  const logPath = path.join(
    getProjectPath(projectId),
    ".agentbuddy/memory/work-log.md"
  );

  const timestamp = new Date().toISOString();
  const entry = `## ${timestamp}\n### ${work}\n${details}\n---\n`;

  // append-only 模式，追加到文件末尾
  await fs.appendFile(logPath, entry);
}

// 用户偏好自动更新
async function detectAndSavePreference(
  userMessage: string,
  projectId: string
): Promise<void> {
  // 检测用户是否在表达偏好
  // 如 "以后都用 tabs"、"不要加分号"、"用 pnpm 不要用 npm"
  const preferencePrompt = `Analyze this user message and determine if the user is expressing a coding preference.

Message: "${userMessage}"

If this is a preference, respond in JSON: { "isPreference": true, "key": "...", "value": "..." }
Otherwise: { "isPreference": false }`;

  const result = await pi.prompt(preferencePrompt, { model: getCheapestModel() });
  const parsed = JSON.parse(result.text);

  if (parsed.isPreference) {
    // 提示用户确认
    const accepted = await suggestSaveMemory(
      parsed.key,
      parsed.value,
      "user"
    );
    if (accepted) {
      await this.writeUserMemory(parsed.key, parsed.value);
    }
  }
}

// 行为学习记录
async function recordBehavior(
  pattern: string,
  action: "accepted" | "rejected",
  context: string
): Promise<void> {
  // 检查是否已有相同模式
  const existing = await this.findBehaviorPattern(pattern);
  if (existing) {
    // 更新频率
    existing.frequency += 1;
    existing.action = action; // 记录最新选择
    existing.lastTriggered = Date.now();
    await this.updateBehaviorPattern(existing);
  } else {
    // 创建新记录
    await this.createBehaviorPattern({
      pattern,
      category: categorizePattern(pattern),
      action,
      frequency: 1,
      context,
      lastTriggered: Date.now(),
      createdAt: Date.now(),
    });
  }
}
```

**会话摘要自动生成**：

```typescript
async function generateSessionSummary(sessionId: string): Promise<SessionSummary> {
  // 1. 获取会话消息历史
  const messages = await sessionManager.getMessages(sessionId);

  // 2. 调用 LLM 生成摘要
  const prompt = `Generate a summary of this conversation session.

Messages:
${messages.map(m => `${m.role}: ${m.content.slice(0, 500)}`).join("\n")}

Provide:
1. Summary (2-3 sentences)
2. Tasks completed
3. Key decisions made (with reasons)
4. Files modified

Respond in JSON: { "summary": "...", "tasks": [...], "keyDecisions": [...], "filesModified": [...] }`;

  const result = await pi.prompt(prompt, { model: getCheapestModel() });
  const parsed = JSON.parse(result.text);

  return {
    sessionId,
    summary: parsed.summary,
    tasks: parsed.tasks,
    keyDecisions: parsed.keyDecisions,
    filesModified: parsed.filesModified,
    createdAt: Date.now(),
  };
}
```
